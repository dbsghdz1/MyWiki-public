# 앱 이름과 검색 노출

출시한 앱이 **자기 이름으로 검색해도 안 나오는** 사태를 Fadeo에서 겪고 정리했다. 이름을 짓는 시점에 판정할 수 있는 것들이다.

## 핵심 — 짧은 조어 브랜드명은 흔한 단어에 먹힌다 ★★

**증상**: `Fadeo`로 검색하면 결과 178개 안에 Fadeo가 없다. KR·US 둘 다. 상위는 전부 **비디오 편집 앱**(Vlogr, VITA, VideoShow, Magisto…).

**원인**: App Store 검색은 정확 일치만 보지 않는다. `Fadeo` ≈ `Video`로 퍼지 매칭되면서, 검색량이 압도적으로 큰 "video" 앱들이 같은 결과 목록을 채워 버린다. 신규 앱은 랭킹 신호(다운로드·리뷰)가 없어서 그 사이에 끼지 못한다.

**이건 예측 가능했다.** 출시 전 조사(2026-08-25)에 *"Fadeo가 Video와 형태가 비슷해 브랜드명 검색 시 비디오 앱들 사이에 묻힐 수 있다"*고 **리스크로 적혀 있었고**, 대응책(한글 표기를 이름·부제에 넣기)까지 나와 있었다. 그런데 실제 출시는 그 문서가 *"비추천"*이라고 표시한 5안(순수 브랜드명 `Fadeo`)으로 나갔다.

> **교훈: 조사 문서의 권고안과 실제 제출값이 어긋나지 않았는지 제출 직전에 대조한다.** 이름·부제·키워드는 조사할 때와 제출할 때 사이가 며칠씩 벌어져서 이런 일이 생긴다.

## 이름 짓기 전 체크 (iTunes Search API로 CLI에서 된다)

```bash
curl -s "https://itunes.apple.com/search?term=<이름>&country=kr&entity=software&limit=200" \
  | python3 -c "import sys,json; d=json.load(sys.stdin); print(d['resultCount']); [print(r['trackName']) for r in d['results'][:10]]"
```

1. **정확 일치가 있는가** — 있으면 ASC에서 "App Name already in use"로 막힌다.
2. **없을 때 무엇이 대신 나오는가 ★** — 이게 진짜 판정이다. 상위가 전부 무관한 대형 앱이면 **그 이름은 검색에서 그들과 싸워야 한다.** Fadeo는 여기서 이미 답이 나와 있었다.
3. **한글 표기도 따로 본다** — `페이디오` 검색 결과 1건(카카오페이지). 한글 브랜드 검색을 잡으려면 이름이나 부제에 한글 표기가 **실제로 들어가 있어야** 한다. 영문만 넣으면 한글로 치는 사람은 못 찾는다.

## 출시 후 진단 — "색인이 안 된 것"과 "순위가 낮은 것"은 다르다

`limit=200`으로 받아 자기 앱의 **위치**를 찾는다. Fadeo 실측(2026-09-02, 출시 이틀째):

| 검색어 | 순위 |
|---|---|
| 현상 카메라 | 21위 |
| 즉석사진 | 66위 |
| **Fadeo** (자기 이름) | **200위 밖** |
| 즉석카메라 · 필름카메라 · 일회용카메라 · 암실 | 200위 밖 |

읽는 법: **부제에 넣은 토큰(`현상`·`사진`)만 잡히고 이름 토큰은 아예 안 잡힌다** → 이름이 검색에서 일을 못 하고 있다는 뜻.
`10분 카메라`·`기다리는 카메라` 같은 **아무도 안 치는 조합**에서만 1위였다.

⚠️ iTunes Search API는 실제 App Store 검색과 **인덱스가 다르다**(통설). 순위 절대값을 믿지 말고 **상대 비교와 부재 판정**에만 쓴다. 최종 확인은 실기기 App Store 앱에서 직접 검색.

## 키워드 100자 — 검색어의 **시장**을 보고 넣는다

Fadeo 1.0은 100자 중 54자만 썼고, 그중 `인화`는 완전한 낭비였다.

**`인화`로 검색하면 나오는 것**: 찍스(리뷰 29,326) · 퍼블로그 · 스냅스 · 포토몬 — 전부 **사진을 실물로 출력해 배송하는 서비스**다. 카메라 앱이 이 목록에 낄 자리가 없고, 낀다 해도 그 사람들이 원하는 건 인화 주문이지 카메라가 아니다.

**규칙: 키워드를 넣기 전에 그 검색어로 실제 검색해서 상위 10개가 무슨 앱인지 본다.** 단어의 사전적 의미가 아니라 **그 검색어가 속한 시장**이 기준이다.

반대로 상위가 약체면 파고들 자리다 — Fadeo 실측에서 `일회용카메라`(상위가 리뷰 0~28), `암실`(전체 결과 33개), `현상 카메라`(1위가 2019년작 리뷰 28)가 그런 자리였다.

## 이름·부제 역할 분담

차트 상위 앱들이 전부 같은 구조다 (`GIKA 기카 - 독보적인 올드폰 감성 카메라`).

- **이름** = 브랜드 + **최대 트래픽 키워드**. `즉석 필름 카메라`처럼 붙이면 토크나이징으로 `즉석카메라`·`필름카메라` 둘 다 커버된다.
- **부제** = **차별화 키워드**. 이름이 못 담은 것.
- **키워드 필드** = 이름·부제에 **안 쓴 말만**. 중복은 낭비다.

지역별로 따로 넣을 수 있고 **둘 다 검색에 색인된다.**
