# 앱 내 계정 삭제 요건

계정 생성이 있는 앱은 **앱 안에서 계정 삭제를 시작할 수 있어야** 심사를 통과하고(2022-06-30부터), **Sign in with Apple을 쓰면 삭제 시 Sign in with Apple REST API로 토큰을 해지해야** 한다. 서버 탈퇴 API만 만들고 애플 토큰 해지를 빠뜨리면 심사 요건 미충족이다.

## 핵심 정리

- **계정 삭제 진입점은 앱 안에** — 웹으로 보내거나 고객센터 문의로 대체하면 안 된다. 삭제는 "개발자 기록에서 계정과 관련 데이터를 지우는 것"이고, **법적으로 보관해야 하는 데이터는 예외**(단, 그 사실을 사용자에게 알려야 한다)
- **Sign in with Apple 토큰 해지** — 원문: *"Apps that support Sign in with Apple should use the Sign in with Apple REST API to revoke user tokens."* 서버가 `POST https://appleid.apple.com/auth/revoke`(client_secret + refresh 또는 access 토큰)를 호출해야 하므로, **서버가 애플 refresh 토큰을 보관하고 있어야** 해지가 가능하다 — ID 토큰만 검증하는 구조(보험찾개냥 `OidcSocialTokenVerifier`)에서는 해지할 토큰 자체가 없다. 탈퇴 티켓과 별도로 **인가 코드 교환·토큰 보관** 설계가 선행돼야 한다
- 카카오는 별도 unlink API(`POST /v1/user/unlink`, admin key 또는 사용자 토큰)가 있고 심사 요건은 아니다 — 서비스 정책 문제

## 기록

### 2026-09-04 — 보험찾개냥 회원 탈퇴 API(SSH-446) spec에서
- 맥락: 소프트웨어마에스트로 SSH-446 티켓 「범위 밖」에 *"애플은 토큰 해지 의무가 있는지 확인 필요"*가 있어 확인
- 배운 것: 위 요건은 Apple 지원 문서 「Offering account deletion in your app」에 명시. 계정 삭제 자체는 2022-06-30 이후 제출 앱 필수, 토큰 해지는 "should" 표현이지만 심사 가이드라인 5.1.1(v)과 묶여 실질 요건으로 취급된다
- 근거: https://developer.apple.com/support/offering-account-deletion-in-your-app/ (2026-09-04 확인) · 제품 레포 `docs/spec/SSH-446/spec.md` 「범위 밖」
