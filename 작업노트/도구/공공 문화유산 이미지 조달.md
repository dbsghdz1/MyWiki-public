# 공공 문화유산 이미지 조달

한국 문화유산·유물·인물 사진을 **상업 앱에 쓸 수 있는 라이선스로** 찾는 경로와 각 소스의 실제 동작. 한능검 사진 선지 복원 스파이크(2026-09-01)에서 확인.

## 핵심 정리

- **시험지·교재의 사진은 제3자 저작물** — 국편 자료실 고지 "사진 등의 저작권은 원저작자에게 있습니다". 같은 유물의 **다른 사진**을 조달하는 게 경로다.
- **국가유산청은 기본 공공누리 1유형**(출처표시만, 상업·변경 가능). 국립중앙박물관 museum.go.kr 소장품 페이지도 확인한 5건 전부 1유형. e뮤지엄은 소장품별로 다르니 개별 확인.
- **표준영정은 자유이용이 아니다** — 저작권이 화가·유족에게 있고 사용에 상속인 허락 필요(현충사 법률자문, YTN 2023-01-29). 이이(7호 김은호)·정도전(54호 권오창)처럼 표준영정만 있는 인물은 초상 자체를 포기해야 한다. 조선시대 원본 초상(국보 송시열·보물 정몽주·채제공)과 승려 진영은 PD/1유형.
- **Wikimedia Commons가 가장 넓다** — 한국 문화유산이 CC0·CC BY(-SA)·KOGL 1·PD로 다수. `extmetadata.LicenseShortName`로 라이선스를 기계로 읽을 수 있다. "Public domain" 표기는 2D 회화 복제(PD-Art) 기준이라 입체 유물 사진엔 촬영자 라이선스가 따로 붙는다.

## 기록

### 2026-09-02 — 107문항·475선지 실제 조달: Commons 429는 UA 단위, 재검색 캐시 함정

- 맥락: 한능검 사진 선지 복원 본작업. 조달 에이전트 6개(Sonnet)가 `tools/photos_fetch.py`로 동시에 Commons를 호출.
- 배운 것:
  1. **429 버킷은 UA 문자열(+IP) 단위다.** 폭주한 UA는 호출을 멈춰도 한참 429가 계속됐고, 같은 IP에서 UA만 바꾸니 즉시 200. 해법: UA 교체 + **프로세스 공통 파일 잠금 스로틀**(`fcntl.flock` + 마지막 호출 시각 파일, 간격 2.5초)로 여러 에이전트의 호출을 직렬화. 에이전트에게 "천천히 하라"고 말하는 건 안 통한다 — 스크립트가 강제해야 한다.
  2. **Commons 검색은 한글 여러 단어 구문에 0건** — "월정사 석탑"→0, "월정사"→4, "Woljeongsa pagoda"→4. 한글은 한 단어씩, 영문은 구문으로.
  3. **후보 썸네일 캐시 함정**: 같은 슬롯 폴더에 다른 검색어로 재검색하면 인덱스가 같은 옛 파일이 남아 JSON 라벨과 사진이 어긋난다(에이전트 3조가 각각 발견). 검색 시 폴더를 비우도록 고쳤고, 마무리 단계는 로컬 썸네일을 버리고 **선택된 파일명으로 Commons에서 다시 받으며 라이선스를 재검증**한다.
  4. 에이전트 판정 규칙에 구멍이 있었다: 국보로 특정된 유물에 "동종 대체"(MET 소장 비슷한 매병), 지하철역 화강암 모작을 "기마인물형토기"로, 무유 복제품을 "녹유 치미"로 고른 사례 — note에 동종·복제·모작이 있으면 마무리에서 이름 카드로 되돌리는 규칙을 넣었다. **에이전트의 보고 note가 곧 필터 입력이다.**
  5. 배경 실행·타이머 대기를 시작한 서브에이전트는 알림 없이 멈춘다(3건) — 조달 프롬프트에 "반드시 포그라운드" 명시.
- 근거: `tools/photos_fetch.py`(throttled·UA·rmtree), `tools/photos_finalize.py`(fresh_from_commons·동종/복제 규칙), `photos/picks/*.json` note 필드.

### 2026-09-01 — 한능검 사진 선지 12문항·55선지 스파이크

- 맥락: [[프로젝트/개인/한능검/사진 선지 복원 스파이크 2026-09-01|스파이크 노트]]. 적중 73%(대체 포함 82%).
- 배운 것:
  1. **국가유산포털 사진 목록은 비공개 AJAX** — `POST https://www.heritage.go.kr/heri/cul/selectCulImageList.do` `ccbaCpno=<13자리>` → JSON(`imageUrl`, `desc`, `open`). `ccbaCpno` = 종목코드2 + "1" + 시도코드2 + 지정번호8 (국보 18호 경북 → `1113700180000`). `open` A/D 코드의 유형 매핑은 브라우저에서 확정 필요(A=1유형 추정). 공식 Open API `SearchKindOpenapiDt.do`는 사진 1장·공공누리 필드 없음.
  2. **e뮤지엄 유물정보 API**: data.go.kr/data/15104964 (약 115,764건, 키 필요). 소장품별 공공누리 유형 표시.
  3. **Commons MediaWiki API**: `list=search` + `prop=imageinfo&iiprop=extmetadata` — UA 헤더 없이 연속 호출하면 429. UA 지정 + 2초 간격.
  4. 막히는 유형: 표준영정 인물, 해외 소장 입체 유물(발해 이불병좌상·도쿄대), 사립 박물관(간송) — 사립·해외는 동종 유물(MET CC0 등)로 대체 가능한 경우가 많다.
- 근거: 세션 스크래치 `spike/` 렌더 12장, 확인 URL — khs.go.kr 저작권정책(`/html/HtmlPage.do?pg=/guide/copyright.jsp`), emuseum.go.kr/m/copyright, museum.go.kr relicId 1200·1210·372·7276·2258.
