# 한국 지도 API 선택

한국에서 웹·앱에 지도를 붙일 때 어느 API를 쓸지. **2026-09-05 기준 네이버는 신규 진입이 막혀 있다** — 이걸 모르고 설계하면 착수 후에 갈아엎는다.

## 핵심 정리

| API | 신규 사용 | 무료 한도 | 비고 |
|---|---|---|---|
| **네이버 지도** | **불가** | — | 신규 신청 **2025-05-22 종료**, 무료 혜택 **2025-07-01 종료**. 기존 이용자만 유지 |
| **카카오맵** | 가능 | 지도 **일 30만(법인)·20만(개인)** · 로컬 API 일 10만 · 전체 월 300만 | **2026-07-21 정책 변경** — 개발자 계정에서 **첫 번째로 활성화한 앱**에만 무료 쿼터가 붙는다. 초과 시 비즈월렛 연결 후 유료 |
| **VWorld** (국토교통부) | 가능 | 무료 | 2D 지도(OpenLayers 기반)·WebGL 3D·Static Map·지오코더·벡터맵. Static Map은 현재 요청 제한 없음(변경 가능), **지오코더는 일일 한도가 있어 초과 시 증액 신청** |
| 구글 지도 | 길찾기 제한 | 유료 | 한국은 측량성과 국외반출 제한으로 길찾기가 막혀 있었고, **2026-02-27 정부가 1:5000 고정밀 지도의 조건부 반출을 허가**했다(보안시설 블러·좌표 제한·국내 서버). 길찾기 서비스 시점은 미정 |

- **개인 사이드 프로젝트의 기본값은 카카오맵**이다. 개인 일 20만 건이면 어지간한 규모에서 안 넘친다.
- **카카오 무료 쿼터는 계정이 아니라 "첫 활성화 앱" 단위**다(2026-07-21~). 앱을 여러 개 만들면 두 번째부터는 무료가 아니다 — 프로젝트마다 앱을 새로 파기 전에 확인한다.
- **공공 성격이거나 쿼터가 걱정되면 VWorld**. 국토부 운영이라 무료이고, 행정경계·지적 같은 공공 레이어를 같이 쓸 수 있다.
- **카카오맵은 베이스맵 스타일을 바꿀 수 없다.** Mapbox·Google의 custom style 같은 API가 웹 SDK에 없다 — `MapTypeId`로 기본/스카이뷰/하이브리드 전환과 지형·교통 오버레이뿐이다. **즉 지도 톤을 제품 팔레트에 맞추는 디자인은 카카오맵에서 성립하지 않는다.** 톤을 반드시 맞춰야 하면 VWorld 벡터맵이나 자체 타일로 가야 한다.
- **kakao 로고와 축척바는 지울 수 없고 위치만 고른다** — `setCopyrightPosition`·`CopyrightPosition`. 화면 네 구석 중 한 곳은 카카오에게 내줘야 하므로, 우리 UI(축척바·푸터 링크·줌 컨트롤)를 그 구석에 두면 겹친다. **우리가 축척바를 직접 그리면 두 개가 나란히 뜬다.**
- **상호 라벨과 POI 아이콘은 타일 그 자체라 끌 수 없다.** 관악구 기본 지도는 화면당 상호 라벨이 수백 개, 오렌지 POI 아이콘이 촘촘하다. **그 위에 반투명 흰 pill 핀을 얹으면 사라진다** — 핀은 불투명 배경 + 테두리 + 그림자로 가야 한다. 지하철 2호선이 굵은 초록 띠라 초록 핀과도 헷갈린다.
- **`MarkerClusterer`는 `Marker` 대상이다.** HTML `CustomOverlay`로 만든 pill 핀에는 클러스터링이 안 붙는다(문서에 CustomOverlay 지원 명시 없음 — 실측 필요). 약국 200곳대를 줌아웃하면 핀이 서로 겹치므로 **줌 레벨별로 핀 모양을 갈아끼우는 설계가 필요하다.**
- **지도 라이브러리는 전부 브라우저 전용이다.** `window`·DOM이 없는 서버에서 초기화가 터지므로 SSR에서는 클라이언트 전용 경계로 분리해야 한다.

## 기록

### 2026-09-05 — 약국맵 착수 전 지도 API를 고르며

- 맥락: [[프로젝트/개인/약국맵/README|약국맵]] 착수. 지도가 제품의 본체라 코드 전에 API부터 확인했다.
- 배운 것:
  - **네이버 지도 API는 신규로 못 쓴다.** 2025-05-22 신규 신청 종료, 2025-07-01 무료 혜택 종료. 한국 지도 = 네이버라는 기본 가정이 이제 틀리다.
  - 카카오맵 무료 쿼터는 넉넉하지만(개인 일 20만) **2026-07-21부터 "첫 활성화 앱"에만 붙는다.**
  - VWorld가 무료 대안이고 공공 레이어까지 준다.
  - 착수 전 30분 확인으로 설계를 바꿨다 — 이 확인을 코드 뒤로 미뤘으면 지도 레이어를 통째로 갈아야 했다.
- 근거: 네이버 클라우드 플랫폼 공지(지도 API 신규 이용 신청 차단 및 무료 혜택 종료), 카카오 데브톡·카카오 공지, 공공데이터포털 국토교통부 2D 지도·Static Map API 페이지 (전부 2026-09-05 확인)

### 2026-09-16 — 카카오맵 실물 위에서 디자인 시안을 판정하며 (약국맵)

- 맥락: [[프로젝트/개인/약국맵/README|약국맵]] Figma 시안(v1)이 **손으로 그린 크림·연초록 지도 일러스트** 위에서 설계돼 있었다. 실제 베이스맵이 카카오맵이 되면 배경 조건이 달라지므로, `map.kakao.com` 「서울대입구역 약국」을 캡처해 v1 패널·핀·범례를 **원래 좌표 그대로 합성**해 눈으로 판정했다.
- 배운 것:
  - **카카오 기본 지도는 노란 건물 블록이 배경을 지배한다.** v1의 초록 패널·핀은 그 노랑과 명도·채도가 갈려서 **오히려 더 또렷해졌다** — 색은 살았다. 깨진 건 색이 아니라 **불투명도**다.
  - **반투명 흰 pill 핀은 실물에서 사라진다.** 상호 라벨 + 노란 블록 위에서 윤곽이 죽는다. 불투명 채움 + 1px 테두리 + 그림자로 바꾸니 읽혔다. 하단 중앙 유리 범례도 같은 이유로 먹혔다.
  - **카카오맵 웹사이트 UI와 SDK가 그리는 것을 구분해야 한다.** 캡처에 섞여 온 파란 물방울 A~N 마커·우측 컨트롤 스택·「이 지역 재검색」·좌측 검색 패널은 **웹사이트 UI라 우리 화면엔 없다.** 타일 자체(노란 블록·상호 라벨·오렌지 POI 아이콘·2호선 초록 띠·kakao 로고+축척바)만 SDK에도 그대로 나온다. 이걸 뭉개면 시안을 과하게 고치게 된다.
  - **곁가지로 제품 판정이 하나 나왔다.** 「서울대입구역 약국」 검색에 **카카오가 이미 약국 162곳을 지도에 찍어준다**(파란 A~N 마커). README가 인정한 「기능은 같다」가 화면으로 확인됐고, 그래서 차별점인 「확인됨」 배지를 v1보다 세게 밀어야 한다는 근거가 됐다.
  - 웹사이트 크롬을 CSS로 숨겨 타일만 캡처하려 했으나, `#view.mapContainer`의 형제·자식을 지우는 방식은 **타일 캔버스까지 같이 죽여 빈 화면**이 됐다. 크롬이 프레임 밖으로 나가게 **잘라내는 쪽이 싸다**.
- 근거: Figma `MyCryptoDiary` 파일 섹션 「약국맵 v2 — 카카오맵 대응 · 3D 아이콘」(판정 합성 이미지 2장·핀 시스템 3단) / 캡처 2026-09-16 `map.kakao.com/?q=서울대입구역 약국` / 카카오맵 웹 SDK 문서 `apis.map.kakao.com/web/documentation/`의 `setCopyrightPosition`·`MapTypeId`·`MarkerClusterer`·`CustomOverlay` 항목 (2026-09-16 확인, 상세 파라미터는 JS 렌더라 WebFetch로 못 읽음)
