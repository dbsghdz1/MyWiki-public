# 한국 지도 API 선택

한국에서 웹·앱에 지도를 붙일 때 어느 API를 쓸지. **2026-09-05 기준 네이버는 신규 진입이 막혀 있다** — 이걸 모르고 설계하면 착수 후에 갈아엎는다.

## 핵심 정리

| API | 신규 사용 | 무료 한도 | 비고 |
|---|---|---|---|
| **네이버 지도** | **불가** | — | 신규 신청 **2025-05-22 종료**, 무료 혜택 **2025-07-01 종료**. 기존 이용자만 유지 |
| **카카오맵** | 가능 | 지도 **일 30만(법인)·20만(개인)** · 로컬 API 일 10만 · 전체 월 300만 | **2026-07-21 정책 변경** — 개발자 계정에서 **첫 번째로 활성화한 앱**에만 무료 쿼터가 붙는다. 초과 시 비즈월렛 연결 후 유료 |
| **VWorld** (국토교통부) | 가능 | 무료 | 2D 지도(OpenLayers 기반)·WebGL 3D·Static Map·지오코더·벡터맵. Static Map은 현재 요청 제한 없음(변경 가능), **지오코더는 일일 한도가 있어 초과 시 증액 신청** |
| 구글 지도 | 길찾기 제한 | 유료 | 한국은 측량성과 국외반출 제한으로 길찾기가 막혀 있었고, **2026-02-27 정부가 1:5000 고정밀 지도의 조건부 반출을 허가**했다(보안시설 블러·좌표 제한·국내 서버). 길찾기 서비스 시점은 미정 |

- **개인 사이드 프로젝트의 기본값은 카카오맵**이다. 개인 일 20만 건이면 어지간한 규모에서 안 넘친다.
- **카카오 무료 쿼터는 계정이 아니라 "첫 활성화 앱" 단위**다(2026-07-21~). 앱을 여러 개 만들면 두 번째부터는 무료가 아니다 — 프로젝트마다 앱을 새로 파기 전에 확인한다.
- **공공 성격이거나 쿼터가 걱정되면 VWorld**. 국토부 운영이라 무료이고, 행정경계·지적 같은 공공 레이어를 같이 쓸 수 있다.
- **지도 라이브러리는 전부 브라우저 전용이다.** `window`·DOM이 없는 서버에서 초기화가 터지므로 SSR에서는 클라이언트 전용 경계로 분리해야 한다.

## 기록

### 2026-09-05 — 약국맵 착수 전 지도 API를 고르며

- 맥락: [[프로젝트/개인/약국맵/README|약국맵]] 착수. 지도가 제품의 본체라 코드 전에 API부터 확인했다.
- 배운 것:
  - **네이버 지도 API는 신규로 못 쓴다.** 2025-05-22 신규 신청 종료, 2025-07-01 무료 혜택 종료. 한국 지도 = 네이버라는 기본 가정이 이제 틀리다.
  - 카카오맵 무료 쿼터는 넉넉하지만(개인 일 20만) **2026-07-21부터 "첫 활성화 앱"에만 붙는다.**
  - VWorld가 무료 대안이고 공공 레이어까지 준다.
  - 착수 전 30분 확인으로 설계를 바꿨다 — 이 확인을 코드 뒤로 미뤘으면 지도 레이어를 통째로 갈아야 했다.
- 근거: 네이버 클라우드 플랫폼 공지(지도 API 신규 이용 신청 차단 및 무료 혜택 종료), 카카오 데브톡·카카오 공지, 공공데이터포털 국토교통부 2D 지도·Static Map API 페이지 (전부 2026-09-05 확인)
