# 앱인토스 미니앱

기존 Vite+React 웹을 토스 앱 안 미니앱으로 내는 절차와, 공식 문서가 안 알려주는 것들. 문서 진입점은 `https://developers-apps-in-toss.toss.im/llms.txt`(전체 목록) — 개별 `.html` 주소는 404가 잦고 **`.md` 주소가 산다**(예: `/documentation/common/monetization/iap/in-app-purchase.md`).

## 핵심 정리

- **패키지**: `@apps-in-toss/web-framework`(3.7.0, 2026-10-01). 설치하면 `npx ait` CLI(`@apps-in-toss/cli`)가 따라온다. 명령은 `ait build`(→ `<appName>.ait` 번들 + deploymentId) · `ait token add` · `ait deploy [--profile]` · `ait migrate`(2.x→3.x). **React 19에서도 설치·빌드된다**(peerDependencies 없음). 문서의 `@toss/tds-mobile`은 react 18 peer라 안 깔았다 — 미니앱 내비바는 토스 컨테이너가 그리므로 TDS 없이도 된다.
- **설정 파일 이름**: 문서는 `granite.config.ts`라고 하는데 CLI 3.x는 `apps-in-toss.config.ts`를 우선 읽는다(둘 다 인식, CLI 소스에 두 이름 공존). `defineConfig`는 `@apps-in-toss/web-framework/config`에서. 필드: `appName`(딥링크 `intoss://<appName>`·콘솔 이름과 일치) · `brand.primaryColor` · `permissions: []` · `navigationBar{withBackButton,withHomeButton,withTitle,theme}` · `webView{bounces,pullToRefreshEnabled,…}` · `webBundleDir`(vite `dist`).
- **토스 안인지 판별**: SDK가 `window.ReactNativeWebView`·`window.__appsInToss`(`__appsInTossConstants`)를 본다. 일반 브라우저에는 브리지가 없어 모든 네이티브 API가 실패하므로 **이 둘 유무로 분기**하고 바깥 경로를 따로 둔다.
- **인앱결제(IAP)**: `import { IAP } from '@apps-in-toss/web-framework'`. `IAP.createOneTimePurchaseOrder({ options: { sku, processProductGrant: ({orderId}) => boolean }, onEvent: ({type:'success', data:{orderId,…}}) => …, onError })` — **반환값이 cleanup 함수이고 흐름이 끝나면 반드시 호출**. `productId`는 deprecated, `sku`를 쓴다. 지급 완료 보고는 `IAP.completeProductGrant({ params: { orderId } })`. 복원은 `IAP.getPendingOrders()`(결제됐는데 지급 안 된 것)와 `IAP.getCompletedOrRefundedOrders()`(status `COMPLETED|REFUNDED`, 페이지네이션 `hasNext/nextKey`). 각 함수에 `isSupported()`와 `MIN_TOSS_APP_VERSION`(5.219~5.233)이 붙어 있다. 서버 검증은 `POST https://apps-in-toss-api.toss.im/api-partner/v1/apps-in-toss/order/get-order-status`(mTLS 인증서 필요).
- **수수료·가격**: 앱마켓 15% + 토스 5% = **20%**. 상품은 콘솔에서 등록 — 비소모성/소모성/구독, **공급가 400~1,400,000원(10원 단위)**, 판매가 = 공급가 + VAT 자동. 비게임 미니앱은 상품 30개 한도. 1024×1024 상품 이미지 필수. 실물·서비스는 토스페이(`checkoutPayment`), 디지털 콘텐츠·권한은 IAP.
- **검수 요건(비게임)** 중 걸리기 쉬운 것: **라이트 테마 구현 필수**, 진입 즉시 바텀시트 금지, 외부 도메인으로 리다이렉트·외부 콘텐츠 렌더 금지, **CSR·SSG만(SSR 불가)**, `eval` 금지, 제스처 줌 비활성(`user-scalable=no`), 자체 서비스 홍보·앱 설치 링크 금지(→ 토스 안에서는 App Store 링크를 숨겼다), UX 카피는 해요체. 사업자 정보 + 정산 정보 등록 검토 2~3영업일, 앱 검수 2~3영업일.
- **테스트**: 샌드박스 앱(iOS 시뮬레이터 드래그 설치 / Android APK)에서 `intoss://<appName>` 입력. IAP는 샌드박스에서 과금 없이 되고, 검수에 ①정상 구매 ②성공-지급 실패-복원 ③오류 처리 세 시나리오를 요구한다.

- **콘솔 MCP가 있다** (2026-10-02 확인): 공식 플러그인 `toss/apps-in-toss-harness` — `claude plugin marketplace add toss/apps-in-toss-harness` → `claude plugin install ait@apps-in-toss` → 세션에서 `/mcp`로 `apps-in-toss-console` OAuth. 문서 검색·미니앱 생성·**콘솔 등록·배포 준비·정책 점검**을 AI가 한다. 플러그인은 세션 시작 때 로드되므로 설치 뒤 새 세션. 수동 연결은 `claude mcp add --transport http apps-in-toss-console https://mcp.toss.im/adapters/apps-in-toss-console/mcp --client-id mcp-gateway`.
