# historyexam 자료실 수집

한국사능력검정시험 기출 PDF는 `historyexam.go.kr` 자료실에서 스크립트로 받을 수 있다. **최근 회차만 보관하고 옛 글은 서버에서 완전히 삭제**되므로, 새 회차가 뜨면 즉시 받아야 한다.

## 기록

### 2026-08-30 — 기본 14회차 28개 PDF 수집 (한능검)

맥락: [[프로젝트/개인/한능검/기본 기출 수집 2026-08-29|한능검 기본 기출 수집]]. 근거: `(로컬 경로)`에 실제 수신·검증한 절차.

- **목록**: `GET https://www.historyexam.go.kr/pst/list.do?bbs=dat&pageIndex=1..4`. 게시글은 `fn_goDetail('<글ID>','BBS0003')` 패턴으로 HTML에 박혀 있다. 2026-08 시점 총 37건 = 심화 57~79회 + 기본 14회(57·58·60·61·63·64·66·67·69·71·73·75·77·79 — **기본은 일부 회차만 시행**).
- **상세**: `POST /pst/view.do?bbs=dat`, body `pst_sno=<글ID>`. GET `view.do?id=...`은 ERROR 페이지가 나온다 — 반드시 POST. 페이지 안 `fnFileDownload('B_YYYYMMDDhhmmss...')`가 파일 ID.
- **다운로드**: `GET /atchFile/FileDown.do?atch_file_id=<파일ID>` 로 바로 PDF가 온다. 브라우저 UI의 NetFunnel(대기열)은 curl 직접 요청에는 안 걸렸다. 회차당 문제지 5~27MB, 답지 26~70KB. 수신 후 `%PDF-` 매직 바이트로 검증했다.
- **옛 글은 ID로도 못 연다**: 57회 심화가 글 ID `1000029845`(목록 최저)인데, `1000029700~844`를 전수 POST 프로브 → 전부 제목 없는 빈 페이지. **"최근 15개 회차" 운영으로 지운다.** 웨이백 CDX에도 `FileDown.do` 캡처가 9건뿐이라 삭제분 복원 불가. 공공데이터포털 15119618도 자료실 안내일 뿐.
- **80회(2026-10 시행) 대비**: 시행 후 목록 1페이지에서 새 글 ID 파싱 → 위 절차 그대로. **이때 57회가 목록에서 밀려날 가능성이 높으니 미보유분이 있으면 먼저 확인.**
- 파이프라인 쪽: `build.py`가 선지 수 4번째 인자를 받는다(기본 시험 4지선다 → `4`), `merge.py`가 베이스 폴더·수준 인자를 받는다(`merge.py ../기본 기본`). 답지 파서는 기본에서도 무수정으로 14회차 정답 700/700 매칭.
