## 기록

### 2026-09-10 — iTunes Search API로 30초 미리듣기를 인증 없이 받을 수 있다 (단, 한국 스토어는 음악을 안 판다)

- 맥락: 개인용 페이지에 배경음악을 넣어야 했는데 음원 파일이 없었다. 스트리밍 전곡은 전부 DRM이라 가져올 수 없다
- 배운 것:
  - `https://itunes.apple.com/search?term=<검색어>&country=US&media=music&entity=song&limit=25` — **인증·토큰 없이** JSON을 준다. 각 결과의 `previewUrl` 은 **30초 m4a(AAC ~277kbps)** 직링크이고 그대로 `curl` 로 받아진다. `trackTimeMillis` 로 전곡 길이도 알 수 있다
  - **`country=KR` 로 조회하면 `resultCount: 0` 이 나온다 — 한국 iTunes Store는 음악을 판매하지 않기 때문**이다(앱·영화는 판매). 한국 아티스트도 `country=US` 나 `JP` 로 조회해야 나오고, 검색어는 로마자 표기(`hanroro`, `Lee Sora`)나 영문 트랙명이 잘 맞는다. 한글 곡명은 URL 인코딩해서 넣으면 걸리기도 한다
  - **미리듣기 구간은 고를 수 없다.** 애플이 미리 잘라 만든 파일 하나뿐이라 시작 지점을 지정하는 파라미터가 없다. 원하는 구간을 쓰려면 전곡 파일이 있어야 한다
  - 30초를 반복 재생할 거면 **앞뒤에 페이드를 넣어야** 이음새가 튀지 않는다: `ffmpeg -af "afade=t=in:st=0:d=1.2,afade=t=out:st=28.4:d=1.6"`
- 곁가지: 여러 곡을 순서대로 돌리려면 `<audio>` 를 곡 수만큼 두고 `ended` 이벤트에서 다음 것을 재생하면 된다. 모바일은 **사용자 제스처 없이는 재생이 막히므로**, 페이지의 첫 탭에서 시작시키는 구조로 만든다

### 2026-09-10 — 가로 영상을 세로 배경으로 쓸 땐 미리 잘라서 인코딩한다

- 맥락: 1920×1080 영상을 세로 화면 전체 배경(`object-fit: cover`)으로 깔았더니 뭉개졌다. 처음엔 480px로 인코딩한 게 원인인 줄 알았다
- 배운 것:
  - **`object-fit: cover` 는 어차피 가운데만 남기고 좌우를 버린다.** 원본 비율 그대로 인코딩하면 **버려질 영역에 비트레이트를 쓰는 셈**이라, 정작 보이는 부분의 실효 해상도가 크게 낮아진다
  - ffmpeg에서 표시될 영역만 먼저 잘라내면 같은 용량으로 실효 해상도가 3배 이상 올라간다. CSS가 하는 크롭과 동일하므로 **구도가 추가로 손실되지 않는다**:
    ```
    ffmpeg -i in.MOV -an -vf "crop=ih*9/16:ih,scale=720:1280:flags=lanczos,fps=30" \
           -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 27 -movflags +faststart out.mp4
    ```
  - **어두운 막(scrim) 아래 깔리는 배경 영상은 crf를 높여도 티가 안 난다** — 해상도(업스케일 여부)가 체감 화질을 지배하고 압축률은 거의 안 보인다. 용량은 crf로, 선명도는 해상도로 잡는다
  - 큰 배경 영상에 `preload="auto"` 를 걸어두면 **첫 화면에서 이미지 로딩과 대역폭을 다툰다.** `preload="none"` 으로 두고 필요한 시점 직전에 `video.preload='auto'; video.load()` 로 당겨 받는다

### 2026-09-02 — Kotlin `is` 접두사 Boolean은 JSON 필드명이 조용히 갈릴 수 있는 자리다

- 맥락: 보험찾개냥 SSH-444/441 — 로그인 응답에 `isOnboarded: Boolean`을 더했다. 계약이 요구하는 필드명은 `isOnboarded`인데, 순수 Java Bean 규칙이라면 getter `isOnboarded()`에서 `is`가 잘려 **`onboarded`로 나갈 수 있는** 이름이다
- 실측: 이 프로젝트(Spring Boot + jackson-module-kotlin)는 **`isOnboarded` 그대로 직렬화된다** — 코틀린 생성자 파라미터 이름을 쓰기 때문이다. 앱 쪽도 `json['isOnboarded']`로 그대로 읽혔다
- **그래서 테스트로 못박았다** — `jsonPath("$.isOnboarded")`. 필드명이 계약인데 프레임워크 규칙 하나로 바뀔 수 있는 자리면, "지금 되니까"로 두지 말고 이름 자체를 단언한다. 모듈 구성이 바뀌는 날 조용히 앱만 깨진다
- 곁가지: 같은 이유로 **`is` 접두사 Boolean은 계약 필드명으로 뽑기 전에 한 번 확인할 값**이다 (Swift·Dart에는 이 규칙이 없어 스택마다 다르게 나온다)

### 2026-08-26 — Flutter 안드로이드 빌드가 Homebrew 최신 JDK를 집어 Gradle이 죽는다

- 맥락: 소프트웨어마에스트로 SSH-290 스크린샷을 안드로이드 에뮬레이터에서 찍으려다 `assembleDebug`가 `Unsupported class file major version 70`으로 죽었다.
- 배운 것:
  - Flutter는 JDK를 `java_home` 순서로 집는다 — 이 맥은 Homebrew OpenJDK **26**(class file 70)뿐이라 프로젝트 Gradle이 못 읽는다. CI는 자기 JDK라 통과하고 **로컬 안드로이드 빌드만 죽는** 모양이 된다.
  - 해법은 레포가 아니라 머신 설정이다: `flutter config --jdk-dir=<flutter-env의 jdk>/Contents/Home` — flutter-env 설치본에 Temurin **21**이 이미 번들돼 있었다.
  - AVD가 하나도 없었다 — `avdmanager create avd -n pixel_ssh -k "system-images;android-36;google_apis;arm64-v8a" -d pixel_7`로 만들었고, 부팅 판정은 `adb shell getprop sys.boot_completed`이 `1`이 될 때까지 폴링.
  - **adb는 simctl과 달리 입력이 된다** — `adb shell input swipe/tap`. iOS는 캡처만, 안드로이드는 스크롤·탭까지 자동화할 수 있다.
- 근거: 2026-08-26 실측, `/tmp/shot-android.log`의 Gradle Flutter Fix 안내.

### 2026-08-26 — Dart의 `?? []`가 for-in에서 요소를 dynamic으로 만든다

- 맥락: 소프트웨어마에스트로 SSH-290 Mapper에서 `for (final item in documents ?? []) item.toDomainOrNull()`이 **컴파일은 되는데 런타임에 `NoSuchMethodError`**로 죽었다. `toDomainOrNull()`은 확장 함수다.
- 배운 것:
  - `documents`가 `List<T>?`여도 `?? []`의 빈 리터럴이 **컨텍스트 타입을 못 받아 `List<dynamic>`으로 추론**되고, 합쳐진 식 전체가 `List<dynamic>`이 된다. for-in 변수도 `dynamic`.
  - **확장 함수는 정적 디스패치라 `dynamic` 수신자에서 조용히 사라진다** — 컴파일러가 못 잡고 런타임 `NoSuchMethodError`가 난다. 일반 메서드였으면 동적 호출로 동작했을 자리라, **확장 함수 + `?? []` 조합이 특히 위험**하다.
  - 고치는 법: `?? const <T>[]`로 타입을 명시하거나, null 검사를 먼저 해서 promotion을 받는다(우리는 후자 — 계약 위반 로그도 남겨야 해서).
- 근거: `ASMSSH/Boheomgaenyang` PR #81 `document_mapper.dart`, Mapper 테스트가 red로 잡았다.

### 2026-08-23 — 0.3초짜리 화면을 시뮬레이터에서 캡처하기

- 맥락: 소프트웨어마에스트로 진입 화면(SSH-326)이 세션을 읽는 동안만 보인다. PR 규칙이 스크린샷 3장을 요구하는데 **여덟 번 찍어도 전부 스플래시 아니면 도착지가 잡혔다.**
- 배운 것:
  - **`xcrun simctl io <dev> screenshot`은 한 장에 0.5초쯤 걸린다.** 그보다 짧게 스치는 화면은 이걸로 못 잡는다.
  - **`simctl io <dev> recordVideo` + `ffmpeg -vf fps=N`으로 프레임을 뽑는다.** 안드로이드는 `adb shell screenrecord` + `adb pull`.
  - **`recordVideo`는 화면이 바뀔 때만 프레임을 남긴다.** 정지 화면을 4초 녹화하면 `nb_frames=1`이다(`ffprobe`로 확인). 그래서 **스피너 한 바퀴 같은 작은 변화만 있는 구간은 이 방법으로도 못 잡는다.**
  - **어느 프레임이 무엇인지 구분할 표식이 필요하다.** Flutter는 debug 빌드에 `DEBUG` 배너를 그리므로, 배너가 없으면 네이티브 런치 이미지, 있으면 Flutter가 그린 화면이다. 이걸로 **네이티브 스플래시와 앱 첫 화면이 이어지는지**를 픽셀로 확인했다.
  - **`simctl`에는 탭 명령이 없다.** macOS `CGEventCreateMouseEvent`(osascript JXA)로 시뮬레이터 창을 클릭하는데, **`kCGEventMouseMoved`를 먼저 보내야** 클릭이 먹는다 — down/up만 보내면 조용히 무시된다.
- 근거: 보험찾개냥 PR #64, `docs/spec/SSH-326/`의 진입 화면 3장.

### 2026-08-23 — Jira는 Subtask ↔ 일반 이슈 전환을 편집 API로 막아 놨다

- 맥락: 팀 보드에 티켓이 안 보였다. 원인은 **Subtask는 보드에 카드로 뜨지 않는 것**이었고, 일반 「작업」으로 바꾸려 했다.
- 배운 것:
  - `PUT /issue/{key}`로 `issuetype`을 바꾸면 **거절된다.** 그런데 **같은 응답의 `allowedValues`에는 그 유형이 들어 있다** — 에러 메시지와 사실이 안 맞는다.
  - `parent`를 함께 넘기면 `"상위 이슈와 같은 프로젝트에 만들어야 합니다"`가 오는데, **같은 프로젝트가 맞다.** 이것도 사실과 안 맞는 메시지다.
  - 실제 이유는 **이 전환이 편집이 아니라 「이동(Move)」이라는 별도 동작**이고, 웹 UI에만 있어서다. **에러 메시지를 액면 그대로 디버깅하면 시간을 버린다.**
  - 부수적으로: 팀 관리형 프로젝트에서 **작업 밑에 작업을 둘 수 없다.** 부모는 에픽이어야 한다 — 그래서 전환은 부모 재지정을 동반한다.

### 2026-08-22 — 보안 저장소 라이브러리의 기본값이 데이터를 지운다

- 맥락: 보험찾개냥에서 로그인 세션을 `flutter_secure_storage` 에 넣으면서. "읽기에 실패해도 저장된 값을 지우지 않는다"를 코드와 테스트로 세워 놨는데, **라이브러리 기본값이 그걸 정반대로 뒤집고 있었다.**
- 배운 것:
  - **`AndroidOptions.resetOnError` 기본값이 `true` 다.** 네이티브 구현이 읽기에 실패하면 **그 키를 지우고 다시 읽어 `null` 을 성공처럼** 돌려준다. 즉 "일시적 실패 → 영구 삭제 → 값이 없었던 것처럼 보임"이 기본 동작이고, **예외도 로그도 안 남는다.**
  - **키체인 `accessibility` 기본값(`whenUnlocked`)은 암호화 백업을 타고 새 기기로 따라간다.** 세션 토큰처럼 "가진 사람이 곧 그 사람"인 값은 `..._this_device` 계열을 써야 기기 밖으로 안 나간다. iOS 키체인 항목은 **앱을 지워도 남는다**는 것도 함께 봐야 한다.
  - **일반화 — 가짜(fake)로 감싼 테스트는 기본값을 검증하지 못한다.** 저장소를 인터페이스 뒤로 숨기고 페이크로 테스트하면 옵션은 아무도 안 본다. 그래서 **옵션 값 자체를 단언하는 테스트**를 따로 뒀다(`storage.aOptions.toMap()['resetOnError'] == 'false'`). 상수를 지워도 컴파일과 나머지 테스트는 전부 초록이라서다.
- 근거: 보험찾개냥 PR #63 리뷰 2회차 P1 (`Client/lib/data/services/storage/session_store.dart`). 패키지 `flutter_secure_storage 10.3.1` 의 `lib/options/android_options.dart:80`, 네이티브 `handleStorageError`.

### 2026-08-22 — 안드로이드 매니페스트의 클래스 이름은 빌드가 검증하지 않는다

- 맥락: 같은 작업에서 카카오 로그인 리다이렉트용 액티비티를 `AndroidManifest.xml` 에 선언했는데, **SDK v2 에 없는 v1 시절 클래스 이름**을 적었다.
- 배운 것:
  - **`android:name` 이 존재하지 않는 클래스를 가리켜도 빌드는 성공한다.** 매니페스트는 컴파일 대상이 아니라 리소스라, `ClassNotFoundException` 은 **그 컴포넌트가 실제로 실행되는 순간** 런타임에 난다. 이번 경우엔 "로그인 창은 뜨는데 앱으로 안 돌아온다"로만 보인다.
  - **라이브러리가 이미 선언한 액티비티에는 intent-filter 만 얹는다.** 같은 `android:name` 으로 다시 선언하면 매니페스트 병합기가 속성을 합쳐 준다 — 라이브러리의 `launchMode`·테마가 유지된 채 우리 필터가 붙는다. 새로 선언해 덮어쓰려 하면 속성 충돌로 병합이 실패한다.
  - **검증은 병합 결과물에서 한다.** `build/app/intermediates/merged_manifests/**/AndroidManifest.xml` 을 열어 보면 최종 형태가 있다. 소스 매니페스트만 봐서는 라이브러리가 무엇을 넣었는지 모른다 — 이번엔 `<queries>` 를 중복 선언한 것도 여기서 드러났다.
- 근거: 보험찾개냥 PR #63 리뷰 1회차 P1 (`Client/android/app/src/main/AndroidManifest.xml`). 패키지 `kakao_flutter_sdk_auth 2.0.0+1` 의 `android/src/main/AndroidManifest.xml`.

### 2026-08-25 — 로그의 부재는 증거가 아니다 (로그 정책을 먼저 확인한다)

- 맥락: 보험찾개냥에서 앱 로그인이 실패해 서버 로그를 뒤졌는데 관련 줄이 **하나도 없었다.** "요청이 안 왔다"로 결론 내릴 뻔했다.
- 배운 것:
  - **4xx를 일부러 로그에 안 남기는 설계가 흔하다.** 전역 예외 핸들러가 `if (status.is5xxServerError) log.error(...)`로 가르면, 401은 조용히 나간다 — 4xx는 정상 흐름이라는 판단이고 타당하다. **그러면 "로그가 없다"가 "요청이 없었다"를 뜻하지 않는다.**
  - **앞단 프록시의 접근 로그도 기본이 꺼져 있을 수 있다.** 40분에 6줄뿐이면 그건 기동 로그지 트래픽 기록이 아니다. 그 부재 역시 증거가 못 된다.
  - **그래도 하나는 건졌다 — 5xx가 아니라는 것.** 5xx만 로그가 남는 설계라면, 로그가 비었다는 사실이 **"500은 아니다"를 증명한다.** 후보를 못 좁혀도 하나는 지울 수 있다.
  - **일반화 — 부재를 근거로 쓰기 전에 "그게 있었다면 정말 기록됐을까"를 먼저 확인한다.** 로그 레벨·필터·샘플링·접근 로그 설정 중 하나만 어긋나도 부재는 무의미해진다.
- 근거: `GlobalExceptionHandler.kt`의 `handleBusiness` — `if (e.status.is5xxServerError) log.error(...)`. Caddy 컨테이너 로그 40분간 6줄(전부 기동 로그)

### 2026-08-29 — 무인증 401로 끊기는 multipart POST는 클라에 Connection reset으로 보인다

- 맥락: 보험찾개냥 dev 실서버 E2E — 앱의 `POST /api/v1/treatment-records`(영수증 파일 동봉 multipart)가 2회 연속 `SocketException: Connection reset by peer (errno = 54)`. 같은 파일을 보낸 permitAll 경로 `POST /receipts/analyze`는 200.
- 배운 것:
  - 클라이언트가 `Authorization: Bearer`를 아예 안 붙이는 상태(부착은 SSH-326 후속 PR로 미구현)에서 **인증 필수 + multipart 업로드** 조합이면, 4xx 응답이 아니라 **TCP reset**으로 보인다. 서버(Spring Security)가 본문을 다 읽기 전에 401을 내고 커넥션을 닫는 것으로 추정 — 무인증 사실·2회 재현·permitAll 경로와의 대조는 실측이고, early-close 인과는 서버 로그로 확정하지 않았다.
  - **"Connection reset"에서 네트워크·프록시·keep-alive부터 파지 말고, 그 경로가 인증 필수인지·요청에 자격증명이 실리는지를 먼저 본다.** 특히 무인증 요청은 없는 경로도 404가 아니라 401로 끊기는 설계(SecurityConfig 기본 거부)라, 홈의 목록 실패도 404가 아니라 401이었다.
- 근거: flutter run 로그(`ApiClient: ✗ POST …/treatment-records (unknown)` × 2, `← 200 …/receipts/analyze`), `Server/…/auth/security/SecurityConfig.kt` permit 목록, `SessionTokenAuthFilter.kt`(Bearer 기대), `grep -rn "Bearer" Client/lib/data` 0건, `docs/spec/SSH-326/spec.md` 「인증 헤더·토큰 갱신은 이 PR이 아니다」

### 2026-09-09 — 로그인 없이 bootRun 실호출을 검증하는 법 (access 토큰 직접 서명)

- 맥락: 보험찾개냥 SSH-446 회원 탈퇴 API를 로컬 bootRun으로 실검증. 1-1 소셜 로그인은 진짜 카카오·애플 ID 토큰이 필요해서 탈 수 없다.
- 배운 것:
  - **세션 토큰은 HS256이고 서명 키가 `.env`의 `AUTH_SESSION_SECRET`이라, 스크립트에서 직접 만들 수 있다.** 클레임은 `sub`(userId 문자열) · `iss` · `iat` · `exp` · `jti` · **`token_use`(`access` / `refresh`)** — `token_use`가 없거나 값이 다르면 `NimbusSessionTokenIssuer.readAccess`가 `null`을 돌려 401이 된다(`typ`가 아니다).
  - **refresh는 원문이 아니라 SHA-256 hex 64자가 `refresh_tokens.token_hash`에 들어간다.** 직접 만든 refresh JWT로 `POST /api/v1/auth/refresh`를 검증하려면 그 해시로 행을 심어야 한다.
  - 나머지 데이터는 `docker compose exec -T mysql mysql …`로 직접 INSERT하는 것이 제일 빠르다. `LAST_INSERT_ID()`는 커넥션 단위라 다시 SELECT해서 ID를 잡는다.
  - **MySQL 다중 테이블 DELETE**: `DELETE h FROM claim_status_histories h JOIN claims c ON h.claim_id = c.id WHERE c.user_id = ?` — 자식 ID를 먼저 조회해 `IN`으로 넘기지 않아도 된다.
  - **S3 `DeleteObject`는 없는 키에도 성공한다**(LocalStack 실측) — 삭제 API를 멱등으로 두는 근거가 된다.

### 2026-09-11 — Kotlin KDoc 안의 `/**` 경로 패턴은 중첩 주석을 연다 (`Unclosed comment`)

- 맥락: 보험찾개냥 SSH-536 `OperatorKeyAuthFilter`·`AuthProperties`·`SecurityConfigTest`의 KDoc에 `` `/api/v1/admin/**` ``를 적었더니 `compileKotlin`이 `Syntax error: Unclosed comment` · `Missing '}'`로 죽었다. ktlintFormat도 `KtLint failed to parse file`. 세 파일에서 세 번 밟았다
- 배운 것:
  - **Kotlin의 블록 주석은 중첩된다**(Java와 다르다). 그래서 KDoc 안의 `/**`(Ant 경로 패턴 `admin/**`의 마지막 `/**`)가 **새 주석을 여는 것**으로 읽히고, 닫는 `*/` 하나로는 바깥 주석이 안 닫힌다. 백틱 코드 스팬 안이어도 렉서는 모른다
  - 에러 줄 번호는 파일 끝(`:70:1 Unclosed comment`)이나 엉뚱한 곳(`:32:6 Missing '}'`)을 가리켜 원인 줄을 못 찾는다. **`grep -n '/\*\*' <파일> | grep -v '^\S*:\s*/\*\*$'`로 줄 첫머리가 아닌 `/**`를 찾으면 바로 나온다**
  - 고치는 법: 주석에서는 `` `/api/v1/admin/` 아래 ``처럼 쓴다. **문자열 리터럴(`const val ADMIN_PATH = "/api/v1/admin/**"`)은 문제없다** — 주석 안에서만 터진다. `// 한 줄 주석`도 안전하다
