# Claude Code 사용량과 한도

구독 한도는 하나가 아니다 — **모델별 하위 한도**가 따로 있고, 실제로 먼저 마르는 건 그쪽이다. 그리고 내 사용량은 추측할 필요 없이 **로컬 트랜스크립트로 실측**할 수 있다.

## 핵심 정리

### 1. Fable 5는 전체 한도와 별개의 자체 한도를 쓴다

한도에 걸리면 전체 사용 한도 메시지가 아니라 **모델 이름이 박힌 별도 메시지**가 온다.

```
You've reached your Fable 5 limit.
Run /usage-credits to continue or switch models with /model.
```

→ **"Max 플랜이 부족하다"와 "Fable 쿼터가 부족하다"는 다른 문제다.** 후자는 `/model`로 Opus 5에 내려오면 그대로 해결된다. 플랜을 올릴 이유가 아니다.

### 2. 사용량은 `(로컬 경로)`로 직접 셀 수 있다

각 줄이 JSON 한 개고, `type: "assistant"`인 줄의 `message.usage`에 토큰이 다 들어 있다.

```python
u = d['message']['usage']
# input_tokens / output_tokens / cache_creation_input_tokens / cache_read_input_tokens
# cache_creation.{ephemeral_5m_input_tokens, ephemeral_1h_input_tokens}
# model 은 d['message']['model'], 시각은 d['timestamp'] (UTC, ISO8601)
```

**중복 제거 키는 `(message.id, requestId)`다.** 같은 응답이 세션 재개·리졸브 때문에 여러 파일에 중복으로 들어간다. 이걸 안 하면 수치가 부풀려진다.

한도 도달·API 에러는 `isApiErrorMessage: true`인 줄에 사람이 읽는 문장으로 남는다 — **"몇 번 막혔나"를 세는 가장 확실한 방법**이다. 실측 로그가 남으니 체감에 의존할 필요가 없다.

### 3. 비용의 대부분은 출력이 아니라 캐시다

공식 배수 (base input 가격 대비):

| 항목 | 배수 |
|---|---|
| 5분 캐시 쓰기 | **1.25×** |
| 1시간 캐시 쓰기 | **2×** |
| 캐시 읽기 | **0.1×** |

Claude Code는 실측상 **캐시 쓰기의 97%가 1시간 TTL**이다. 읽기가 0.1×로 싸 보여도 **양이 압도적**이라(내 한 달치: 캐시 읽기 29억 토큰 vs 출력 1,056만 토큰 — 275배) 정가 환산 비용의 절반 이상이 캐시 읽기에서 나온다. 캐시 배수를 빼고 출력 토큰만 세면 실제의 1/5도 안 나온다.

### 4. 모델 등급은 토큰당 가격에 그대로 비례한다

Fable 5는 $10/$50, Opus 5는 $5/$25 — **정확히 2배**다. 같은 작업량이면 Opus 5로 내리는 것만으로 소모가 절반이 된다. 별도의 효율 개선이 필요한 게 아니다.

## 기록

### 2026-08-22 — 한도에 막힌 건 플랜이 아니라 Fable 쿼터였다

- **맥락**: "지금 구독 플랜이 나한테 충분한가"를 체감이 아니라 숫자로 판단해야 했다. 지난 31일치(2026-07-21~08-21) 로컬 트랜스크립트를 전수 집계했다.
- **배운 것**:
  - **31일 동안 한도에 막힌 건 딱 한 번, 2026-08-14 오전이고 그마저 Fable 5 전용 한도였다.** 전체 사용 한도 메시지는 0건. → 플랜이 부족한 게 아니었다.
  - **판단은 이미 실험으로 끝나 있었다.** 08-13까지는 사실상 100% Fable이었는데, 08-14에 한도를 맞고 Opus 5로 갈아탄 뒤 08-19에 **이번 달 출력 최고치(777K 토큰, Opus 5 573건)**를 찍고도 한도에 안 걸렸다. 08-20은 Opus 5만 431건 — 역시 무사. **"Fable 줄이고 Opus 5로"는 가설이 아니라 사흘 검증된 결과.**
  - 정가 환산 총 $5,282 (Fable $4,349 / Opus 5 $877 / Opus 4.8 $55). **비용의 82%가 Fable 한 모델**이었고, 전량 Opus 5였다면 약 $3,100.
  - 구독료($200) 대비 26배지만 **이 배수는 한도 소진율이 아니다.** 실제 한도는 달러가 아니라 5시간·주간 윈도우 기준이고 환산식은 비공개다. 둘을 섞으면 "26배 썼으니 한도를 넘었겠지"라는 틀린 결론이 나온다 — 실제로는 한 번도 안 넘었다.
- **근거**: `(로컬 경로)` 전수 집계(154개 파일, 어시스턴트 메시지 10,949건, `(message.id, requestId)` 중복 제거). 한도 도달 로그는 `isApiErrorMessage`인 6줄이 전부 2026-08-14 08:20~09:32Z 한 시간 안에 몰려 있어 **단일 사건**임이 확인된다.
