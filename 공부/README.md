# 공부

프로젝트·운영을 하면서 **내가 새로 이해하게 된 것**을 주제별로 쌓는 영역 허브다. `_wiki/`가 외부 출처(Sources)를 종합한 지식이라면, 공부는 실제 작업 경험에서 나온 1인칭 학습 노트다. CS든 프레임워크든 도구든, 배운 것은 전부 여기로 모인다.

## 원칙

1. **주제별 파일, 날짜별 항목 append.** 같은 주제로 배운 게 쌓이며 한 파일이 두꺼워지는 것이 목적이다. 날짜별 파일은 만들지 않는다.
2. **양방향 연결.** 공부 항목은 맥락이 된 프로젝트를 링크하고, 그 프로젝트 README의 `## 배운 것` 섹션은 공부 주제를 링크한다. 작업 기록 파일(`<주제> YYYY-MM-DD.md`)에도 `배운 것:` 한 줄로 공부 주제를 링크한다. 한쪽만 있으면 미완성이다.
    - **맥락이 프로젝트가 아닐 수 있다** (2026-08-22 추가). 볼트 운영·비용·인프라처럼 특정 프로젝트에 속하지 않는 주제는 `프로젝트/` 대신 그 맥락이 된 문서(`운영/…`, `금융/…`)를 링크한다. 억지로 프로젝트를 붙이지 않는다 — 근거가 약해질 뿐이다. 이때도 **상대 문서 쪽에 역링크를 남기는 의무는 그대로다.**
