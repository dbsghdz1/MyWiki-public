# CoinPilot 새 구현 시작 준비

## 완료한 준비

기존 구현 `1d7fa6956972b7e5d39452ded77684c055663fd7`에 `archive/pre-rebuild-2026-11-13` 태그를 붙였다. `feat/coinpilot-rebuild` 브랜치를 만들고 현재 작업 브랜치로 전환했다. 태그와 브랜치 모두 원격 반영을 다시 조회해 확인했다. 새 구현 코드는 작성하지 않았고 기존 소스와 의존성 설정을 유지했다. 근거: 저장소 커밋 `f4ff325`, `git ls-remote` 재조회, 2026-11-13.

오후 시작 안내는 저장소 `docs/rebuild-start.md`다. 확정한 요구사항, FSD 구조의 책임, 첫 파일과 블록별 검증 방법을 담았다. 근거: [준비 문서 커밋](https://github.com/dbsghdz1/MyCryptoDiary/commit/f4ff325b816dab8c9496e197d3103d8a52a27d2d), [화면 결정](README.md#공통-화면-구조-결정-2026-11-13).

## 오후 첫 구현

- 시작 파일: `src/widgets/app-shell/ui/AppShell.tsx`
- 첫 목표: 왼쪽 메뉴, 오른쪽 상단과 본문 영역의 정적인 PC 화면 틀 한 파일
- 메뉴: 대시보드, 거래소, 내 자산, 랭킹
- 진행: 박스 구조를 먼저 그리고 크기, 여백, 스크롤 책임을 정한 다음 기존 토큰으로 직접 타이핑한다. 본문은 children으로 받아 배치한다.
- 다음 블록: 공개 export와 인증 레이아웃 연결, PC 화면 확인, 모바일 메뉴 상태와 화면 이동 순서

첫 블록에는 API, 실제 잔고와 시세, 로그인 연결, 모바일 토글을 함께 넣지 않는다. 현재 인증 판단은 `app/(protected)/layout.tsx`에 있으므로 공통 틀에 옮기지 않는다. 근거: 저장소 `docs/rebuild-start.md`, `app/(protected)/layout.tsx`, [학습 조건](README.md#에이전트-작업-규칙).
