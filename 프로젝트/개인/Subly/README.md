# Subly (코드명)

## 현재 카드
- **단계**: 보류
- **현재**: 2026-08-22 착수 당일 마일스톤 0(오디오 전용 SCK 스트림, 자막 지연 +0.85~1.03초) 통과 뒤 포지셔닝 문제로 08-23 보류. 번역 품질은 미검증
- **다음 판정**: 애플 en→ko 번역 품질 측정 결과 + 구독 전제 재계산(08-23 운영 원칙 개정) — 둘 다 없이는 착수하지 않는다
- **지금 할 일**: 우클릭 → 번역 한 번으로 en→ko 품질 측정(몇 분) — 결과로 세 갈래 중 둘을 지운다
- **하지 않을 일**: 세 갈래(모델 번들·구독+클라우드·파일 기반) 어느 쪽도 측정 전 착수 금지. `Subly`는 코드명 — 스토어 이름으로 쓰지 않는다

macOS 26의 `SpeechAnalyzer` + 온디바이스 번역으로 **맥에서 재생 중인 모든 소리에 실시간 자막을 띄우는 플로팅 창.** 2026-08-22 착수, 같은 날 마일스톤 0(기술 스파이크)까지 진행하고 **방향 재평가로 보류**했다.

> [!warning] status: paused — 기술은 검증됐고 제품 전제가 무너졌다
> 스파이크는 성공했다(아래 실측). 보류 사유는 기술이 아니라 **포지셔닝**이다. 2026-08-23 운영 원칙 전면 개정(사업 운영 원칙)으로 전제가 또 바뀌었으므로, 재개하려면 **구독 전제로 다시 계산**해야 한다.

## 무엇을 만들려 했나

- **포지셔닝(초안)**: "클라우드 안 감, 구독 없음, 1회 결제" — 경쟁사(Otter, Zoom AI)가 전부 구독+클라우드라 정확히 반대편
- **타겟**: 영어 강의·미팅을 듣는 비영어권 직장인·유학생, 청각 약자
- **가격(초안)**: 39,000원 1회 결제

## 마일스톤 0 결과 (2026-08-22) — 기술은 전부 통과

버리는 CLI 스파이크로 `시스템 오디오 → 자막 → 한국어 번역` 파이프라인을 검증했다. 코드: `(로컬 경로)` (SPM, 서명된 .app 번들).

| 검증 항목 | 결과 |
|---|---|
| 고정 인증서 서명 + `open` 실행 → TCC 귀속 | ✅ 재빌드해도 화면 기록 권한 유지 |
| **오디오 전용 ScreenCaptureKit 스트림** | ✅ **macOS 26에서 성립 — 더미 비디오 출력 불필요** |
| 시스템 오디오 수신 | ✅ 버퍼 피크 0.14~0.28 (무음 아님) |
| 48kHz/2ch planar → 16kHz/1ch 변환 | ✅ `AVAudioConverter` |
| 영어 자막 정확도 | ✅ **약 110단어에 오류 1건**(고유명사 `Kryvyi Rih`→`Kriviri`). 문장부호·대소문자·숫자 정확 |
| **자막 지연** | ✅ **확정까지 +0.85 ~ +1.03초** (기준선 2.5초를 크게 밑돔) |
| 번역 | ❌ 미검증 — 한국어 번역 모델 미설치 |

측정에 쓴 오디오는 BBC 뉴스(깨끗한 방송 음성)다. **줌 회의·강의는 억양·마이크 품질·말 겹침 때문에 더 어렵다** — 이 수치를 그대로 일반화하면 안 된다.

## 왜 보류했나 — 두 개의 벽

### ① 애플이 이미 무료로 넣어놨다

**macOS에는 Live Captions가 기본 탑재돼 있다.** 애플 실리콘 전용·온디바이스·한국어와 영어 포함. **번역이 없고 저장이 안 될 뿐** 실시간 자막 자체는 무료다.

→ **"온디바이스 실시간 자막"은 해자가 아니다.** 해자는 오직 번역(+저장)이다. 그리고 $9짜리 경쟁 앱([subtitles-live.com](https://subtitles-live.com/), Core Audio 프로세스 탭·완전 오프라인·9개 언어·Gumroad)도 이미 나와 있다.

### ② 핵심 가치가 남의 모델에 묶여 있다

사용자 지적(2026-08-23): *"결국 애플의 모델 성능을 따라가고, 번역이 그렇게 잘 되진 않잖아."*

여기서 나온 일반 규칙 — **감싸서 팔리는 건 "좋은 모델 + 쓰기 불편"일 때뿐이다.** `Aiko $24`는 OpenAI Whisper를 감싼 것인데 팔린다. Whisper가 진짜 좋고 일반인이 쓰기 불편하기 때문이다. 모델이 평범하면 감싸봐야 **예쁜 UI를 씌운 평범한 결과**고, 사용자는 UI가 아니라 결과를 보고 판단한다.

그리고 $20~36 구간 46개 앱 중 **"우리 AI가 좋습니다"로 파는 앱이 하나도 없다** — 전부 작업을 해주는 도구로 판다([[_wiki/1인 개발 앱 수익화|가격대 실측]]).

## 재개한다면 — 세 갈래

1. **모델을 소유한다** — 한국어 번역 모델을 직접 번들(NLLB·opus-mt → CoreML). 품질이 애플에 묶이지 않고 그 품질이 해자가 된다. 대가: 번들 500MB~1.5GB, 변환·속도 작업
2. **구독 + 클라우드 API** — 2026-08-23 원칙 개정으로 **새로 열린 길**(사업 운영 원칙). 품질 상한이 사라지는 대신 원가·구독 저항이 들어온다
3. **대상을 바꾼다** — "실시간·소비자"가 아니라 "파일 기반·전문가"(영상 편집자·유튜버 자막 제작). 지연·정확도 압박이 사라지고 화면 기록 권한도 불필요해진다. 경쟁: Aiko $24, MacWhisper, `Subtitle Edit Pro $29.99` — **다만 이들 모두 번역을 안 한다**

**어느 쪽이든 착수 전에 애플 en→ko 번역 품질을 먼저 재야 한다.** 우클릭 → 번역 한 번이면 갈래 둘이 지워진다.

## 이름 — Subly는 스토어에 못 쓴다

`SUBLY`는 Subly Media Inc. / Subly UK Ltd의 **등록 상표**이고 하필 **자막·번역·전사라는 동일 분야**다(getsubly.com). 심사 가이드라인 5.2.1 반려와 상표 이의제기 위험이 실질적이다. → **코드명으로만 사용**, 스토어 이름은 별도.
