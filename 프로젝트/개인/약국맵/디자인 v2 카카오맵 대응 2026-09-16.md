# 약국맵 디자인 v2 — 카카오맵 대응 (2026-09-16)

**결론 한 줄**: v1 시안은 손으로 그린 지도 일러스트 위에서 설계돼 있었다. 카카오맵 실물 위에 같은 좌표로 얹어보니 **색은 살았고 불투명도가 깨졌다** — 초록 팔레트는 노란 카카오 타일 위에서 오히려 더 또렷했고, 반투명 흰 pill 핀과 유리 범례는 사라졌다.

배운 것: [[작업노트/도구/한국 지도 API 선택|한국 지도 API 선택]] · [[작업노트/도구/Figma MCP|Figma MCP]] · [[작업노트/도구/Aside 브라우저 폼 자동 입력|Aside repl 캡처]]

## 왜 이걸 했나

홍: *"여기를 보완해줘 나는 3d아이콘을 좋아하는 것 같아 색상은 일단 마음에 들어 그런데 지도 사진이 아마 카카오맵으로 할것 같아"*

세 가지가 동시에 들어왔다 — ① 시안 보완 ② 3D 아이콘 선호 ③ 베이스맵이 카카오맵. ③이 ①의 전제를 바꾸므로 **추측으로 고치지 않고 실물 위에서 판정**부터 했다.

## 판정 — 카카오맵 실물 위에 v1을 얹었다

`map.kakao.com` 「서울대입구역 약국」을 캡처해 v1 패널·핀·범례를 **원래 좌표 그대로** 합성했다.

| 판정 | 무엇 | 왜 |
|---|---|---|
| **유지** | 초록 팔레트 | 카카오 타일은 노란 건물 블록이 배경을 지배한다. 초록은 명도·채도가 갈려서 **더 또렷해졌다** |
| 고침 | 비선택 핀 | 반투명 흰 pill이 상호 라벨 + 노란 블록 위에서 **사라진다** |
| 고침 | 하단 범례 | 유리 바 투명도가 높아 지도 라벨에 먹힌다 |
| 고침 | 선택 핀 윤곽 | 지하철 2호선이 굵은 초록 띠라 초록 핀과 헷갈린다 → 흰 외곽선 2px |
| 고침 | 우리 축척바 | 카카오가 축척바 + kakao 로고를 구석에 직접 그린다(삭제 불가). v1 눈금(`459:944~947`)은 중복 |
| 참고 | 오렌지 POI 아이콘 | 타일 그 자체라 끌 수 없다. 핀은 **크기로 이겨야** 한다 |

> [!warning] 합성 이미지를 과하게 읽지 말 것
> 캡처 원본은 **카카오맵 웹사이트**다. 파란 물방울 A~N 마커·우측 컨트롤 스택·「이 지역 재검색」·좌측 검색 패널은 **웹사이트 UI라 우리 화면엔 없다**(우리는 JS SDK로 직접 그린다). SDK에도 나오는 건 타일 자체 — 노란 블록·상호 라벨·오렌지 POI 아이콘·2호선 초록 띠·kakao 로고+축척바.

### 곁가지로 나온 제품 판정

「서울대입구역 약국」 검색에 **카카오가 이미 약국 162곳을 파란 A~N 마커로 찍어준다.** README가 인정한 *"기능은 같다"*가 화면으로 확인됐다. 그래서 차별점인 **「확인됨」 배지를 v1보다 세게 밀어야 한다** — 이게 아래 04번 변경의 근거다.

## 무엇을 고쳤나 (Figma 섹션 「약국맵 v2 — 카카오맵 대응 · 3D 아이콘」)

기존 섹션은 **손대지 않고** 아래에 v2 섹션을 새로 만들었다 — 비교해서 보고 마음에 안 들면 버릴 수 있게.

| # | 내용 |
|---|---|
| 01 | 판정 합성 이미지 (BEFORE) + 판정 카드 6장 + 「합성 이미지 읽는 법」 |
| 02 | **핀 시스템 3단** — L1 멀리=숫자 클러스터 / L2 중간=아이콘만 36px / L3 가까이=이름 pill. v1은 핀이 3개뿐이라 안 보였던 문제(관악구 약국 200곳대) |
| 03 | **AFTER 판정판** — 같은 캡처·같은 좌표에 v2 핀만 갈아끼운 편집 가능한 프레임. 핀을 끌어 옮겨가며 볼 수 있다 |
| 04 | **「확인됨」 배지 강화** — 시각을 배지 안으로(「12분 전 확인」), 확인한 사람 수(「오늘 3명 확인」), 카드 왼쪽 초록 바 4px, 연한 초록 틴트 |
| 05 | **3D 아이콘 규칙** — 3D는 히어로 5자리에만(브랜드 56 / 제보 히어로 64 / 제보 완료 88 / 선택된 핀 44 / 빈 상태 120), 24px 이하 컨트롤은 평면 선 유지 |
| 06 | **빈 상태 3종** — 열린 곳 없음 · 위치 권한 거부 · 불러오기 실패. v1에 아예 없던 화면이고 3D가 가장 크게 들어갈 자리 |
| 07 | **제보 CTA 중립화 + 상충 제보 카드** |
| 08 | **체크 표시를 버렸다** — 네 자리(배지·지도 핀·제보 완료·필터 칩)의 ✓를 전부 **펄스 점**으로 |

### 핀은 왜 3단인가

`MarkerClusterer`는 `Marker` 대상이라 HTML `CustomOverlay` pill에는 클러스터링이 안 붙는다(문서에 명시 없음 — **실측 필요**). 관악구 약국만 200곳대이므로 줌아웃하면 이름 pill 수백 개가 겹친다. 그래서 줌 레벨로 핀 모양을 갈아낀다.

### 제보를 고발처럼 보이게 하지 않기

v1의 제보 CTA는 화면에서 가장 큰 **붉은 버튼**이다(`459:2959`). 제보는 고발이 아니라 다음 사람을 위한 도움인데 「이 약국을 신고한다」로 읽힌다. **홍이 약국에서 일하는 사람이라 약국 쪽 반감은 가정이 아니라 실제 리스크다.**

- 붉은색은 **상태 표시(닫힘 배지·닫힘 핀)에만**. 버튼은 초록
- 문구도 `닫힘 제보 보내기` → `지금 닫혀 있다고 알리기`
- 다이얼로그 제목 「지금 닫혀 있나요?」와 부제는 이미 좋아서 그대로

### 상충 제보 — 로그인 없는 구조의 필연

로그인 없이 누르므로 「A는 열림·B는 닫힘」이 **반드시** 생기는데 v1에 그 화면이 없다. 앰버 카드를 새로 만들었다.

- 가장 최근 제보가 이긴다. 다만 **30분 안에 서로 반대인 제보가 2건 이상이면** 「엇갈려요」로 넘어간다
- 「엇갈려요」에서는 초록도 붉은색도 안 쓴다 — **앰버**. 우리가 모른다는 것을 색으로 말한다
- **여기서만 전화 버튼을 앞세운다.** 전화를 줄이는 게 제품 목적이지만, 우리가 모를 때는 전화가 맞다
- 장난 제보 방어를 이 화면이 대신한다 — 지우는 대신 엇갈림을 보여주면 **한 건이 전체를 뒤집지 못한다**

### 체크 표시를 버린 이유 (홍 지적 → 내 판단)

홍: *"아 저 체크 표시가 마음에 안든건데"* → 어느 자리냐 물었더니 **네 자리 전부**, 그리고 *"느낌 있게 해봐"*.

**체크(✓)는 「이 정보가 맞다」를 말한다. 그런데 이 제품이 파는 건 정확성이 아니라 신선도다** — 공식 데이터도 「맞다」, 다만 오래됐다. 기호가 제품의 주장을 안 하고 있었다.

먼저 기각한 후보:

| 후보 | 기각 이유 |
|---|---|
| **도장** | 한국에서 가장 직관적이지만 **관공서·공식을 뜻한다.** 이 제품이 불신하는 게 바로 그 「신고 기준 공식 데이터」다 — **기호가 제품 주장을 배신한다.** (내가 처음 추천했다가 철회) |
| 발자국 | 「헛걸음을 줄여요」와 뜻은 맞는데, v1 제보 다이얼로그의 `직접 방문` 버튼이 **이미 걷기 아이콘을 쓴다.** 같은 화면에서 부딪힌다 |
| 눈 | 감시·열람 뉘앙스가 붙고 16px에서 눈꺼풀 곡선이 뭉개진다 |
| 사람+체크 | 체크를 그대로 남기는 절충안이라 애초 문제가 안 풀린다 |

**채택: 펄스 점 (Live dot)** — 초록 점 하나 + 바깥으로 퍼지는 링. 녹화 중·라이브 방송에서 빌려온 관용구라 「지금 살아 있다」가 설명 없이 읽힌다. 세 가지가 동시에 맞는다.

1. **10px에서도 안 무너진다** — 그냥 점이다. 체크·발자국·눈이 전부 여기서 죽었다
2. **시간과 자연스럽게 붙는다** — `● 12분 전 확인`
3. **v1에 이미 있던 언어다** — 사이드바 「지금 열림」 토글 옆 초록 점. 새 기호를 들여오는 게 아니라 있던 것을 승격시킨 셈이다

크기 램프(코어는 단조 증가): 10px 점만 / 16px 링 1겹 / 24px 링 2겹 / 44px 히어로 / **88px는 3D 광택 구슬 + 링**.

**필터 칩은 예외적으로 기호를 아예 뺐다.** 거기 체크는 「확인됨」이 아니라 「필터 켜짐」을 뜻해서 **두 의미가 한 기호를 쓰고 있었다.** 칩이 채워지는 것(연초록 틴트 + Primary 테두리)으로 켜짐을 말한다 — 기호가 하나 줄고 뜻이 하나 갈린다.

**제보 완료 화면도 체크가 아니다.** 그 화면이 말해야 하는 건 「성공했다」가 아니라 **「네 제보가 지도에 올라갔다」** — 신호가 등록된 것이다. 같은 펄스 점의 3D판을 쓴다. 닫힘 제보 완료도 **X를 쓰지 않고** 같은 구슬을 Report 색으로만 바꾼다(실패가 아니라 「닫힘 신호가 올라갔다」이므로).

## 남은 것

- **3D 아이콘 4개(약국 십자 · 펄스 구슬 · 깃발 · 느낌표)를 Blender로 렌더** — 애드온은 업데이트했고 Blender에서 `Start MCP Server`를 한 번 눌러야 연결된다. 슬롯은 05·06번에 크기까지 잡혀 있다
- **모바일 바텀시트 3단**(핸들만 / 카드 1개 / 전체) — v1은 1단뿐
- **목록↔지도 hover 연동** 상태 (데스크톱)
- 상세의 `전화 확인` 버튼 무게 — 전화를 줄이는 게 목적인데 `길찾기`와 동급으로 크다. 「확인된 곳은 전화 버튼을 약하게」 규칙을 넣을지 홍 결정
- **v2 텍스트 폰트가 Noto Sans KR이다** — 플러그인 환경에 Pretendard가 없어서. v2 섹션 전체 선택 → Pretendard로 한 번에 바꾸면 v1과 맞는다
- `MarkerClusterer` + `CustomOverlay` 조합 실측 (코드 붙일 때)
