# 약국맵 학습 로드맵

**실제 작업이 던진 문제를 계기로, 커리큘럼 없이 손으로 부딪혀 배운다.** 문제가 학습 순서를 정한다 — 필요한 것을 필요한 순간에, 예측하고 실행해서.
한 칸 오르면 그게 [[프로젝트/개인/약국맵/README|약국맵]]의 커밋 하나가 된다. 세션 운영 규칙(몰입·난이도 조절·기록 방법)은 [[학습/README|학습]] 허브가 원본이다.

> [!note] 2026-09-13 — 학습 아래의 별도 하위 영역을 없애고 이 파일로 옮겼다
> 칸 목록과 세션 기록은 약국맵이라는 **한 프로젝트에 붙은 것**이라 프로젝트 폴더로 왔다. 일반 규칙(몰입 조건·발동 신호·기록 형식)만 [[학습/README|학습]] 허브에 남겼다.

## 예정 세션 — 프론트 로드맵 (2026-09-05 신설 → 같은 날 [[프로젝트/개인/약국맵/README|약국맵]]으로 대상 확정)

**계기**: 익히려는 스택(React·TS·**TanStack Query·Vite·Fastify·`react-dom/server` Streaming SSR`**)과 [[프로젝트/개인/MyCryptoDiary/D4 회고 2026-09-04|MyCryptoDiary D4 회고]](한 일차에 새 개념 10개 → 3x).

> [!important] 2026-09-05 — 연습 대상을 **약국맵**으로 확정했다 (홍 결정)
> 처음에는 버리는 코드로 스택만 익힐 계획이었다. 홍이 스스로 문제를 정의한 실제 프로젝트로 하고 싶다고 해서 **세션의 소재를 실제 프로젝트로 바꿨다.** 한 칸 오르면 그게 [[프로젝트/개인/약국맵/README|약국맵]]의 커밋 하나가 된다. 버리는 코드가 아니므로 작업 폴더는 프로젝트 저장소다.
> **규칙은 그대로다** — 세션당 새 개념 ≤3, 홍이 전부 타이핑, 에이전트는 로드맵과 **정확한 문서 링크**를 준다(빈칸 금지), 예측 → 실행 → 기록, 검증 명령을 시작 전에 정한다, 끝에 한 줄 설명. 슬롯은 **화~토 16:00~19:00 실습·프로젝트 블록 — CS 3세션(13:00~16:00) 바로 뒤**(2026-09-23 — 정본은 공부 학습 계획의 12시간 표. 화·토는 오픈소스 뒤라 18:00부터). **CS만 해도 그날은 성공**이라 실습은 "이어서 되면 하는 것"이다. 막히는 세션은 둘로 쪼갠다. 측정: 주당 실행 횟수 · 예측 적중/누락 · 에너지 1~10.

> [!important] 2026-09-08 — **문서 링크는 에이전트가 붙인다** (세션 1 직후 홍 제안)
> 원래 규칙은 *"에이전트는 로드맵과 찾는 법만"*이었는데, [[프로젝트/개인/약국맵/실습 1 — fetch와 useState 2026-09-08|세션 1]]에서 **그게 난이도를 엉뚱한 데서 올렸다.** 배울 것은 `useState`·`fetch`인데 정작 시간을 쓴 건 *"어느 문서를 봐야 하지"*였고, 그건 공부가 아니라 마찰이다(에너지 5, 불안 쪽으로 어긋남).
> **새 개념이 나오면 정확한 문서 페이지 링크를 에이전트가 먼저 붙인다.** 「찾는 법」은 홍이 이미 찾을 줄 아는 것에만 남긴다. **코드는 홍이 전부 타이핑**하는 원칙은 그대로다.

> [!important] 2026-09-09 — **링크만으로는 부족했다. 「한국어 + 절 이름 + 요약 3줄」로 준다**
> 하루 만에 다시 걸렸다. 홍: *"문서를 주면 다 보기에는 어렵고 영어로 쓰여 있어서 더 어려운 것 같아서"*. 링크를 주니 이번엔 **영어 문서 통독**이 마찰이 됐다.
> → **① 한국어 링크**(`react.dev` → `ko.react.dev`, MDN은 `/ko/` — 단 MDN 한국어는 오래된 번역이 섞여 있어 이상하면 영어와 대조) **② 그 페이지에서 볼 절 이름 하나** **③ 그 절의 핵심 2~3줄을 에이전트가 한국어로 옮겨서.** 한국어판이 없는 문서(TanStack Query)는 요약을 에이전트가 쓴다. **문서는 확인용이지, 읽어야 진도가 나가는 위치에 두지 않는다.**
> **문서 읽는 법**도 같이 정리했다 — `/learn/`은 개념(처음 배울 때), `/reference/`는 사전(확인할 때). reference는 위에서부터 읽지 않고, **증상이 있으면 `Troubleshooting`부터**(제목이 전부 증상 문장이다).

### 웹뷰 트랙 — 앱 안에서 도는 웹 (2026-09-20 신설, 홍 결정)

**계기**: [[프로젝트/개인/한능검/README|한능검]]은 웹 코어를 Capacitor로 감싼 앱이고, 위젯·iCloud 백업은 `WKScriptMessageHandler` 브릿지로 붙어 있다. 출시까지 했지만 막혔던 자리 여섯 개의 **원인과 해법은 에이전트가 찾아** [[작업노트/Apple/Capacitor 웹앱 iOS 래핑|에이전트용 노트]]에 남겼다(증상을 잡은 건 홍의 QA였다). 그 원인을 이번엔 **홍이 손으로 재현하고 확인한다.** 소재는 약국맵이다 — 위치 권한이 필요한 서비스라 웹뷰·앱·서버 세 레이어가 전부 걸린다.

**규칙은 위와 같다** — 새 개념 ≤3, 홍이 전부 타이핑, 예측 → 실행 → 기록, 검증을 시작 전에 정한다, 끝에 인출 퀴즈와 에너지 1~10. 09-10에 맞았던 방식(완성 코드를 따라 치고 → 실행 → 개념 질문)으로 시작한다. **칸마다 전/후로 셀 수 있는 것을 하나씩 심었다** — 몰입한 두 번(09-09 프록시 · 09-10 지도)이 모두 「막힘이 작고 결과가 바로 보인 날」이었다.
