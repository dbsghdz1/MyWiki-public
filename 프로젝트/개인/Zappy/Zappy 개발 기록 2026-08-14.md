# Zappy 개발 기록 2026-08-14 — 1.5 테마 리디자인 (유령·슬라임·너구리)

1.4.0 당일 승인 이후, 사용자가 "진짜 업데이트 필요"라고 지목한 유령·슬라임을 갈아엎고 너구리 얼굴을 보강했다. 커밋 d646c1e·745f90f·55d9417. 출처: Claude 대화, 2026-08-14.

## 결정

- **유령: 물 차오름 → 소멸 문법** — 기존 몸속 잔량 채움은 모찌·픽셀과 겹치는 문법이었다. 잔량 = 불투명도 + 부양 높이(투명해지며 가라앉음), 저전력 = 흩어지는 입자 + 당황한 빈 눈 + 물결 입, 충전 = 반짝이며 실체 회복. 구현: CGContext transparency layer로 몸 전체에 알파 적용 (컬러·모노 동일 구조).
- **슬라임: 2단계 형태 → 연속 볼륨 변형** — 꼭대기 높이·퍼짐이 잔량 함수로 연속 변화 (모노의 크기 축소 문법을 컬러로 통일). 만땅 = 탱글 꼭지, 충전 = 방울이 떨어져 흡수될 때마다 바운스.
- **너구리: 마스크 속 흰 점 눈 → 큰 흰자+눈동자+하이라이트** — 무표정의 원인이 눈동자 부재였다. 귀 꼭짓점 둥글게, 주둥이 확대. 볼터치는 금지 원칙 유지.
- 충전 모션 예외 확장: 소다 → 소다·유령·슬라임 ("차오르는 씬"은 모션 허용).
- **1.5 출시 시 스토어 설명 갱신 필요**: 유령 줄("몸속에 배터리가 물처럼 차올라요") → 소멸 문법으로. 슬라임 줄에 볼륨 변형 반영.

## 추가 (같은 날) — 너구리 원복 + Zappy+ 상시 모션

- **너구리 보강 철회**: 큰 눈망울 시안보다 기존 흰 점 눈이 너구리답다는 사용자 판단 — revert 후 build 10 재제출. 교훈: 귀여움 보강이 항상 정답은 아니다, 캐릭터 고유의 담백함이 정체성일 수 있음.
- **Zappy+ 상시 모션 (1.6 예정)**: "유료 = 항상 살아있는 테마" 가치 강화 — 불꽃 일렁임(폭·높이 반대 숨쉬기 ±7/9% + 스파크 교차), 해 광선 무한 회전(4페이즈에 광선 한 칸씩 = 이음새 없음). 충전 중 정지 규칙 유지. fire·weather-sun 모션 GIF 마케팅 폴더에 추가.

## 추가 (08-15) — 1.6 "살아있는 Zappy" 4종 구현

사용자가 아이디어 6개 중 4개(시즌 캘린더·위젯·충전 완료 연출·호버 반응)를 승인 — 하루에 전부 구현. 출처: Claude 대화, 2026-08-15.

- **충전 완료 연출**: 완충 전이(전원 연결 + 100%) 순간 ~3.4초 — 휴식 씬에서 일어나 평상시 100% 포즈(로봇이면 춤)로 돌아오며 회전 반짝이. 테마별 재작업 없이 `celebrationOverlay(base:tick:)` 공통 오버레이(모노는 검정). "충전 완료 알림" 옵트인 — 알림 배너에 캐릭터 PNG 첨부(UNNotificationAttachment).
- **호버 반응**: NSStatusBarButton에 tracking area(`.inVisibleRect` — % 표시로 폭이 바뀌어도 자동 추적), mouseEntered 시 하트가 ~1초 떠오르며 옅어짐. 교훈: 하트는 두 원+삼각형 합성이 아니라 **단일 윤곽 베지어**로 — 합성하면 winding 방향 불일치로 가운데 구멍, 알파 페이드도 겹침 얼룩.
- **위젯 (WidgetKit 익스텐션)**: small/medium, 캐릭터 6배 벡터 렌더. **App Group은 팀 ID 접두(`WN2B884S76.com.hong.zappy`)** — macOS에선 포털 등록 없이 자동 서명으로 동작(`group.` 접두는 등록 필요). 배터리는 위젯이 IOKit 직접 읽기, 앱은 테마·모노·plus만 미러링 + 상태 변화 시 reloadAllTimelines. pbxproj: sync group **예외 세트**로 Sources/CuteBattery를 두 타깃이 공유(App/Store/Paywall 등은 위젯에서 제외), Widget/Info.plist는 리소스 복사 제외. Release 아카이브 + App Store export 성공 검증(자동 서명이 익스텐션 프로파일 생성). fastlane `export_xcargs: -allowProvisioningUpdates` 추가.
- **시즌 테마 캘린더** 연 5회(할로윈·크리스마스·발렌타인·벚꽃·여름) 로드맵에 확정 — [[프로젝트/개인/Zappy/Zappy 로드맵과 유료화 계획]].
- 위젯 오프스크린 검증 팁: `@Environment(\.widgetFamily)` 기본값이 medium이라 small 뷰는 SmallView를 직접 호스팅해 렌더해야 한다.
