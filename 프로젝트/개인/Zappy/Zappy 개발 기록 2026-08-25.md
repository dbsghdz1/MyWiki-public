# Zappy 개발 기록 2026-08-25 — 나무 테마 (1.10.0, build 19)

Zappy+ 아홉 번째 모션 테마 **나무**. 잔량을 처음으로 **시간(계절)** 으로 은유한 테마다.
사용자 요청 원문: "벚꽃나무인데 단풍나무인 것처럼 — 100 봄 / 75 여름 / 50 가을 / 25 겨울 / 0".

## 결정

### 계절은 네 칸, 잎은 연속 함수

계절 이름은 25%씩 네 칸으로 끊기지만, 프로젝트 원칙([[프로젝트/개인/Zappy/README|README]] 결정 2 "잔량은 연속적으로 표현한다")을 지키려면
어느 잔량에서도 상태가 읽혀야 한다. 그래서 **이름만 이산, 그림은 연속**으로 갈랐다.

- `leaf`(잎의 양): `t≥0.5`면 1.0→0.7로 완만히, `0.25≤t<0.5`면 0.7→0으로 떨어지고 겨울엔 0.
  봄·여름 구간에서도 30% 줄어드는 건 **색이 없는 모노 때문**이다. 모노는 계절 색을 못 쓰므로
  덩어리 크기가 유일한 잔량 신호다. 처음엔 1.0→0.85만 줄여서 100%와 52%가 모노에서 똑같아 보였다.
- 색은 정점 보간(`treeLeafColor`): 벚꽃 분홍 → 연둣빛 → 짙은 여름 초록 → 노란 단풍 → 붉은 단풍.
- 잎덩어리는 `puffs` 5개(중앙 + 좌우 + 안쪽 2개). 각 덩어리에 등장 문턱값이 있어
  잔량이 빠지면 안쪽부터 사라지며 전체가 작아진다 = "낙엽이 진다".

### 씬 문법

- 상시 모션: 봄 꽃잎 · 여름 잎 · 가을 낙엽 · 겨울 눈이 4페이즈에 걸쳐 흩날린다(`drifters`) + 잎이 살랑(`sway`).
  `shouldAnimate`는 나무만 잔량 조건 없이 항상 true — 계절이 곧 모션이라 방전 직전에도 눈은 내린다.
- 충전 = **볕을 쬐며 광합성**(정지). 물뿌리개(선인장)·비(날씨)와 겹치지 않는 모티프를 골랐다.

## 렌더에서 잡은 것 (전부 눈으로 보고 나서야 드러남)

그림을 코드로 그리는 이 프로젝트의 대가 그대로 — 4번 렌더해서 4번 고쳤다.

1. **계절 색 보간 폭이 넓으면 중간이 진흙색이 된다.** 첫 정점은 0.82(분홍)→0.72(초록)라
   80%가 분홍과 초록의 중간, 즉 탁한 베이지로 떴다. 80%는 한복판 봄인데 봄으로 안 보인다.
   → 보간은 **경계 근처에서만 짧게**. 정점을 0.79/0.72로 좁혀 각 계절 대부분 구간은 순색이 나온다.
2. **좌우 대칭으로 두 갈래씩 뻗은 가지는 사슴뿔로 읽힌다.** 겨울(잎 0)에서 V자 세 쌍이
   그대로 뿔이 됐다. → 좌·우·중앙 가지의 길이와 각도를 일부러 어긋나게 뒀다.
3. **잎 밖으로 삐져나온 잔가지 끝은 뿔·더듬이가 된다.** 잎이 무성한 구간에서 잔가지 끝만
   캔버스 위쪽으로 튀어나왔다. → `twigAlpha`로 잎이 얇아진 뒤에만 그린다.
4. **눈은 덩어리로 얹으면 모자가 된다.** 가지 끝에 반원을 얹었더니 버섯 갓·전등갓처럼 보였다.
   → **가지 경로를 위로 0.9~1.3pt 민 선**을 눈으로 그린다. 밑에 얼음색 테두리를 깔아야 밝은 메뉴바에서 보인다.

### 모노 교훈: 실루엣에는 '위에 얹힌다'는 개념이 없다

컬러는 흰 눈 / 갈색 가지로 저절로 분리되지만, 모노(템플릿)는 둘 다 검정이라
눈을 얹으면 **가지가 굵어진 것**으로만 보인다. 해법은 사이에 **knockout 틈**을 내는 것 —
`가지(검정) → 틈(투명) → 눈(검정)`. 선인장 화분 테두리에서 쓴 것과 같은 수법이다.
그리고 knockout이 가는 선을 지우지 않도록 줄기는 그 뒤에 그려 되메운다(그리기 순서가 곧 z축).

## 곁다리로 고친 것

- **페이월 미리보기 줄이 이미 창 밖으로 나가 있었다.** 8종 기준 `52*8 + 4*7 = 444pt`인데 창은 380pt —
  1.9.0부터 양끝 카드가 잘린 채 나가 있었다. 아홉 번째를 더하기 전에 두 줄(5+4)로 접고 창 높이 +50.
  **테마를 늘릴 때마다 커지는 UI는 상한을 코드로 못 박아두지 않으면 조용히 넘친다.**
- **설명문 5개 언어가 전부 "테마 16종"이라 적어놓고 목록엔 14개만 있었다.** 선인장·해파리를 추가할 때
  숫자만 올리고 목록을 안 채운 것. 나무까지 셋을 채우고 17종·모션 9종으로 정정.
- **심사 노트의 "no Bluetooth entitlement"** 는 1.9.1 BLE 경로 이후 사실이 아니다 → GATT 0x180F 설명으로 교체.
  ([[공부/Apple/블루투스 기기 배터리 읽기|블루투스 기기 배터리 읽기]])
