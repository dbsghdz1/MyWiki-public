# Zappy 개발 기록 2026-10-03 — 기본 배터리 테마 · 소모 전력 · 발열 · 충전 사유 (1.18 작업분)

## 배경

홍 "기본 배터리 설정으로 돌아갈 수 있게 만들고, 배터리에 관한 좋은 기능을 추가해야 할 것 같아. 현재 있는 건 정말 꾸미기 용도로 남겨두는 거지." — 캐릭터는 꾸미기, 쓸모는 배터리 기능이 맡는다는 방향. [로드맵 1.17 결정 8](Zappy%20%EB%A1%9C%EB%93%9C%EB%A7%B5%EA%B3%BC%20%EC%9C%A0%EB%A3%8C%ED%99%94%20%EA%B3%84%ED%9A%8D.md)의 14일 판정(유틸 추가 여부)보다 앞서 홍이 직접 정했다. 기능 후보 넷 중 홍이 고른 셋: **지금 소모 전력 · 발열 경고 · 충전이 느린 이유**(배터리 건강 한 줄은 빠짐).

**상태: main `274dc34`로 커밋·push(10-03 저녁).** 1.17.0이 아직 WAITING_FOR_REVIEW(`asc state` 10-03 확인)라 버전은 올리지 않았다 — 홍이 기능 추가와 컨셉 변경을 더 원해서 1.18 범위는 열려 있다.

## 한 것

- **기본 배터리 테마** `Theme.classic`("기본", 무료, 무료 블록 8번째 — 그리드가 4×2로 꽉 찬다). 시스템 배터리 모양: 둥근 몸통 + 가로 잔량 막대 + 꼭지, 전원 연결 중엔 막대를 뚫고 번개. 얼굴·모션이 없는 유일한 테마. 기하는 `ClassicGeom` 하나를 컬러·모노가 같이 쓴다. 모노는 윤곽 알파 0.5·막대 1.0, 컬러는 양쪽 메뉴바에서 읽히는 중간 회색 윤곽 + 20% 이하 빨강·충전 초록. 위젯 `ThemePick`·`Localizable.xcstrings`(Classic)·`L10n` 5로케일(기본/Classic/標準/Clásica/經典).
  - 첫 렌더에서 번개를 뚫는 윤곽이 몸통 테두리까지 잘랐다 → 번개 높이 ±4.6 → ±3.5, 뚫는 폭 1.1 → 0.9로 몸통 안에 가뒀다.
- **메뉴 상태 묶음 3줄 추가**(`infoItem` → `chargerItem` → 아래 셋, 해당 없으면 숨김, 주변기기 줄은 그 아래로 이동):
  - `powerItem` "11W 사용 중 · 평소보다 높음" — 배터리 구동 중엔 Voltage×Amperage, 전원 연결 중엔 `PowerTelemetryData.SystemLoad`. 평소값은 5분 표본 지수 평균(`drainAvgW`), 12표본(1시간) 뒤부터 1.5배 이상일 때만 비교를 붙인다.
  - `heatItem` "배터리 41°C · 온도가 높아요" — 40°C 이상에서만. **발열 알림** 토글(`heatAlert`, 기본 꺼짐, 37°C 아래로 식어야 다시 알림).
  - `chargeNoteItem` — 전원이 꽂혀 있는데 충전이 기대와 다를 때: 최적화된 충전 대기 / 충전기보다 많이 쓰는 중 / 뜨거워서 대기 / 80% 이상에서 대기(충전 한도 또는 보호) / 느리게 충전 중.
- 메뉴를 여는 순간에도 세 줄을 다시 읽는다(`menuWillOpen` → `refreshLiveLines`) — 전력은 초 단위로 변하는데 `update()`는 전원 이벤트와 120초 폴백에서만 돈다.

## 결정

- **비공개 코드표는 해석하지 않는다.** `ChargerData.NotChargingReason`(배터리 구동 중 128)·`SlowChargingReason`은 값의 뜻이 문서에 없다. 충전 사유는 확인 가능한 것만으로 판정한다 — IOPS `Optimized Battery Charging Engaged`, 전류 부호, 온도, 80% 이상 여부. `SlowChargingReason`은 0인지 아닌지만 본다. 80% 미만에서 이유 없이 멈춘 경우는 아무 말도 하지 않는다.
- 충전 사유는 흔들림을 걷어낸 충전 상태(`settledCharging`)로 판단 — IsCharging이 전원 연결 중 몇 초 주기로 깜빡여서 그대로 쓰면 문구가 깜빡인다.
- 스토어의 "18종" 표기는 그대로. 기본 배터리는 캐릭터가 아니다.

## 검증

- `swift build`, `xcodebuild -scheme Zappy -configuration Debug`(위젯 포함) **BUILD SUCCEEDED**
- 기본 배터리 렌더: 밝은·어두운 배경 × 모노·컬러 × 잔량 6단계·충전 3단계 육안 확인
- `chargeNote()` 판정 10건 PASS(배터리 구동·정상 충전·느린 충전·완충·최적화·충전기 부족·발열·80% 한도·79% 불명·우선순위)
- 실제 앱(`-theme "기본" -forceTemp 42`) 메뉴를 AppleScript로 읽음: `Battery 43% · until 19:39 · 2 hr 15 min left` / `Using 8 W` / `Battery 42°C · running hot` / 주변기기 줄 / … / `Heat Alert`
- **미검증(실기 몫)**: 충전 사유 5종은 전원을 꽂아야 나온다 — 이 세션은 배터리 구동 상태였다. `Optimized Battery Charging Engaged` 키는 배터리 구동 중 IOPS 사전에 없어서 값 확인을 못 했다. 발열 알림 실제 발송, "평소보다 높음"(1시간 표본 필요)도 미확인.
