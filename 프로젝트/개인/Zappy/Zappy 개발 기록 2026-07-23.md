## 기술 노트 (재사용 가치)

- **`NSApplication.delegate`는 약한 참조** — 델리게이트를 지역 변수로 들면 즉시 해제되어 "프로세스는 살았는데 메뉴바 아이콘만 없는" 증상. `static let`으로 강하게 보유해야 함
- **템플릿 아이콘은 알파 채널만 사용** — 색 2개가 불가능하므로 "채움 위 얼굴은 knockout(blend .clear), 빈 곳은 불투명"으로 반전. 채움 경계가 얼굴을 지날 땐 fill 영역 안/밖 이중 클리핑(splitFace)으로 처리. 좌우 채움은 비대칭이라 지저분 → **상하 채움이 대칭이라 깔끔**
- **IOPSNotificationCreateRunLoopSource** — 폴링 대신 전원 이벤트 기반 갱신. C 콜백에 `Unmanaged.passUnretained(self).toOpaque()`로 컨텍스트 전달
- **Xcode 16+ 수제 pbxproj** — `PBXFileSystemSynchronizedRootGroup`으로 폴더를 통째 참조하면 파일 목록 관리 불필요. `GENERATE_INFOPLIST_FILE` + `INFOPLIST_KEY_*`로 plist 파일도 생략
- **Figma 플러그인 API 함정**: ① vectorPaths로 만든 벡터는 x,y가 bbox 기준이라 중심 좌표로 재배치 필요 ② 벡터 복사본의 boolean intersect는 렌더링되지 않음 → 클리핑 프레임 사용 ③ `upload_assets`는 nodeId 지정 URL을 여러 개 동시 발급받으면 배치 유실 — count 방식으로 받아 imageHash를 fills에 직접 지정
- **SPM 실행파일로 Archive하면 Generic Archive** — 앱 타깃 xcodeproj 필수
