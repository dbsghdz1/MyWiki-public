# Zappy 개발 기록 2026-08-21

**새 캐릭터 선인장 + 1.8.0 제출.** "새로운 캐릭터 하나 만들어볼까"로 시작해 반나절 안에 그리기 → 메뉴바 실기 확인 → 1.8.0(build 14) 제출까지 갔다. 1.7.0은 제출 다음 날 이미 **승인·출시(READY_FOR_SALE)** 돼 있었다 — `asc state`로 확인하기 전까지 위키는 "심사 대기"였다.

## 결정 — 왜 선인장인가

로드맵에 이월돼 있던 후보는 커피잔·해파리(07-28). 선인장을 고른 이유: 기존 14종과 **실루엣·문법이 겹치지 않는다**. 커피잔은 소다와 같은 "채움" 계열이고, 선인장은 "생기(vitality)" 문법 — 역도·로봇의 활력형과 눈사람의 변형형 사이의 새 자리다. Zappy+ 7번째 모션 테마로 배치(`paidMenuOrder` 끝).

## 문법 (코드 `CactusGeom` 기준)

- **잔량 = 생기**, 전부 연속값: 몸통 높이 `7.2 + 4.0t`·폭 `5.8 + 1.8t`, 팔 꺾임 `-3 + 6.5t`(만세 ↔ 축 처짐), 몸색 초록→올리브 보간
- 꽃: ≥70% 개화(5잎 + 꽃술) → ≥40% 봉오리 → 없음 → ≤20% **바닥에 떨어진 꽃잎 + 화분 금 + 몸통 주름 + 시무룩**
- **충전 = 물뿌리개 휴식 씬**(정지) — 눈 감고 `^ ^`
- **상시 모션(Zappy+)**: ≥70%에서 꽃 옆을 맴도는 벌(`phaseAmp`로 위아래 1.4pt)
- 모노: 골(세로 줄)·주름을 **생략** — knockout 선이 몸통을 조각내서 실루엣이 깨졌다. 생기는 팔 각도·꽃·금으로만 읽힌다. 봉오리는 몸통과 붙어 뾰족머리로 보여 밑선 knockout 0.5pt로 분리
- 캔버스 22 안에 꽃 포함 꼭대기 21.8 — 처음엔 화분이 너무 커서(높이 5.8) 선인장이 눌려 보였고, 화분을 4.3으로 낮추고 몸통을 키웠다

## 실기 확인에서 배운 것 (프로젝트 고유)

- `pkill -x Zappy`는 아무것도 안 죽인다 — 실행 파일명이 **`CuteBattery`** 다. 기존 인스턴스가 살아서 새 빌드가 안 뜬 것처럼 보였다. `pkill -x CuteBattery`
- `defaults write com.hong.zappy theme 선인장` 후 재실행해도 테마가 안 바뀌는 경우가 있었다(원인 미확정 — 컨테이너 plist에도 값은 들어갔다). **`-theme "선인장"` 인자 도메인이 확실**하다 → CLAUDE.md 플래그 목록에 추가
- `-forceCharging`은 YES만 강제할 수 있고 **언플러그는 강제 못 한다** — 전원 연결 중엔 메뉴바에서 비충전 모습을 못 본다. 비충전 모습은 렌더 스트립(`swiftc Themes.swift Mono.swift + main.swift`)으로 검증
