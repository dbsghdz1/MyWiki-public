## 3. 1.2 기능 선행 구현 (App.swift)

- **잔량 % 표시 토글** (요청 1순위 예상): 메뉴바 아이콘 옆 숫자, monospaced digit 11.5pt, 기본 꺼짐. `showPercent` 키
- **저전력 알림 임계값**: "저전력 알림" 서브메뉴 — 30/25/20/15/10% · 사용 안 함 (기본 20%). `lowThreshold` 키. 기준이 10%보다 높으면 10%에서 비상 알림 한 번 더 (기존 20/10 동작의 일반화)
- 검증: `package-app.sh`로 패키징해 실기기 메뉴바에서 "로봇 79%" 표시 확인 후 원래 앱 복구

## 교훈

- **샌드박스 셸에서 직접 실행한 바이너리는 NSStatusItem이 안 뜬다** — 프로세스는 살아있는데 메뉴바 아이콘이 등록되지 않음. 개발 검증은 `package-app.sh` → `open Zappy.app` 경로로 할 것
- 최상위 실행문이 있는 Swift 스크립트 파일은 `main.swift`여야 swiftc가 컴파일함
- ASC 상품 ID는 `com.hong.zappy.plus.unlock` (`.plus`에서 변경됨, 커밋 421627e) — 문서에 옛 ID가 남아있으면 헷갈리니 주의
