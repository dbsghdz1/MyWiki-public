# Zappy 개발 기록 2026-08-11 — 1.3.0 UI 품질 개편 + 4프레임 모션

"퀄리티 있는 앱처럼 보이게"를 목표로 UI 셸을 갈아엎고 모션을 두 배 부드럽게 만들었다. 커밋 6개(`ce37608`~`9079304`), 각 커밋 시점 빌드 검증 완료. 출처: Claude 대화, 2026-08-11.

## 결정

- **퀄리티 체감은 기능이 아니라 표면(UI 셸)에서 갈린다** — 기본 NSMenu/NSAlert 조합이 "잘 만든 유틸"에서 못 벗어나는 원인이라 판단, 우선순위를 ①테마 그리드 ②페이월 창 ③온보딩 ④정보 디테일 ⑤모션 프레임으로 정했다. 그리드가 1순위인 이유: 매일 보는 화면이자 무료 사용자에게 유료 테마를 진열하는 공간(BM 직결).
- **테마 메뉴 = 카드 그리드** (`ThemeGrid.swift`, NSMenuItem.view 커스텀 드로잉): 무료 8종 블록 + "Zappy+" 캡션 + 유료 5종 블록, 호버 하이라이트·선택 링·자물쇠 배지. 미리보기 규칙은 1.2.0 스펙 유지(미구매 = 무료 흑백·유료 컬러+자물쇠, 구매 후 = 설정 따름).
- **결제 순간은 시스템 알럿에 맡기지 않는다** (`Paywall.swift`): 유료 테마 5종이 실제로 움직이는 미리보기 + 혜택 3줄 + StoreKit `displayPrice` 버튼 + 복원. "한 번 구매 · 구독 없음" 명시.
- **모션은 아트 재작업 없이 진폭 보간으로**: `phaseAmp`(페이즈 0-1-2-3 → 진폭 0→0.5→1→0.5 왕복)·`phaseFlip`(반 주기 교차) 헬퍼로 기존 `phase % 2` 이진 토글을 전면 교체. 타이머 0.55s → 0.28s — 사이클 속도는 그대로, 프레임만 2→4. 로봇 팔은 좌표 보간으로 실제 스윙, 빗줄기는 연속 낙하(랩어라운드).
- **앱 아이콘 플랫 시안 보류** (revert 커밋): 새 시안이 macOS 표준 투명 여백(~10%) 없이 캔버스를 꽉 채워 독에서 다른 앱보다 커 보임. 여백 보완 전까지 기존 아이콘 유지.
- 같은 날 별도 세션이 **너구리 라면 충전 씬 옆모습 리디자인 + 불꽃 잔량 가속 커브(t^1.35)** 작업 — 파일 소유를 나눠(그쪽 Themes/Mono 캐릭터 함수, 이쪽 App/신규 파일) 동시 진행하고, phase 관련 수정만 역적용/복원하는 방식으로 커밋을 세션별로 분리했다.

## 1.3.0에 들어간 것

- 테마 카드 그리드 · Zappy+ 페이월 창 · 첫 실행 온보딩(테마 안내·기본 배터리 숨기기·자동 실행)
- 메뉴 정보 한 줄 강화: "배터리 72% · 3시간 12분 남음" / "완충까지 1시간 5분" (IOPS 추정, 불명이면 생략) + 아이콘 툴팁·VoiceOver 라벨 + About 메뉴 — 신규 문구 5개 언어 로컬라이징
- 상시 모션 4프레임, 너구리 옆모습·불꽃 가속 커브, 버전 1.3.0 범프

## 교훈

- **오프스크린 렌더(cacheDisplay)는 appearance가 어긋난다**: 뷰는 앱 유효 appearance(다크)로, 이후 NSImage 합성 블록은 기본(라이트)으로 해석돼 "흰 글자 + 투명 배경" PNG가 나온다. 해법: 뷰·창에 `NSAppearance(named: .aqua)` 강제 + 배경색 합성 후 저장.
- **2프레임용 코드에 4페이즈를 얹으면 조용히 깨진다**: `phaseFlip(0) == phaseFlip(1)`이라 GIF 생성기가 페이즈 0/1로 뽑던 충전 GIF(번개 등)는 같은 포즈 두 장이 된다 — 반 주기 간격인 0/2로 수정.
- 메뉴 popUp 자동화(`-openMenuOnLaunch`)는 headless 검증용으로 불안정 — 화면 검증은 renderShots 경로가 확실하다.

## 재사용 지식

- **개발자 플래그 `-forceCharging YES` / `-forceLevel N`** (2026-08-12 추가): 충전기 없이 충전 씬·잔량별 반응 확인. argument domain이라 프로세스 종료 시 자동 해제. `-devFullAccess YES`(Zappy+ 강제)와 조합 가능.
- **`-renderShots <폴더>` 디버그 플래그** (2026-08-11 기준): `open Zappy.app --args -renderShots /경로` → 그리드·페이월·온보딩을 PNG로 렌더하고 종료. 스토어 스크린샷·문서용 캡처 자동화에 재사용 가능. 기존 `-screenshotBackdrop`/`-openMenuOnLaunch`와 같은 argument domain 패턴.

## 추가 (08-12 새벽) — 소다 테마 + 그리드 흐림 수정

- **소다 테마 신설** (Zappy+ 6번째, 커밋 fdc0a30): 잔량 = 남은 음료 — 100% 얼음·탄산 가득 → 50% 절반 → 25% 얼음 거의 녹음 → 10% 빨간 빨대 + 갈라진 얼음. 충전 = 음료가 차오르며 기포 상승 — **"충전 중 모션 정지"(1.2.0) 규칙의 유일한 예외** (씬 자체가 차오르는 중이라서). 모노판 수면 얼굴 처리는 splitFace 재사용.
- 사용자가 제안한 플랫 앱 아이콘 방향은 폐기 확정 (음료 컨셉은 테마로 흡수).
- **그리드 흐림 수정**: 모노 미리보기를 secondaryLabelColor(회색)로 틴트한 게 원인 — 메뉴바 실물은 labelColor 농도로 렌더되므로 미리보기도 labelColor로 + `allowsVibrancy` 차단. 교훈: 메뉴 커스텀 뷰 미리보기는 실물과 같은 색 시스템을 써야 한다.
- 페이월 "모션 테마 6종"으로 갱신, 레퍼런스에 soda 잔량 스트립·충전 GIF 추가.
- 로봇 충전 씬을 서 있기 → **바닥에 앉아 쉬기**로 교체 (사용자 제안) — 저잔량 주저앉기 기하 재사용, 머리는 들고 흐뭇한 감은 눈. "충전 = 쉬는 시간" 콘셉트 강화. 다리는 몸통 밖까지 뻗고 발끝을 세워야 실루엣이 읽힘 (가리면 옆 덩어리로 보임).
- 교훈: **iconScale 확대 테마는 전폭 구도 씬에서 잘린다** — 로봇(1.1배)의 충전 씬은 벽 콘센트가 왼쪽 끝(x 1.2)에 있어 확대 시 캔버스 밖으로 나감. 충전 중엔 스케일 1.0으로 해제 (iconScale에 charging 파라미터 추가).
