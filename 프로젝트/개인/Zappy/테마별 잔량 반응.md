# Zappy — 테마별 잔량 반응 정리

코드(Themes.swift) 기준의 확정 명세. 시즌 테마를 새로 만들 때 이 문법을 따른다. (1.14.0 기준, 2026-09-04 갱신 — 날씨·사과·선인장·해파리 09-04 다듬기; 풍선 08-28 신설; 나무 08-25 신설; 선인장·해파리 08-21 신설; 유령·슬라임은 08-14 리디자인, 소다는 08-12 신설)

## 공통 문법

- **잔량 색상(levelColor)**: >50% 초록 · 21~50% 노랑 · ≤20% 빨강 — 배터리형 테마의 채움색과 로봇 코어·역도 플레이트 등 보조 신호에 사용
- **≤20% = 시무룩 라인**: 모든 테마가 20% 이하에서 슬픈 표정 또는 특수 상태로 전환. 저전력 알림 기본 기준(20%)과 일치시킨 설계
- **충전 중**: 모션 없음 — 테마별 정적 **휴식 씬**으로 전환한다(1.2.0에서 "충전 숨쉬기(bobbed)" 애니메이션을 완전히 제거. 근거: [[프로젝트/개인/Zappy/Zappy 개발 기록 2026-08-08|개발 기록 08-08]] — 고객 명시 요청 + bobbed 재그리기가 픽셀 깨짐의 원인). 소다 테마만 예외로 충전 기포 모션이 있다([[프로젝트/개인/Zappy/Zappy 개발 기록 2026-08-11|개발 기록 08-11]]) → 08-14 갱신: 예외를 소다·유령·슬라임("차오르는 씬")으로 확장([[프로젝트/개인/Zappy/Zappy 개발 기록 2026-08-14|개발 기록 08-14]])
- **모션 테마 4단계 표준**: 70 / 40 / 20 경계 (로봇·역도·날씨·사과 적용, 2026-07-28 확립)
- **상시 애니메이션 조건**(App.swift shouldAnimate): **충전 중에는 false**(휴식 씬) / 로봇 ≥20 / 역도 항상 / 날씨 <20(빗줄기) / 사과 ≥20 (0.55초 2프레임 토글) → 1.6.0(08-17 출시)에서 Zappy+ 상시 모션 추가: 불꽃 일렁임·해 광선 회전·소다 탄산 기포([[프로젝트/개인/Zappy/App Store 심사 이력|심사 이력]] 08-15 행) → 1.8.0: 선인장 ≥70 벌 맴돌기 → 1.9.0: 해파리 >20 맥동 → **1.10.0: 나무는 잔량 조건 없이 항상 true**(계절이 곧 모션 — 방전 직전에도 눈은 내린다) → 1.12.0: 충전 모션 예외(차오르는 씬)에 풍선 펌프 추가 — 소다·슬라임·풍선 (유령은 1.11.0 반짝이 제거로 예외에서 빠짐) → **1.14.0: 날씨·사과는 잔량 무관 항상, 선인장 ≥40; 충전 모션 예외에 선인장(물방울)·해파리(공기방울)·날씨(번개)·사과(고치 zzz·나비) 추가**

## 배터리형 (잔량 = 채움 높이/너비)

| 테마 | 잔량 표현 | >20% | ≤20% |
|---|---|---|---|
| 모찌 | 몸통 가로 채움 (levelColor) | 방긋 | 시무룩 |
| 픽셀 | 8비트 가로 채움 | 방긋 | 시무룩 |
| 고양이 | 몸통 가로 채움 + 귀·수염 | ω 수염입 | 일자 입 |

## 변형형 (잔량 = 형태 자체의 변화)

| 테마 | 잔량 표현 | 세부 단계 |
|---|---|---|
| 슬라임 | **잔량 = 연속 볼륨** — 꼭대기 높이·퍼짐이 잔량 함수로 연속 변화 (1.5/1.6.0 리디자인 08-14. 이전: 컬러는 색(levelColor)만, 모노만 몸집 축소 2026-08-08 → 컬러도 볼륨 문법으로 통일) | 만땅 = 탱글 꼭지 → 잔량에 따라 높이·퍼짐 연속 변화 (구 2단계 문법의 ≤20% "바닥에 넓게 퍼짐 + 물방울"은 연속 변형에 흡수) · **충전 = 방울이 떨어져 흡수될 때마다 바운스** |
| 유령 | **잔량 = 불투명도 + 부양 높이** (소멸 문법, 08-14 리디자인. 이전 "몸속 물 차오름"은 모찌·픽셀과 겹쳐 폐기) | 투명해지며 가라앉음 → 저전력 = 흩어지는 입자 + 당황한 빈 눈 + 물결 입 · **충전 = 반짝이며 실체 회복** |
| 소다 | **잔량 = 남은 음료** (Zappy+ 6번째, 08-12 신설) | 100% 얼음·탄산 가득 → 50% 절반 → 25% 얼음 거의 녹음 → 10% 빨간 빨대 + 갈라진 얼음 · **충전 = 음료가 차오르며 기포 상승** · 1.6.0부터 상시 탄산 기포 |
| 달 | **잔량 = 월령** (그림자가 왼쪽부터) | 100% 보름달 → 50% 정확히 반달 → ≤20% 감은 눈 + 시무룩 + zzz |
| 눈사람 | **잔량 = 녹는 정도** (melt = t^1.35, 낮을수록 급가속) | ~75% 발밑 물웅덩이 시작 → ≤55% 땀 삐질 → ≤45% 우물쭈물 일자입 → ≤20% 웅덩이에 잠긴 머리 + 떨어진 당근. 몸통 높이 충분할 때만 단추 2개 |
| 불꽃 | **잔량 = 불꽃 크기** (몸통 3겹 + 왕눈이) | >55% 좌우 날름 불길 2개 → >35% 왼쪽 날름 1개 → ≤20% 꺼져가는 작은 불 + 연기 2줄 |
| 사과 | **잔량 = 남은 사과** (애벌레가 **배터리를 쓰는 만큼 계속** 갉아먹음, 1.14 연속형) — 자국 8개가 순서대로, 잎은 초록→갈색으로 처짐. 사과엔 얼굴 없음(애벌레만) | >90% 온전한 사과 + 구멍에서 쏙 들어갔다 빼꼼 → 90~20% 자국이 8.75%마다 하나씩(마지막 자국은 옴뇸뇸 박자에 벌어짐, 입 벌림) + 속살 → ≤20% 사과심 + 배부른 애벌레 쿨쿨(zzz 떠오름) · **충전 = 사과 위 고치에서 쿨쿨(zzz), 100%+전원이면 나비**(날개 팔랑, 충전 모션 예외). 상세: [[프로젝트/개인/Zappy/Zappy 개발 기록 2026-09-04\|개발 기록 09-04]] |
| 풍선 | **잔량 = 부푼 크기** (Zappy+ 10번째, 1.12.0 08-28 신설) — r=3.05+3.85t, 매듭 아래 고정이라 빠질수록 내려앉음. 색은 levelColor 3단계의 풍선 파스텔 | >72% 주름 없음·하이라이트 → 주름 1→2→3개, 끈이 구불거림(wobble 1.0+2.6(1−t)) → ≤20% 시무룩. 표정 >45% 웃음 · 21~45% 일자 · **충전 = 발펌프 4프레임**(r 3.3→6.9, 끈 대신 호스, "차오르는 씬" 예외 4번째) — 슬라임과 구분: 슬라임은 퍼지며 무너지고 풍선은 원형 유지한 채 줄어든다 |

## 생기형 (잔량 = 식물의 생기)

| 테마 | 잔량 표현 | 세부 단계 |
|---|---|---|
| 선인장 | **잔량 = 생기** (Zappy+ 7번째, 08-21 신설) — 몸통 높이·폭, 팔 각도(만세↔처짐), 초록→올리브 색이 연속 변화 | ≥70% 꽃 활짝 + **양팔 엇갈려 살랑 + 벌이 꽃 주위 궤도**(1.14) → ≥40% 봉오리 **톡톡 부풂**(1.14) → 꽃 없음 → ≤20% 떨어진 꽃잎 + 화분 금 + 주름 + 시무룩 · **충전 = 물뿌리개 휴식 씬**(눈 감고 흐뭇, **물방울 낙하** 1.14 충전 모션 예외). 모노는 골·주름 생략(실루엣 보호). 상세: [[프로젝트/개인/Zappy/Zappy 개발 기록 2026-08-21\|개발 기록 08-21]] · [[프로젝트/개인/Zappy/Zappy 개발 기록 2026-09-04\|09-04]] |

| 해파리 | **잔량 = 부력** (Zappy+ 8번째, 08-21 신설) — 부양 높이·갓 크기·촉수 길이가 연속 변화, ≥50% 발광. **얼굴은 눈만**(1.14, `jellyFace = .eyes` — 입 제거, 시들면 반쯤 감김) | >20% **수축하며 위로·이완하며 아래로** 헤엄(1.14 추진 리듬, 촉수 반박자 지연, 발광 동기) → ≤20% 바닥에 주저앉고 촉수 늘어짐 + 졸린 눈 · **충전 = 해저 휴식**(눈 감고 **공기방울 상승**, 1.14 충전 모션 예외). 모노는 하이라이트 생략. 바닥·배경 소품 없음(캐릭터만) |
| 나무 | **잔량 = 계절** (Zappy+ 9번째, 08-25 신설) — 계절 이름은 25%씩 네 칸이지만 **잎의 양·색은 잔량의 연속 함수**(`leaf` 1.0→0.7→0, 색은 정점 보간). 잎덩어리 5개가 문턱값 순으로 사라지며 작아진다 | >75% 봄 벚꽃(분홍, 꽃송이 반점) → >50% 여름 무성(초록) → >25% 가을 단풍·낙엽(노랑→빨강, 잔가지 드러남) → ≤25% 겨울(잎 0, 가지에 눈, 시무룩) · **상시 모션 = 꽃잎·잎·낙엽·눈이 흩날림 + 잎 살랑** · **충전 = 볕을 쬐며 광합성**(눈 감고 흐뭇, 정지). 모노는 봄만 knockout 꽃송이로 구분하고 눈은 knockout 틈으로 얹는다 |

## 캐릭터 활력형 (잔량 = 기력)

| 테마 | 단계 |
|---|---|
| 로봇 | ≥70% 춤(팔 교차·다리 들썩·반짝이) → ≥40% 팔 살랑 → ≥20% 주저앉아 고개 떨굼(지친 숨) → <20% 전원 꺼짐(회색 눈·처진 안테나) |
| 너구리 | 꼬리 각도 = 잔량(바짝↔처짐). ≥70% 만세 → 40~70% 보통 → <40% 팔·귀 처짐 → ≤20% 웅크려 잠 + 꼬리로 몸 감싸기 + zzz |
| 역도 | **잔량 = 바벨 높이**. ≥70% 머리 위 프레스 성공(들썩) → ≥40% 가슴에서 낑낑 → ≥20% 무릎에서 용쓰기(>< 눈) → <20% 기진맥진·가쁜 숨. **충전 = 휴식**: 바벨 내려놓고 물 벌컥벌컥 |
| 날씨 | **잔량 = 구름이 해를 가린 정도** (1.14 연속형, `WeatherGeom`). **얼굴은 해에만** — 구름은 날씨(상태). 100% 맑음 → 85% 저 멀리 구름 한 점 → 55% 닿음 → 40% 오른쪽 눈 하나 → 25% 다 가림(해는 60%부터 조금 작아짐) → <20% 짙은 구름 + 비 · 상시 모션 = 광선 회전 + 구름 떠다님 + 빗줄기 · **충전 = 먹구름 + 번개가 실제로 침**(페이즈 0·2, 충전 모션 예외) + 먹구름 뒤 작은 해 빼꼼 |
