# Zappy 3D 눈사람 (Blender) 2026-08-09

Blender MCP로 눈사람 테마를 3D화하고, 녹는 4단계와 충전(함박눈+복구) 애니메이션 클립까지 만들었다. 마케팅용 비주얼 실험. 출처: Claude 대화, 2026-08-09.

## 산출물 (`(로컬 경로)`)

- `zappy-snowman-3d.png` — 히어로 스틸 (100%, 1600×1000, EEVEE)
- `zappy-snowman-charge.gif` / `.mp4` — 8.3초 100프레임 루프: 방전(100→10%, 녹음) → 충전 시작(함박눈 40송이) → 눈사람 복구 → 완충 반짝(십자 별 6개 트윙클)
- 녹는 4단계 스틸(75/55/45/15%)은 세션 스크래치에만 있음 — 필요하면 아래 로직으로 재생성

## 디자인 결정

- **2D 문법을 그대로 3D 이식**: melt = t^1.35 공식, 치비 2등신(얼굴 크게), 코코아 브라운 이목구비, 단계 연출(75% 웅덩이 시작 → 55% 땀 → 45% 일자 입 → ≤20% 머리 잠김+당근코 낙하)을 [[프로젝트/개인/Zappy/테마별 잔량 반응|테마별 잔량 반응]] 명세대로 구현
- **충전 = 함박눈 + 복구 + 반짝**: 1.2.0 충전 휴식 씬(함박눈)을 확장해 "눈을 맞으며 다시 차오른다"로 연출. 충전 중 땀방울은 제거(휴식 콘셉트 위배)
- **상태는 전부 `apply_melt(level)` 파라메트릭 함수 하나로**: 몸통 스쿼시·머리 침하·얼굴 추종·소품 표시/숨김을 잔량 하나로 구동 → 임의 잔량 스틸이나 애니메이션 커브를 자유롭게 뽑을 수 있다. 키프레임 대신 프레임 루프에서 함수 호출 후 스틸 렌더 → ffmpeg 조립

## 재사용 로직 요지 (재생성용)

- 잔량 커브: 프레임 1–30 방전 100→10(smoothstep), 31–36 홀드, 37–72 충전 10→100, 73–100 완충+반짝. 12fps
- 몸통: `scale=(1+0.4m, 1+0.4m, 0.9(1-0.55m))`, 머리 침하 `1.0·m^1.6`, 웅덩이 반지름 `1.15+2.1m` (m=melt)
- 눈송이: 인덱스 기반 결정적 속도/오프셋으로 z 루프 낙하 + sin 스웨이 (`z = 5.4 - ((t·speed+off) % 5.2)`)
- Blender 조작 기술 교훈은 [[_wiki/AI 디자인 스킬|AI 디자인 스킬]]의 "Blender MCP 실전 노하우" 참고
