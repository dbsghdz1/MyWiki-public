## 2.1 정보 요청 (2026-07-25)

신규 개발자 계정 첫 제출에 관례적으로 오는 요청이며, 특히 메뉴바 전용 앱(LSUIElement)은 심사관이 "창이 안 뜬다"고 느끼기 쉬워 잘 받는다. [[프로젝트/개인/BarStack/App Store 심사 이력|BarStack]]도 동일한 2.1을 받았다 — [[_wiki/Sources/2026/07/2026-07-22-apple-app-review-2-1-information-needed-barstack|BarStack 2.1 원문]].

요구 7항목 중 Zappy에 실질 해당하는 것은 화면 녹화뿐이다 (계정·결제·UGC·외부 서비스 없음).

### 대응 (회신 + Notes 필드 동시 기입)

1. **화면 녹화** — QuickTime으로 1~2분: 실행 → 메뉴바 아이콘 등장 → 알림 권한 팝업 → 메뉴 열기(배터리 %) → 테마 전환(달·눈사람·불꽃) → 모노/컬러 전환 → 자동 실행 토글 → 충전기 연결(번개+애니메이션). 유튜브 미등록/Drive 링크로 첨부
2. **테스트 기기** — MacBook Pro 14" (Apple Silicon) + macOS 버전
3. **목적/대상** — 잔량을 캐릭터 상태로 전달하는 메뉴바 유틸리티, 전 연령
4. **사용법** — 로그인 불필요. 메뉴바 전용 앱(의도적으로 Dock 아이콘·메인 윈도우 없음, LSUIElement) 명시
5. **외부 서비스** — 없음 (Apple 프레임워크만, 네트워크 미사용)
6. **지역 차이** — 없음
7. **규제 산업/서드파티 자료** — 해당 없음, 전부 오리지널 아트워크

영문 회신 전문은 2026-07-25 세션에서 작성 완료 (Resolution Center 회신 + App Review Information Notes에 붙여넣기).

## 1.1.0 제출 (2026-07-31)

Zappy+ IAP를 포함한 1.1.0을 심사에 제출했다 (사용자 확인). 첫 인앱 결제 심사이므로 체크 포인트:

- IAP 상품도 앱 버전과 **함께 심사**되므로, 상품 상태가 "Waiting for Review"로 같이 넘어갔는지 확인
- 심사관이 구매 흐름을 못 찾으면 2.1이 올 수 있음 — 심사 노트에 구매 경로(메뉴 → 잠금 테마 🔒 클릭 → 구매 시트) 안내 여부 확인
- 구매 복원(Restore Purchases) 버튼 부재는 3.1.1 반려 사유 — 빌드에 포함되어 있음

## 교훈

- **fastlane precheck 자체 오류("ran into a problem")는 제출과 무관하다** — 1.3.0·1.6.1·1.7.0 세 번 모두 났고 세 번 다 제출은 성공했다. 로그에서 볼 것은 `Successfully submitted the app for review!` 한 줄이고, 최종 판정은 `asc state`
- **출시에서 기능을 뺄 땐 산출물로 확인한다** — 릴리즈 바이너리 `strings`에서 그 기능 문자열이 사라졌는지, 살아 있어야 할 문자열 하나를 대조군으로 함께 본다 (1.7.0 데스크톱 펫). 소스만 보고 "껐다"고 판단하면 저장된 설정·번들 에셋 같은 다른 경로가 남는다
- 메뉴바 앱은 **심사 노트에 LSUIElement 안내를 반드시 선제 기입** — BarStack·Zappy 모두 이 지점에서 심사 마찰 발생
- **호버·트래킹처럼 실기에서만 확인되는 연출은 릴리즈 전 수동 체크리스트로 확인한다** — 1.6.0 호버 하트는 코드가 다 맞는데 셀렉터 이름만 어긋나 한 번도 동작하지 않은 채 출시됐고, 그 기능이 What's New에 5개 언어로 광고돼 있었다. 사후 확인은 `strings -a <바이너리> | grep '^mouseEntered'`가 가장 빠르다
- **스크린샷은 실제 UI가 대부분이어야 함(2.3.3)** — 홍보형 이미지는 반려. 캡처를 배경+캡션 위에 올린 합성도 엄격한 심사관에겐 반려됐다(2026-07-30). 가장 안전한 것은 **무가공 풀스크린 원본**. 그리고 Media Manager의 **모든 사이즈 슬롯**을 청소해야 한다 — 첫 업로드가 전 사이즈에 복사되어 남는다
- **Support URL은 문의 수단(이메일)이 보이는 페이지여야 함(1.5)** — 소개만 있는 페이지는 반려. 공유 링크의 `?source=copy_link` 같은 파라미터는 제거
- `Package.swift`(SPM)로 Archive하면 Generic Archive가 되어 업로드 불가 — 반드시 `Zappy.xcodeproj`로
