# Zappy 개발 기록 2026-08-28 — AirPods 반증 + 풍선 테마 (1.12.0)

## 1. AirPods 행 검증 실패 — macOS 26에서 전제 반증

홍 제보 "에어팟 끼고 있는데 안 나온다" → 1.11.0 미검증 리스크의 실검증. **코드 버그가 아니라 소스 부재**: macOS 26.5.1은 에어팟을 IORegistry에 아예 안 올린다(`BatteryPercentLeft` 키 0개, MAC 주소 노드 0개, `IOBluetoothDevice` 계열 클래스 공백). 같은 시각 `system_profiler`는 좌 100%·우 99% 표시 — 잔량은 유저스페이스 bluetoothd만 안다. 셸아웃 대체도 불가(링크 유휴 시 필드가 사라지는 일시적 값, `-json`엔 기기가 통째로 빠지기도). 1.11.0은 이미 READY_FOR_SALE이라 심사 취소 선택지 없음 → 1.12.0에서 제거 결정. 상세: [[작업노트/Apple/블루투스 기기 배터리 읽기]] 08-28 항목.

교훈(심사 이력에도 기록): **"미검증 제출"로 표시한 리스크는 What's New에 실리기 전에 검증한다** — 광고한 기능이 최신 macOS에서 동작하지 않는 상태가 됐다.

## 2. 풍선 테마 (Zappy+ 10번째 모션 테마)

`(로컬 경로)`의 명세(08-25 작성, BalloonGeom 수식 + SVG 좌표 원본 + 레퍼런스 렌더)를 그대로 구현. 이월 후보 소진 후 첫 "명세 패키지 → 구현" 흐름 — SVG(viewBox 22×22, y-down) 좌표를 캔버스 35×22 y-up으로 **x+6.5, y=22−y** 이식하고, SVG `q`(2차 베지어)는 `quadCurve` 헬퍼로 3차 승격.

- **잔량 = 부푼 크기**: r=3.05+3.85t, 매듭 y 고정이라 빠지면 내려앉음. 주름 0→3개, 끈 wobble 1.0+2.6(1−t), 하이라이트는 t>0.26. 표정 >45% 웃음 · 21~45% 일자 · ≤20% 시무룩
- **색은 levelColor 3단계를 풍선 파스텔로**: 초록 `#AEE0BB` / 노랑 `#FBE09C` / 빨강 `#F5B0B0` — 새 색 규칙 안 만듦
- **충전 = 발펌프 4프레임** (r 3.3→6.9, 손잡이 교대) — **홍 결정: 정지 씬 대신 펌프 모션**, "차오르는 씬" 예외 4번째(소다·유령→제거됨·슬라임 다음). 명세의 0.5s 대신 앱 표준 0.28s 타이머 사용. 충전 중 얼굴·하이라이트는 프레임 r의 등가 t로, 색은 초록 고정, 주름 없음, 끈 대신 호스(SVG 실측으로 확인)
- **모노**: 주름·하이라이트 생략(실루엣 보호), 펌프는 knockout 여백 위에. 상시 모션 없음
- 등록: enum·paidMenuOrder 끝·디스패치 2곳·shouldAnimate·Paywall 미리보기(충전 씬)·L10n 4언어(Balloon/ふうせん/Globo/氣球)·Widget ThemePick+xcstrings·generate.swift
- 검증: 렌더 스트립(컬러/모노 8단계 + 충전 4프레임) → 실기 메뉴바 22pt 확인(충전 펌프 씬). 비충전은 렌더로(-forceCharging 언플러그 불가)
- **카운트 결정: 테마 18종 · 모션 테마 10종** — 설명문의 "모션 테마 = Zappy+ 블록" 등식 유지가 근거(소다도 1.3.0 충전 기포만으로 모션에 들었던 전례)

## 3. 스토어 문구에서 낡은 광고 2건 발견·정정

설명문(5로케일)이 **1.2.0에서 없어진 "충전 숨쉬기"** 와 **1.11.0에서 제거한 "충전 완료 연출"** 을 아직 광고하고 있었다 → 휴식 씬·완충 알림(옵션)으로 교체. 기능을 빼는 릴리즈에서 release_notes만 고치고 description을 안 훑은 것이 원인 — **기능 제거 시 description도 grep**.

## 4. 랜딩 나무 누락 보충
