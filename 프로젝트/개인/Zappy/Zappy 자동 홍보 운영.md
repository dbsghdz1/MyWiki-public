# Zappy 자동 홍보 운영

## 목표

Oracle Hermes가 Mac 전원 상태와 무관하게 Zappy 홍보 소재를 준비하고 Slack `#zappy`에 전달한다. X 게시물은 사용자가 직접 올리며 Hermes는 외부 SNS에 자동 게시하지 않는다.

## 일정

- 일요일 18:00 KST: 다음 주 소재의 디자인 필요 여부 점검
- 월·수·금 19:00 KST: 홍보 초안 1건 생성, 기존 GIF/PNG 선택, Slack 미리보기 전송
- 엔진: Hermes cron 6개 엔진은 2026-08-17부터 `ollama-cloud/gpt-oss:120b`

## 디자인 정책

- 기존 마케팅 GIF와 실제 앱 캡처를 최우선으로 재사용한다.
- 새 정적 카드·플랫폼별 크롭이 꼭 필요할 때만 디자인 에이전트를 실행한다.
- 브랜드 팔레트: cream `#F8F3EB`, ink `#3E2E24`, pink `#EE7290`, soft `#FBE3EA`, border `#EADFD2`.
- 귀여움은 캐릭터가 담당하고 문구는 담백하게 유지한다.
- 새 디자인은 오탈자·잘림·제품 사실을 육안 검수한 후 Slack에 보낸다.

## 채널 경계

- X: Hermes가 Slack `#zappy`에 완성 카피·GIF·링크를 보내고 사용자가 직접 게시한다. X API PPU 비용이 있으므로 자동 게시하지 않는다.
- Threads: 계정/API 연결 전까지 초안만 만들고 자동 게시하지 않는다.
- 디스콰이엇: 제품 등록은 완료. 메이커로그는 장문 초안과 최종 검토가 필요하다.
- Reddit: 커뮤니티 규칙 확인이 필요하므로 자동 게시하지 않고 초안만 만든다.
- Product Hunt: 날짜를 정한 런치 이벤트로 운영하며 최종 승인 없이 게시하지 않는다.

## 현재 연결 상태

- X 공식 CLI `xurl`: Mac에서 `@DevHongX` OAuth 2.0 연결과 읽기 API 검증 완료. 쓰기 요청은 `402 credits depleted`로 차단됐으며 Oracle 배포는 하지 않는다.
- Threads·Instagram Zappy 전용 게시 권한: 미연결
- Slack `#zappy`: 초안·GIF 미리보기 전송 검증 완료
- Slack 파일 업로드 권한 부족 시 완성 미디어만 ImgBB 링크로 자동 폴백
