## 결정

### 얼굴은 캐릭터에만 — 소품·날씨엔 없다
- **날씨**: 해·구름 둘 다 얼굴이 있어 캐릭터가 둘이었다. **얼굴은 해에만** 남기고 구름은 날씨(상태)로. 나무가 계절로 상태를 나르는 것과 같은 논리. 해는 늘 웃고, 시무룩함은 구름과 비가 맡는다.
- **사과**: 이미 얼굴은 애벌레뿐 — 구조 유지.
- **선인장**: 몸통이 초록 알약이라 얼굴 없으면 정체가 안 읽힘 — 유지.
- **해파리**: 부양 높이·촉수·맥동·발광만으로 상태가 읽히는 유일한 테마라 실험 대상. 눈만 / 없음 / 기존 세 판을 렌더해 비교(`jellyFace` 전역 스위치) — **눈만 남긴 판을 채택**(홍 "알아서 해줘"). 얼굴 없는 판은 모노에서 버섯으로 읽혔다. 시들면 눈이 반쯤 감긴다(아래로 볼록한 호).

### 사과 — "배터리를 쓰는 만큼 계속 갉아먹는다" (홍 요청: 단계를 더 늘려줘)
- 90% 위: 온전한 사과, 구멍에서 **쏙 들어갔다 빼꼼**(4페이즈, 페이즈 0 = 나온 자세 — 정지 미리보기가 이 프레임). 클립 rect로 구멍 아래는 안 보인다.
- 90%→20%: `AppleGeom.biteSlots` 8개가 순서대로 나타난다(자국 하나 = 8.75%). 마지막 자국은 잔량이 줄수록 커지고(0.45→1.0), **머리가 파고드는 박자에 0.8~1.0으로 벌어진다**("먹는 중"). 속살(cream)은 베어문 옆구리에서 안쪽으로 자라는 타원을 몸통에 클립해 그리고, 자국이 그 위를 뚫어 언저리에만 남는다.
  - 처음엔 애벌레 머리를 마지막 자국 위치에 뒀는데 **윗자국(꼭지 옆)을 먹을 때 잎과 겹쳤다** → 머리는 오른쪽 옆구리에 붙어 `eaten`만큼 안쪽으로 파고드는 고정 궤적(`hx = 24.6 − 3.4·eaten`)으로.
  - 처음엔 속살 타원을 알파로 페이드했더니 **안 베어문 껍질 위에 창백한 얼룩**으로 보였다 → 성장 타원 + 몸통 클립.
- 입: 머리가 사과에 닿는 페이즈에 벌어진 타원, 나머지는 방긋(`mouthOpen`).
- 20% 아래: 사과심 + 배부른 애벌레, zzz가 떠오르며 옅어진다(`shouldAnimate` 사과는 이제 잔량 무관 true).
- 잎: 꼭지 밑동을 축으로 +18°→−38° 처지고 초록→갈색(`leafAngle`, `tiltedOval`).
- **충전 씬이 아예 없었다** (홍 "사과일 때 충전 중일 때가 쪼금 아쉬운 것 같아" → 코드가 `charging`을 안 봄). 신설: **고치** — 사과 위 꼭지 왼쪽(잎은 오른쪽)에 세로 타원 + 실 두 줄 + 감은 눈, zzz 떠오름. **100% + 전원 = 나비**(분홍 날개 두 쌍, 반 주기마다 접었다 폄). 사과심 상태면 바닥 오른쪽. 충전 중 구멍은 안 그린다 — 빈 구멍만 남으면 검은 점으로 보였다. 첫 배치(y 17.8)는 캔버스 위에 닿아 17.0으로 내려 사과에 걸터앉게.

### 날씨 — 구름이 잔량의 연속 함수로 해를 가린다 (`WeatherGeom`)
- `cover = (0.95 − t)/0.70`, `approach = cover^1.5`(멀리선 천천히, 닿고 나서 빨리 — 40%에 오른쪽 눈 하나가 남는 배치). 100% 없음 → 85% 저 멀리 옅은 구름 한 점(`cloudAlpha`) → 55% 닿음 → 40% 눈 하나 → 25% 다 가림(`sunVisible = cover < 0.999`) → 20% 아래 비.
- 구름을 어떻게 해보다 크게 만드나 — 세 번 시도: ① 캔버스 밖에서 밀고 들어오기 → **잘린 반쪽 구름**이 버그처럼 보임. ② 밑동을 두껍게(`belly`) → **컵케이크**. ③ 꼭대기 고정 세로 늘리기(`stretch`) → **탑**. 채택: **구름은 제 모양을 지키고(최대 1.3배) 해가 덮임 60%부터 5.6→4.2로 작아진다(멀어짐)**. 왼쪽 끝은 항상 캔버스 안(0.3+)에서 시작해 잘리지 않는다.
- 상시 모션: 광선 회전(기존) + 구름 떠다님 ±0.35 + 빗줄기. `shouldAnimate` 날씨는 잔량 무관 true.
- 충전: 먹구름 + **번개가 실제로 친다** — 페이즈 0·2에만 자리를 바꿔 그리고 1·3은 먹구름만(번쩍임). 충전 모션 예외에 등록. 1.6~1.13은 충전 정지 규칙 때문에 번개가 한 자리에 고정돼 있었다(홍 "번개가 친다던지"로 발견). 먹구름 뒤 오른쪽 위에 작은 해(r 3.3)가 빼꼼 — iconScale 1.1이라 광선 끝 ≤ 21 유지.
- 모노: 구름 knockout 테두리(1.12배)를 먼저 뚫어 해·광선과 분리. 광선은 `rayAlpha`로 사그라든다.

### 선인장 — 팔·벌·봉오리·물방울
- `CactusGeom`에 `phase`·`charging` 추가(기본값 있는 `var` — `let`이면 memberwise init에서 빠져 컴파일 에러). 꽃 피면 `armWave`로 양팔이 엇갈려 살랑(±0.4), 벌은 `(27.0, 15.8)` 타원 궤도(4페이즈 = 한 바퀴) + 몸집 3.8×2.2·날개 2장·눈. 봉오리는 `bud`가 amp에 따라 0.6 부푼다. `shouldAnimate` ≥40.
- 충전: 물뿌리개 물방울이 떨어진다 — 간격 2.6 = 페이즈 이동 0.65×4라 이음새 없이 순환. 충전 모션 예외 등록.

### 해파리 — 실제 추진 리듬
- 수축(`pulse`)하면 갓이 좁고 길어지며 `bellBottom`이 0.6 오르고, 이완하면 퍼지며 내려온다. 촉수는 `phaseAmp(phase + 1)`로 반박자 늦게 살랑이고 수축 때 6% 더 늘어진다. 발광은 수축에 맞춰 밝아진다(`glowAlpha`).
- 꼭대기 한계: 만땅·수축에서 ≈21.5 — 처음 계수(8.8·0.9·1.09)로는 22.6이 되어 잘렸다 → 8.4·0.6·1.06.
- 충전: 공기방울이 올라간다(간격 3.6 = 0.9×4). 충전 모션 예외 등록.
