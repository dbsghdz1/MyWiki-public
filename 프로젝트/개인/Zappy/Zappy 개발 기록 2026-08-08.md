# Zappy 개발 기록 2026-08-08 — 첫 고객 피드백 반영 (1.2.0)

출시 나흘 만에 **첫 고객이 피드백 9건**을 줬고, 전부 1.2.0 (build 5)에 반영했다. 출처: Claude 대화, 2026-08-08.

## 피드백 → 반영 내역

| # | 피드백 | 반영 |
|---|---|---|
| 1 | 픽셀 테두리를 모찌 계열 진한 갈색으로 | `cocoaDeep`으로 교체 (보라끼 회색 → 갈색) |
| 2 | 볼터치 전부 제거 | `blushDot` 헬퍼·호출 전체 삭제 (픽셀의 분홍 픽셀 포함) |
| 3 | 역도: 충전 중 물 마시기 | 바벨 내려놓고 기울인 물병으로 벌컥벌컥 (기울기는 NSAffineTransform 회전) |
| 4 | 로봇: 충전 중 콘센트 | 벽 콘센트 + 플러그 + 케이블, 흐뭇하게 감은 눈 |
| 5 | 너구리: 충전 중 너구리라면 🍜 | 빨간 컵 + 면발 후루룩 + 김 |
| 6 | 사과: 애벌레 확대 | 세그먼트 반지름 ~23% 확대 |
| 7 | 충전 중 모션 정지 | `shouldAnimate`가 충전 시 false — "쉬는 시간" 콘셉트로 통일 |
| 8 | 눈사람: 충전 중 눈 내림 | 함박눈 10송이 정적 오버레이 (잔량 상태 유지) |
| 9 | 픽셀 깨짐 (특히 움직일 때) | 충전 숨쉬기(bobbed) 제거 + 픽셀 테마 안티앨리어싱 오프 |

## 결정

- **충전 = 휴식 씬, 모션 없음**: 기존 "충전 숨쉬기" 애니메이션을 완전히 제거하고 테마별 정적 휴식 씬으로 교체. 근거: 고객이 명시 요청 + bobbed 재그리기가 픽셀 깨짐의 원인.
- ~~충전 씬은 컬러 모드 전용~~ → **같은 날 모노판 4종도 구현 완료** (사용자 결정: 무료 사용자도 보게). 눈송이 링·물병 테두리·콘센트·라면 컵을 흑백 실루엣으로.
- 메뉴 미리보기 최종 스펙(1.2.0, 사용자 직접 구현): 미구매 = 무료 흑백·유료 컬러 + 회색 자물쇠(오른쪽 끝 정렬), 구매 후 = 모노/컬러 설정 따름. "기본 배터리 숨기기" 안내 메뉴도 추가됨.

## 추가 수정 (같은 날)

- **완충 시 씬 소실 버그**: `kIOPSIsChargingKey`는 배터리가 가득 차면 false → 콘센트를 꽂아둬도 씬이 사라짐. `kIOPSPowerSourceStateKey`(AC 전원) 기준 `plugged`로 트리거 변경, 완충 상태 라벨 "전원 연결됨" 추가. 실기기 검증: 충전 중 메뉴바에 라면 먹는 너구리 표시 확인.
