# BarStack 1.2 — Pro 일회성 IAP 계획

1.1이 2026-07-30 승인·출시되어 착수. 전략 배경과 가격 근거는 [[프로젝트/개인/BarStack/BarStack 로드맵과 유료화 계획|로드맵]]. **✅ = 결정됨, ❓ = 피드백 필요.**

> 취업 지원을 위해 MyCryptoDiary에 집중하기로 하면서 1.2 Pro는 착수하지 않는다. **지원 D-day는 2026-08-16에 12월 → `2026-11-14`로 앞당겨졌다.** 아래 계획은 재개 시점의 출발점으로 보존한다. 근거: 계획 우선순위 표.

## 확정 사항 (로드맵에서 이월) ✅

- **가격**: ₩7,700 일회성 IAP (Non-Consumable). 구독 없음.
- **무료/유료 경계**: 수동으로 쓰는 건 무료(핵심 숨김 영원히 무료), 알아서 움직이는 자동화는 Pro.
- **대표 기능**: 앱 트리거 — "Zoom을 켜면 메뉴바가 알아서 정리됩니다."

## 범위 ✅ A안 확정 (2026-07-30 사용자 결정)

- **A안 — MVP Pro (확정)**: IAP 인프라 + 앱 트리거 + 디스플레이 트리거. Shortcuts 액션·Always Hidden 존은 1.3으로. 근거: 결제 인프라가 처음 들어가는 버전은 작게 제출해 심사 리스크(3.1.2 등)를 분리하는 게 안전. 트리거 2종만으로도 "발표 모드" 스토리가 완성됨.
- **B안 — 풀 Pro**: 로드맵의 5종 전부(앱·디스플레이·시간 트리거, Shortcuts, Always Hidden). 판매 포인트는 풍성하지만 제출까지 오래 걸리고 심사 변수 증가.

## 구현 항목 (A안 기준)

### 1. Pro 구매 인프라 ✅ 방식 확정
- StoreKit 2 (`Product.purchase`, `Transaction.currentEntitlements`). 영수증 검증은 로컬(온디바이스) — 네트워크 제로 원칙 유지 가능(StoreKit 통신은 시스템 프레임워크가 담당, 앱이 직접 여는 네트워크 아님. 개인정보 문구 갱신 불필요 여부는 제출 전 재확인).
- 복원(Restore Purchases) 버튼 필수(심사 요구).
- App Store Connect: Non-Consumable IAP 생성(`pro.unlock` 형태), 심사용 스크린샷 필요.

### 2. 앱 트리거 (Pro 대표)
- `NSWorkspace.didLaunchApplicationNotification` / `didTerminateApplicationNotification` 구독 — 샌드박스에서 동작, 권한 불필요 (실행 목록을 읽는 게 아니라 알림 수신).
- 설정 UI: "이 앱이 실행되면 → 접기/펼치기" 목록. 앱 선택은 실행 중 앱 목록(`NSWorkspace.runningApplications`) + 응용 프로그램 폴더에서 선택.
- 동작 규칙: 트리거로 인한 접기/펼치기는 `userWantsExpanded`보다 우선하되, 트리거 앱 종료 시 이전 상태 복귀. 상세 상태 머신은 구현 시 설계.

### 3. 디스플레이 트리거
- 기존 `didChangeScreenParametersNotification` 재활용. 규칙: "외장 모니터 연결 시 펼침 / 노트북 단독(노치) 시 접힘" 토글 2개 수준으로 단순하게.

### 4. 페이월 UI ✅ 설정 Pro 탭 확정 (2026-07-30)
- 제안: 설정에 "Pro" 탭 추가(기능 소개 + 구매·복원 버튼) + Triggers 탭의 Pro 기능에 자물쇠 표시 → 클릭 시 Pro 탭으로. 팝오버는 건드리지 않음(무료 경험 오염 방지).
- 대안: 팝오버 하단에 작은 "Pro" 배지 노출(전환율↑, 그러나 미니멀함↓).

## 심사 대비 (1.0 경험 반영)

- **3.1.2**: 구매 버튼 근처에 가격·일회성임을 명시. 이용약관(Apple 표준 EULA) 링크.
- **심사 노트**: 구매 흐름 실기기 녹화 포함(1.0 요구사항의 학습). 샌드박스 테스터 계정 불필요(심사관은 자체 환경 사용)이나 IAP가 "심사 대기" 상태로 버전과 함께 제출되어야 함.
- 지역 가격: ₩7,700 기준으로 Apple 가격 티어 자동 적용 확인.

## 출시 타이밍 ✅ 완성 즉시 제출 (2026-07-30 사용자 결정)

- 기각된 대안: 리뷰 5개 이상 또는 2주 경과 후 제출 — 1.1의 리뷰 요청 코드가 이제 막 돌기 시작했으니, 무료 사용자 기반과 별점이 조금 쌓인 뒤 유료 기능을 얹는 게 로드맵의 "무료 우선" 원칙과 일치. 개발은 지금 시작하되 제출만 늦추는 것.
- 대안: 완성 즉시 제출(빠른 수익화, 리뷰 기반 약할 때 유료 전환 노출이 단점).
