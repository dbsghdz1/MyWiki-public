# BarStack — 아이디어 인박스

사용자가 던진 아이디어를 원문 그대로 보존하고, 에이전트가 해석·실현 가능성을 붙인다. 확정되면 [[프로젝트/개인/BarStack/BarStack 로드맵과 유료화 계획|로드맵]]이나 [[프로젝트/개인/BarStack/1.1 계획과 출시 직후 작업|1.1 계획]]으로 승격한다.

## 아이디어 1 — "활성상태 보기처럼" (2026-07-25)

> 사용자 원문: "CollectionTopBar 활성상태 보기 처럼 되었으면 좋겠다.!,.!"

"활성 상태 보기"는 macOS Activity Monitor의 한국어 이름이다. 해석이 갈려서 피드백 필요 ❓:

- **해석 A — 팝오버에 실행 중인 앱 목록 표시**: BarStack 팝오버에서 지금 실행 중인 앱들을 목록으로 보여준다. `NSWorkspace.runningApplications` 기반이라 **샌드박스에서 가능, 권한 불필요**. 단, "이 앱의 메뉴바 아이콘이 지금 숨겨져 있는지"와의 매칭은 불가능하다(그건 AX가 필요 — [[프로젝트/개인/BarStack/BarStack 개발 기록 2026-07-22|실측 근거]]). → **2026-08-16 갱신: 화면 기록 권한이 있으면 매칭 가능**해졌고, 실제로 "숨긴 아이콘 목록"으로 구현됐다([[프로젝트/개인/BarStack/BarStack 개발 기록 2026-08-16|개발 기록]]). 해석 A는 사실상 해소. 예전에 이 한계 때문에 실행 앱 목록 기능을 제거한 이력이 있어, 다시 넣으려면 "숨김과 무관한 단순 목록"이라는 것을 UI로 분명히 해야 한다.
- **해석 B — CPU·메모리 등 시스템 지표를 메뉴바에 표시**: Activity Monitor의 지표를 메뉴바에서 보는 것. 시스템 전체 지표는 샌드박스에서도 읽을 수 있으나, 이는 BarStack(아이콘 정리)의 문제 영역 밖이라 별도 앱 소재에 가깝다 — 개인프로젝트의 새 항목 후보. (2026-08-15: 예시로 들었던 '상단바 날씨' 아이디어 폴더는 삭제됨)
- **해석 C — BarStack 자체의 동작 상태 표시**: 접힘/펼침 상태, 자동 접힘까지 남은 시간 등을 팝오버에 보여주는 것. 가장 작게 구현 가능하고 1.1 온보딩과 자연스럽게 합쳐진다.

**현재 판단**: 미해결 — 사용자 피드백 대기. (해석 C면 1.1에 편입, A면 1.2 후보로 검토, B면 별도 프로젝트로 분리.)
