# BarStack 개발 기록 — 2026-07-22

App Store 심사 리젝 대응에서 시작해 앱을 세 번 재설계하고 제출 준비까지 마친 하루의 기록이다. 모든 검증은 실기기(MacBook Pro M5 Pro, macOS 26.5.1 + DELL 외장 모니터 듀얼) 실측으로 수행했다.

## 타임라인

1. **심사 리젝 접수** — Guideline 2.1 Information Needed (거절이 아닌 정보 요청). 실기기 녹화 + 앱 설명 7개 항목 요구.
2. **브랜딩·권한 흐름 정리** — 앱 이름을 BarStack으로 통일(CFBundleName, PRODUCT_NAME, CI의 APP_NAME). 불필요한 entitlement(다운로드·사진·음악·동영상 폴더 접근) 제거.
3. **핵심 발견: 샌드박스가 AX를 차단** — 손쉬운 사용 권한을 허용해도 샌드박스 빌드는 다른 앱 메뉴바 아이템을 0개 감지. 동일 코드의 비샌드박스 빌드는 15개+ 감지. App Store(샌드박스 필수)에서는 아이템 감지·클릭 실행이 원천 불가.
4. **"App Store만" 결정** — AX 의존 기능 전면 제거. 권한을 하나도 요청하지 않는 앱이 됨 (-1,833줄).
5. **숨김 메커니즘 3차 재설계** — 아래 기술 노트 참조. 최종: 펼침 상태에서만 보이는 `‹` 경계 핸들 + 10초 자동 접힘.
6. **껍데기 기능 제거** — 실행 앱 자동 그룹(-674줄), 프리셋·아이템 규칙 저장소(-526줄), 거짓 개인정보 문구 수정.
7. **제출 준비 완료** — 빌드 1.0 (3), 심사 회신 문서(`(로컬 경로)`), Figma 스크린샷 템플릿 12장(한/영), README·RELEASING 문서 갱신.

## 기술 노트: 샌드박스 메뉴바 숨김 (재사용 지식)

macOS는 앱이 다른 앱의 메뉴바 아이콘을 코드로 옮기는 것을 허용하지 않는다. 샌드박스 앱이 쓸 수 있는 유일한 수단은 **자기 NSStatusItem의 길이를 늘려 왼쪽 아이템들을 화면 밖으로 밀어내는 것**(Hidden Bar 방식)이다. 실측으로 확인한 함정들:

- **늘어난 아이템은 통째로 화면 밖에 배치된다.** 아이콘 아이템 자체를 늘리면 안 되고, 아이콘(정상 크기)과 스페이서(늘어나는 쪽)를 분리해야 한다.
- **macOS 26은 보이는 상태 아이템에 최소 폭을 강제한다.** 폭을 0~2pt로 줄여도 빈 캡슐 한 칸이 그려진다. 보이지 않는 경계를 원하면 `isVisible = false`뿐인데…
- **`isVisible` 토글은 세션 내 자리(slot)를 기억한다.** 저장된 preferred position을 무시하고 원래 자리로 복귀한다. 자리를 옮기려면 `removeStatusItem` 후 재생성해야 하며, 재생성도 한 번에 한 칸씩만 이동한다.
- **`NSStatusItem Preferred Position <autosaveName>`(UserDefaults)은 디스플레이 우측 끝에서의 거리다.** 화면 좌표로 계산하면 듀얼 모니터에서 값이 오염된다. 다른 아이템 옆에 붙이려면 그 아이템의 저장값 ± 1을 쓰는 것이 안전하다.
- **늘어난 상태의 위치가 autosave로 저장되면** 다음 실행에서 아이콘이 화면 밖에서 시작한다. 실행 시 저장값 범위 검사·복구가 필요하다.
- **늘림 길이는 화면 계산 없이 10,000pt 고정**이 안전하다. `NSScreen.screens` 기반 계산은 시점에 따라 일부 디스플레이를 놓친다.
- **결론: 코드로 보이지 않는 경계를 추적하지 말 것.** 경계를 사용자 눈에 보이게 하면(펼침 상태에서만 `‹` 표시) 위의 모든 꼼수가 불필요해진다. 최종 구현: 스페이서는 항상 존재, 펼침 시 `variableLength`+chevron 이미지, 접힘 시 10,000pt+이미지 제거. 접기 전 핸들이 아이콘 왼쪽에 있는지만 검사.

검증 방법도 기록해 둘 가치가 있다: 스크린샷 권한 없이도 **터미널의 AX 권한으로 모든 앱의 메뉴바 아이템 위치·크기를 실측**(`AXUIElementCopyAttributeValue` + `kAXExtrasMenuBarAttribute`)해 숨김 여부를 수치로 확인했다.
