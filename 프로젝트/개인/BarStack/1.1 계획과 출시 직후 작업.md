# BarStack 1.1 계획과 출시 직후 작업

1.0 출시(2026-07-25) 직후의 실행 계획. 전략 배경은 [[프로젝트/개인/BarStack/BarStack 로드맵과 유료화 계획|로드맵]] 참고. **✅ = 결정됨, ❓ = 피드백 필요.**

## 1.1의 목표

리뷰·별점 확보. 유료화(1.2)는 리뷰가 쌓인 뒤에만 의미가 있다. 1.1은 전부 무료 기능이고, 성공 지표는 기능 수가 아니라 **첫 리뷰 10개**다.

## 기능 4개 (핵심 숨김은 권한 없이 — 1.1.1의 목록은 화면 기록 권한 선택, 08-16 정정)

### 1. 첫 실행 온보딩 ✅
- 첫 실행 시 팝오버를 자동으로 열고 안내 표시: "⌘를 누른 채 아이콘을 ‹ 왼쪽으로 드래그하면 숨겨집니다."
- 구현: `UserDefaults`에 `hasCompletedOnboarding` 플래그, 첫 접기 성공 시 완료 처리.
- ❓ 온보딩을 팝오버 안 안내문으로 할지, 별도 창(2~3 스텝)으로 할지. 제안: **팝오버 안내문** — 창은 과하고, 설정 앱의 SetupGuideCard가 이미 상세 안내를 담당.

### 2. 팝오버 "잠깐 보기" 버튼 ✅
- Quick Reveal(단축키로만 가능했던 것)의 클릭 진입점. 팝오버 상단에 버튼 하나.
- 누르면 펼치고, 기존 Quick Reveal 타이머 규칙대로 자동 복귀.

### 3. ~~자동 접힘 시간 설정~~ → 명시적 펼침 유지로 대체 (2026-07-29 결정)
- 시간 피커(5초~1분)를 구현했다가 **제거**. 사용자 결정: "잠깐 보기가 있으니 항목 표시를 했을 땐 다시 사라지지 않게" — 명시적 펼침(항목 표시·핸들 클릭·계속 표시)은 사용자가 접기 전까지 유지, 임시 확인은 잠깐 보기/호버(Quick Reveal 타이머)가 담당.
- 결과적으로 시간 피커는 작동할 일이 없는 죽은 설정이 되어 UI에서 제거. 10초 타이머는 "접힘 저장 상태였는데 실행 직후 레이아웃 미준비로 펼쳐진 경우"의 회복용으로만 내부 유지.

### 4. 호버로 펼치기 ❓
- BarStack 아이콘에 마우스를 올리면 자동 펼침. 기존 2초 마우스 폴링 재활용이라 권한·전력 부담 없음.
- 열린 질문: 의도치 않은 펼침(마우스가 지나가기만 해도 펼쳐짐)이 거슬릴 수 있다. 제안: **기본 꺼짐, 설정에서 켜는 옵션**으로 넣고 반응을 본다.

## 리뷰 요청 (코드 작업, 1.1에 포함) ✅

- `SKStoreReviewController.requestReview` — 접기 동작 누적 20회 이후, 앱 활성 상태에서 1회 호출. Apple이 연 3회로 제한하므로 시점만 신중하면 됨.
- ❓ 호출 시점 대안: 접기 20회 vs 설치 3일 후 첫 실행. 제안: **접기 20회** — 가치를 체감한 사용자에게만 뜬다.

## ASO (코드 외 작업, App Store Connect에서)

- 부제(subtitle) 후보 ❓ 피드백 필요:
  - ko: "권한 요구 없는 메뉴 막대 정리" / en: "Tidy menu bar. Zero permissions."
- 키워드 후보 (4개 언어 각 100자):
  - en: `menu bar,hide icons,menubar,organizer,bartender,hidden bar,clean,notch,status bar,tidy`
  - ko: `메뉴바,메뉴 막대,아이콘 숨기기,정리,노치,상태바,숨김,깔끔,메뉴바 정리,바텐더`
  - ja/es는 en 기반 번역 후 현지 검색어 확인.
- ❓ 경쟁 앱 이름(bartender, hidden bar)을 키워드에 넣는 것: 정책상 허용되나(상표 침해만 아니면) 심사관 재량 리스크 소폭. 제안: **넣는다** — 발견성 이득이 더 큼.

## 커뮤니티 공개

- 채널: r/macapps, GeekNews, 디스콰이엇. 각 채널 1회, 출시 알림 톤(광고 톤 금지).
- 메시지 뼈대: "샌드박스 때문에 권한 없이는 못 만든다는 메뉴바 정리 앱을, 권한 제로로 만들었습니다. 무료입니다." (08-16 정정: 목록 기능은 화면 기록 권한 필요 — "권한 제로" 문구는 폐기, [[프로젝트/개인/BarStack/BarStack 개발 기록 2026-08-16|개발 기록 08-16]])
- ❓ 시점: 지금 바로 vs 1.1 온보딩 개선 후. 제안: **1.1 승인 후** — 첫인상에서 온보딩 부재로 별점 깎이는 것 방지. 단 GeekNews/디스콰이엇 같은 국내 채널은 지금 올려도 무방.

## 하지 않는 것 (재확인)

- 분석 SDK·크래시 리포터 — 네트워크 제로 포지셔닝 유지. 피드백 채널은 리뷰 + 지원 메일.
- 아이콘 목록·검색·미리보기 — AX/화면 기록 필요, [[프로젝트/개인/BarStack/BarStack 개발 기록 2026-07-22|실측 근거]]로 영구 제외.
