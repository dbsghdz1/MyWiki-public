## 무엇

해외에서 화제가 된 짧은 영상(강아지·아기·가족·스포츠·야생동물) 중 **크리에이티브 커먼즈 저작자 표시(CC BY)** 라이선스인 것을 골라, 세로 1080×1920으로 자르고 **상단 고정 훅 제목 2줄 + 등장인물 대사형 타이핑 자막**을 입혀 올린다. 포맷 참고는 조회수 685만의 해외 클립 쇼츠(10초, 대사형 자막) — 그 채널은 원본 라이선스가 일반이라 무단 사용으로 보였고, 우리는 CC만 쓴다.

- 채널: 「오늘 본 장면」 `@oneulbon`, 채널 ID `UCVQO1cK5874XudCzoYctHGQ`(홍의 개발용 구글 계정). 프로필 사진은 쇼츠 제목 스타일(검정·흰색·하늘색 + 노란 TODAY 배지)
- 수익 조건: 구독자 1,000명 + 최근 90일 쇼츠 조회수 1,000만 → 파트너 프로그램 신청 → 심사(약 한 달) → **승인 후 조회수부터** 수익. 한국 쇼츠 수익은 1,000회당 40~80원 추정(공개 사례 기준 해석, 채널마다 편차 큼)
- 수익화 위험: YouTube 파트너 프로그램의 재사용·비진정성 콘텐츠 정책. 남의 클립에 자막만 얹은 채널은 거절될 수 있다 — 지어낸 대사(창작 부분)가 채널의 독창성 근거다
