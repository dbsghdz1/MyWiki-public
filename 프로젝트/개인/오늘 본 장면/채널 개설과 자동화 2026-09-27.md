## 파이프라인 (`(로컬 경로)`)

1. **수집**: 화이트리스트 채널(원 저작자가 직접 찍어 CC BY로 올리는 곳)의 shorts·videos 탭 + CC 필터 키워드 검색. 채널별 조회수순으로 번갈아 뽑고, 채널당 하루 완성 3개·시도 6개 상한.
2. **검사**: `yt-dlp -J`로 `license`에 `Creative Commons`가 있어야 받는다. 8~900초.
3. **준비**: 1080p 다운로드 → `mlx-whisper`(large-v3-turbo) 전사 → 초 표시 콘택트시트(24칸 × 최대 3장).
4. **기획**: `claude -p --model opus`(읽기 권한은 작업 폴더만)가 시트·전사를 보고 JSON(훅 제목 2줄·구간·원본 기준 초의 대사 자막·자막 위치)을 낸다. AI 생성·재업로드·원본 자막 박힘·아동 곤란 장면은 거절.
5. **렌더**: Pillow로 오버레이 PNG(글자 단위 타이핑)를 만들고 ffmpeg concat으로 합성 — Homebrew ffmpeg에 `drawtext`·`ass`·`subtitles` 필터가 없어서다.
6. **보고·게시**: 헤르메스 `hermes send --to slack:C0BMNRH3GV6`로 완성 수·썸네일 격자 → 업로더가 하루 10번 하나씩 공개 게시하고 링크를 Slack에 보낸다.

## 막혔던 것

- `hermes send --to slack`(홈 채널)은 `Slack API error: channel_not_found` → 채널 ID `slack:C0BMNRH3GV6` 명시.
- yt-dlp가 동영상 탭이 없는 채널에 `null`을 돌려줘 `AttributeError: 'NoneType' object has no attribute 'get'`로 첫 실행이 즉사 → 처리 + 중단 시 Slack 알림.
- `aside exec`는 402 Insufficient credits → REPL만 쓴다. `setInputFiles`는 `escapes the session directory` → 세션 폴더로 복사.
- 자막이 화면 67% 높이라 쇼츠 하단 UI(채널명·제목)에 덮였다 → 55%·영상 윗단으로 이동, 제목은 좌우 아이콘 폭을 비움.

## 남은 위험

- **수익화 심사**: 재사용 콘텐츠로 거절될 수 있다. 대사 창작이 근거지만 판정은 유튜브 몫.
- **Mac 의존**: 잠자기·Aside 앱 종료 시 제작·게시가 빠진다.
- **소재 고갈**: 원 저작자 CC 채널이 4곳뿐. 검색분은 재업로드·AI 판정에 기댄다.
- 스튜디오에 첫 시험 업로드 비공개 초안 "up"이 남아 있다.
