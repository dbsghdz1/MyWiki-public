## 제작: `factory.py` (launchd `com.hong.shorts-factory`, 03:00과 09:30)

`scripts/daily.sh`가 감싼다. PATH를 고정하고, `output/factory.log`가 5MB를 넘으면 `.1`로 돌리고, 14일 지난 `output/<날짜>/` 폴더를 지운 뒤 `caffeinate -i /usr/bin/python3 src/factory.py`를 돌린다. 같은 날 `output/<날짜>/*.mp4`가 이미 10개면 바로 끝나므로 09:30 재시도가 중복 제작하지 않는다. `state/.lock`에 flock을 걸어 동시 실행도 막는다.

| 단계 | 함수 | 하는 일 | 산출물 |
|---|---|---|---|
| 1 수집 | `collect_candidates` | 화이트리스트 채널 8곳의 shorts와 videos 탭 각 150개 + 키워드 10개를 CC 필터(`sp` protobuf: 조회수순, 올해, 4분 이하, 크리에이티브 커먼즈)로 검색한 10개씩. `used`와 `rejected`에 있는 ID는 뺀다. 채널별 조회수순으로 줄 세운 뒤 라운드로빈, 검색분은 맨 뒤 | 후보 목록(10-17에 1,401개) |
| 2 검사 | `fetch_meta` | `yt-dlp -J`로 `license`에 "creative commons"가 있어야 통과, 라이브 제외, 길이 8~900초 | `rejected`에 사유 기록 |
| 3 준비 | `download`, `transcribe`, `contact_sheets` | 1080p 이하 mp4 다운로드, `mlx_whisper` large-v3-turbo로 전사(반복 환각 줄 제거), 길이/72초 간격 프레임을 24칸 시트 최대 3장으로 | `work/<id>/src.mp4`, `transcript.txt`, `sheet1~3.jpg` |
| 4 기획 | `ask_claude`, `validate` | `claude -p --output-format json --model opus --max-turns 8`에 프롬프트를 stdin으로 넣는다. 도구는 `Read(work 폴더)`만 허용, Bash와 Write 등은 금지, 420초 제한. 출력 JSON: 훅 제목 2줄(13자 이내), 구간 1~5개(속도 0.5/1/1.5/2), 대사 자막 4~8개(18자 이내), `cap_pos`, 유튜브 제목, 해시태그. 거절 조건은 AI 생성, 재업로드, 원본 자막 박힘, 사고와 아동 곤란 장면. `validate`가 총길이 10~40초와 자막 2개 이상을 확인하고 구간 끝을 원본 길이로 자른다 | `work/<id>/plan.json`, `claude_raw.json`, `prompt.md` |
| 5 렌더 | `render.render` | 구간별 ffmpeg 잘라내기(속도 적용) → concat → 1080×1920에 상단 330px 검은 바를 pad → Pillow로 만든 오버레이 PNG 시퀀스(제목 2줄, 출처 한 줄, 글자 단위 타이핑 자막 0.045초/글자)를 concat demuxer로 겹친다. 자막 y는 middle 1050, high 560, 글자 폭 900 이하. 폰트는 AppleSDGothicNeo. libx264 crf 19, 30fps | `output/<날짜>/NN_<id>.mp4`, `.plan.json`, `.txt`(설명란 글) |
| 6 보고 | `slack`, `preview_grid` | 완성 수, 시도 수, 실패 3건, 썸네일 격자를 `hermes send --to slack:<채널>`로. 10-16에 보고 채널을 `#00-헤르메스-비서`에서 `#10-콘텐츠-유튜브`로 분리했다(`backups/slack-split-20261016-231251`) | Slack 메시지, `output/<날짜>/_preview.jpg` |

상한: 하루 시도 40회, 채널당 완성 3개와 시도 6회. 완성하면 `work/<id>/`를 지우고, 실패한 작업 폴더는 3일 뒤 지운다. 어떤 영상이 실패해도 `rejected`에 "실패: …"로 적고 다음 후보로 간다. 전체가 죽으면 Slack에 「쇼츠 공장 중단」을 보낸다.

`.plan.json`을 남기는 이유는 레이아웃을 바꿀 때 Claude를 다시 부르지 않고 `render.render(plan, src, out, tmp)`만 다시 돌리기 위해서다. 원본 mp4는 지워지므로 재렌더에는 `youtu.be/<id>` 재다운로드가 필요하다.

## 게시: `uploader.py` (launchd `com.hong.shorts-uploader`, 09:00부터 22:30까지 10회)

1. `output/*/NN_*.mp4` 중 `state/uploaded.json`에 없는 가장 오래된 1편을 고른다
2. `aside repl <JS>`를 띄우고, Aside가 만든 새 세션 폴더(`(로컬 경로)`)를 찾아 영상을 `up.mp4.part`로 복사한 뒤 `up.mp4`로 이름을 바꾼다. JS는 그 파일이 생길 때까지 최대 60초 기다린다
3. JS가 스튜디오 `videos/upload?d=ud`를 열고 `input[type=file]`에 넣는다 → 제목 textbox(`.txt` 첫 줄 95자) → 설명 textbox(`.txt` 전체) → 「아니요, 아동용이 아닙니다」 → 세부정보 화면 스냅숏에서 `youtube.com/shorts/<id>` 링크를 미리 읽는다 → 「다음」 3회 → 「공개」 → 「게시」
4. 「게시」 클릭까지 갔고 `FAIL`이 없으면 성공으로 보고 `uploaded.json`에 시각과 링크를 적는다. 게시 확인 문구는 화면마다 달라 믿지 않는다
5. Slack에 게시 링크와 남은 미게시 수, 실패면 로그 끝 500자를 보낸다

YouTube Data API를 쓰지 않은 이유: 심사 안 받은 API 프로젝트로 올린 영상은 비공개로 잠긴다. 예약 게시 대신 launchd 시각으로 분산한 이유: 스튜디오의 날짜 선택기 조작이 불안정했다. 자세한 셀렉터와 Aside 제약은 [유튜브 쇼츠 CC 소싱과 자동 업로드](../../../%EC%9E%91%EC%97%85%EB%85%B8%ED%8A%B8/%EB%8F%84%EA%B5%AC/%EC%9C%A0%ED%8A%9C%EB%B8%8C%20%EC%87%BC%EC%B8%A0%20CC%20%EC%86%8C%EC%8B%B1%EA%B3%BC%20%EC%9E%90%EB%8F%99%20%EC%97%85%EB%A1%9C%EB%93%9C.md)와 [Aside 브라우저 폼 자동 입력](../../../%EC%9E%91%EC%97%85%EB%85%B8%ED%8A%B8/%EB%8F%84%EA%B5%AC/Aside%20%EB%B8%8C%EB%9D%BC%EC%9A%B0%EC%A0%80%20%ED%8F%BC%20%EC%9E%90%EB%8F%99%20%EC%9E%85%EB%A0%A5.md).

## 재개하거나 다른 채널에 재사용할 때

- **재개**: `(로컬 경로)`와 `com.hong.shorts-uploader.plist.off`의 `.off`를 떼고 `launchctl bootstrap gui/$(id -u) <plist 경로>`. 수동 한 번 돌리기는 `cd (로컬 경로) && zsh scripts/daily.sh`(또는 `python3 src/factory.py --count 2`, 시험은 `--only <영상ID>`), 게시 한 편은 `python3 src/uploader.py [mp4 경로]`
- **전제**: 맥이 깨어 있어야 하고(잠자기 설정은 운영 참고), Aside 앱이 로그인된 채 떠 있어야 하며, `claude` CLI 로그인과 `hermes` Slack 설정이 살아 있어야 한다. 서버(Oracle)에서는 유튜브가 IP를 막고 RAM이 부족해 못 돈다
- **다른 채널로 쓰려면** 바꿀 곳: `uploader.py`의 `CHANNEL`(채널 ID), `config/channels.json`(원본 채널과 키워드), `factory.py`의 `PROMPT`(포맷과 거절 조건), `render.py`의 `TOP`, `CAP_Y`, 색과 폰트, 두 파일의 `SHORTS_SLACK`
- **소재 방향을 바꾼다면** 판정 기록대로 골든리트리버, 반려닭, 연년생 육아 세 소재로 좁히고 하루 2~3편에 첫 1초 훅과 15초 이하 길이를 시험한다. 지속률은 스튜디오 분석에서 직접 봐야 하며 파이프라인은 그것을 모으지 않는다
- **보존**: 코드 저장소에 원격이 없다. 맥을 바꾸거나 초기화하면 사라지므로 비공개 저장소로 push하거나 `(로컬 경로)`를 통째로 백업해 둘 것
