**실운영 중 — 자율 발행 체제.** 7월 22일부터 Instagram 캐러셀 실발행(08-01 기준 발행 기록 10건 — 고유 게시물 9건, 강제 재발행 1건 포함). roundup 외에 **개별 기사형 포스트**(경기·순위·인터뷰)도 08-01부터 발행하기 시작했다. 08-12 지표: 팔로워 39 · 누적 게시물 27([[프로젝트/개인/인스타카드뉴스/발행·지표 일지|발행·지표 일지]]). 08-09 사용자 승인 플로우 폐지 → 08-14 운영 개편: Oracle 서버 systemd timer가 08:00·23:00 자동 발행, 08:00 게시물은 전날 23:00 Slack `#instagram` 사전 미리보기로 수정·보류 피드백을 받는다([[프로젝트/개인/인스타카드뉴스/LLM 판단 기준 2026-08-01|LLM 판단 기준]] 08-09·08-14 정책 변경). 확립된 워크플로·1차 발행 이력은 [[프로젝트/개인/인스타카드뉴스/발행 운영 기록 2026-07-29|발행 운영 기록 2026-07-29]], 에이전트 판단 기준·2차 발행 이력은 [[프로젝트/개인/인스타카드뉴스/LLM 판단 기준 2026-08-01|LLM 판단 기준 2026-08-01]] 참조.

- 일일 파이프라인: 연합뉴스 RSS 수집 → 기사 원문 확인 후 2~4장 편집 → 렌더 → PNG 육안 검수 → 해시 승인(`approve_posts.py`) → **자율 발행**(Oracle systemd timer 08:00·23:00, 08-14부터 — 판단 기준은 [[프로젝트/개인/인스타카드뉴스/LLM 판단 기준 2026-08-01|LLM 판단 기준]]) + 08:00분은 전날 23:00 Slack 사전 미리보기 (전 과정 `.venv/bin/python` 사용)
- 이미지 정책: 07-31 사용자가 뉴스 사진 라이선스 구매 확인 → **기사 보도사진 사용 재개**. 사진 없는 기사는 생성 배경(`assets/backgrounds/`) 유지
- 07-30~08-01 "API access blocked" 임시 차단 겪음 → 발행 간격 옵션(`--interval`, 기본 600초) 추가로 대응
- AI 릴스(나레이션+모션그래픽) 프로토타입 제작 완료, 발행 미연동
- 대기 중: 릴스 발행 연동 여부
