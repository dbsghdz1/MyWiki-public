- **현재**: **2026-09-23 릴스 발행 시작** — 첫 릴스(9/22 힐리어드 38호 만루포, 34초)를 올렸고, 매일 23:45(재시도 06:30) Mac launchd가 그날 경기에서 한 장면을 골라 사실 검증 후 자동 발행한다([릴스 발행 시작](%EB%A6%B4%EC%8A%A4%20%EB%B0%9C%ED%96%89%20%EC%8B%9C%EC%9E%91%202026-09-23.md)). 계정명 `yagu.3cut`, 팔로워 269·게시물 84(09-23). 카드뉴스는 서버 08:00·23:00 그대로지만 08:00 회차가 09-22·23 imgbb 타임아웃으로 실패
- **다음 판정**: 2026-09-30 — 릴스 7일 중 몇 번 자동 발행됐고 조회수가 카드뉴스보다 높은가. 자동 발행 5회 미만이면 Mac 대기·Claude 한도부터 고친다
- **지금 할 일**: 첫 릴스 캡션의 «9회초 1사 만루»를 앱에서 «9회초 2사 만루»로 고친다 — API로는 캡션 수정이 안 된다
