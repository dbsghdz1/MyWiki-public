# 커플앱 (작업공간 이름, 가칭 몽돌, 제품명 미정)

## 현재 카드
- **단계**: 문제 검증 (홍 결정으로 디자인 시안과 BM을 먼저 만듦, 코드는 게이트 뒤)
- **현재**: 2026-10-12 시장 조사로 App Store 커플앱 65개, 리뷰 8,712건과 플레이 리뷰, 커뮤니티 글 59건을 실측해 불만 49건을 모았다. 옛 1위 비트윈은 2025-09 사진 삭제 사고 뒤 최근 1~3★ 104건 중 51건이 "사진이 사라졌다"이고, ₩9,900 1회 결제 커플앱이 2025-02 출시 뒤 팔리고 있다 → 시장 조사. 같은 날 홍 결정으로 가칭 「몽돌」 디자인 시안 9장(조약돌 캐릭터 둘)과 BM(커플 평생권 ₩19,000 하나, 무료 사진 500장, 광고와 구독 없음)을 만들었다 → [디자인 시안](%EB%94%94%EC%9E%90%EC%9D%B8%20%EC%8B%9C%EC%95%88%202026-10-12.md), [PRD와 BM](PRD%EC%99%80%20BM%202026-10-12.md). 2026-10-13 홍이 컨셉을 확정했고, 사진은 보내는 사람이 직접 고르는 방식으로 정했다. 1차 시안이 별로라는 반응에 홈을 세 방향으로 다시 그렸고, 사진이 주인공인 A안으로 4장을 더 만들어 홍 선택을 기다린다
- **다음 판정**: 조건. 인터뷰 5명과 행동 2건이 채워지면 passed로 바꾸고 7일 MVP. 인터뷰 5명 중 "기록을 잃을까 봐 돈을 내겠다"가 3명 미만이면 중단
- **지금 할 일**: 홍이 비트윈 사고 피해 커플과 3년 이상 장기 커플 5명에게 문제 인터뷰. 「구글 포토 파트너 공유를 두고 왜 이 앱에 돈을 내나요」와 「지금 커플 사진을 어떻게 주고받나요」를 꼭 묻는다. 시안을 보여 주고 「지금 커플앱에 사진이 몇 장 있나요」를 물어 무료 한도 500장을 고친다. 끝에 Android 비공개 테스트 참여를 부탁하면 행동 2건과 Play 출시 조건(테스터 12명 14일)을 같이 채운다
- **하지 않을 일**: 코드와 스토어 상품 등록, 최종 이름 확정. 전달 서버와 내보내기 기술 스파이크도 게이트 통과 전에는 하지 않는다. 가격 A/B 테스트

## 문제

커플앱에 쌓은 사진과 기록이 운영사 사고, 휴면 계정 삭제, 연결 해제, 폰 교체로 사라진다. 1위 앱이 2025-09에 무료 회원의 사진과 영상을 영구 삭제하는 사고를 냈고, 돈을 낸 사람만 기록이 남았다. 사람들은 광고와 월 구독에 지쳐 1회 결제를 원한다. 홍 결정으로 iPhone과 Android 둘 다 지원한다. 상세와 근거는 시장 조사 2~5절.
