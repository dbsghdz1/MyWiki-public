# Fadeo (즉석카메라)

## 현재 카드
- **단계**: 운영
- **현재**: 1.0 출시(2026-08-31, 무료 KR·US) → 1.1 출시(09-03, 필름 6종·물성 렌더·ASO 개편) → 1.2(build 5, 필름 장전·라이브 액티비티·홈 위젯·리뷰 요청, 스토어 기본 언어 en-US) 09-04 제출 심사 대기 — [[프로젝트/개인/즉석카메라/App Store 심사 이력|심사 이력]]. 유료 ₩1,100 전환은 '예정'으로만 기록돼 있고 실제 적용은 미확인
- **다음 판정**: 1.2 심사 결과 + 가격 실험(첫 주 ₩1,100 → 정가 ₩3,300 복귀 권고)의 실제 적용과 유료 차트 진입 여부. Tenra(2026-07 출시)가 같은 컨셉이라 승부는 완성도·갱신 속도
- **지금 할 일**: KIPRIS 상표 검색 1회(ASO 잔여 — 리스크는 소송이 아니라 신고 한 건)
- **하지 않을 일**: 스티커·글꼴·텍스트 편집, 카메라 수십 종, 동영상, 계정·서버, 스킵 기능 — 이 카테고리는 기능을 더하면 진다

> [!note] 2026-08-31 — **1.0 출시됨 (무료, KR·US).** 2026-09-03 — **1.1 출시.** 2026-09-04 — **1.2 제출**(필름 장전·잠금화면 라이브 액티비티·홈 위젯·인앱 리뷰 요청, 스토어 기본 언어 ko → en-US). **유료 ₩1,100 전환은 09-02에 '예정'으로만 적혔고 적용 기록이 없다** — 아래 v1 사양의 ₩3,300과 충돌하므로 실제 판매 가격을 확인해 하나로 정할 것. [[프로젝트/개인/즉석카메라/App Store 심사 이력|심사 이력]]

**찍으면 바로 안 보이고 10분에 걸쳐 현상되는 iOS 즉석카메라 앱.** 흔들면 빨라진다. 2026-08-25 착수 결정.

> [!info] 이 프로젝트가 선택된 경위
> "월 100만원 벌 아이템"을 찾는 조사에서 **후보 9개가 죽은 뒤** 데이터로 도달한 자리다. 죽은 이유는 매번 같았다 — *수요가 있는 곳엔 이미 유능한 주인이 있다*. 이 자리는 그 둘이 분리돼 있다: **수요는 구닥이 증명했고, 주인은 5년째 없다.**

## 왜 여기인가 — 근거

### ① 노출 문제가 구조적으로 풀린다 (다른 후보엔 없던 조건)

[[프로젝트/개인/Zappy/README|Zappy]]는 **월 앱스토어 노출 9회**로 죽었다. 제품이 아니라 유통에서 죽은 것이다. 그런데 **한국 iOS 유료 차트는 신규 앱이 며칠 만에 진입한다**(2026-08-25 실측):

| 앱 | 출시 후 | 리뷰 | 가격 | 차트 |
|---|---|---|---|---|
| iY2K | **4일** | 0건 | ₩4,900 | **30위** |
| ZRcamera | **11일** | 8건 | ₩3,300 | **16위** |
| 영뽀또 | 60일 | 43건 | ₩3,300 | **8위** |
| 올디 Oldi | 158일 | 299건 | ₩1,100 | **전체 1위** |

최근 18개월 신규 진입 28개 중 **12개가 사진·비디오**다. 계속 자리가 나는 구조다.

### ② 수요는 증명됐고 주인은 없다 — **2026-07에 깨졌다**

> [!warning] 2026-09-02 갱신 — 이 전제는 더 이상 사실이 아니다
> **`Tenra — 필름 카메라와 암실`**(2026-07-10 출시, 무료+Pro)이 거의 같은 컨셉으로 들어왔다. 스토어 설명: *"찍고 바로 확인하는 앱이 아닙니다 (…) 사진은 암실에서 현상을 기다립니다"*. 필름 8종(5종 무료, Pro로 전체 해제), 탭 포커스·플래시·전후면 전환.
>
> 그리고 `현상 카메라` 검색에 **2026년 신규만 7개**가 들어왔다 — 에코롤(08) · Eluvo(08) · 릴리(08) · Yuzu Cam(07) · Licht(07) · Film35(05) · Filmi(09). 대부분 리뷰 0~2의 신생이지만, **"5년째 빈 자리"라는 출발 전제는 이제 없다.**
>
> 남아 있는 것: 이 신규들 중 리뷰가 붙은 앱이 아직 없다. 승부는 여전히 완성도와 갱신 속도다 — 그건 ④·⑤ 근거가 그대로다.


- **구닥(Gudak, 2017)** — 필름 24장·하루 24장 제한·**3일 기다려야 사진이 나오는** 앱으로 여러 나라 앱스토어 유료 1위. **"기다림에 돈을 낸다"를 증명했다.**
- 현재: `Gudak Cam Lite` 리뷰 150 **2.9★ · 2021-07 갱신**, `구닥6` 145 · **2021-08 갱신**. 원조 유료 앱은 검색에 없다. **Screw Bar Inc.가 5년째 손을 놨다.**
- `Instants: Instax Retro Camera` ₩3,300 · 리뷰 **3,872** · 4.6★ · **2022-12 갱신(4년 방치)** — 다만 이건 카메라가 아니라 **프레임·스티커 편집 도구**다(배경 80·글꼴 30·스티커 170). 현상 경험 없음.

### ③ 현역 강자가 이 자리를 명시적으로 비웠다

`TOK CAM 즉석카메라`(무료·구독, 리뷰 277·4.7★, 2026-08 갱신, 카메라 43종)의 스토어 설명:

> *"필름 현상이나 인화 과정을 **기다릴 필요가 없습니다**."*

**기다림을 세일즈 포인트로 부정했다.** 그 자리가 비어 있다.

### ④ 승부처가 홍의 강점과 겹친다

`디카 99` 리뷰 99건 실측 — 칭찬이 색감이 아니라 **디자인**이다: *"UXUI 디자인이 너무 이뻐요!!"*, *"디자인이 깔끔하고 쓰기 편합니다"*. [[프로젝트/개인/Zappy/README|Zappy]] 테마 14종(컬러·모노 쌍)·Figma 시안 26종 경험이 직접 쓰인다.

### ⑤ 경쟁자는 방치되고 홍은 안 된다

이 카테고리 앱들이 1~7년씩 멈춰 있다(구닥 5년, Instants 4년, 디카99 1년+, Polca 7년). `appstore-release` 스킬 + fastlane 파이프라인이 있는 홍에게 **꾸준한 갱신은 저비용 차별점**이다.

## v1 사양 (의도적으로 얇게)

`디카 99` 리뷰의 교훈이 범위를 정했다 — *"프레임이 추가되면서 너무 복잡해지고 불편해졌어요"*, *"업데이트 전으로 돌려주세요"*. **이 카테고리는 기능을 더하면 진다.**

**넣는 것**
- 카메라 1종(정사각 인화지 프레임) · 필름 톤 3~5종 → **1.1에서 6종**(클래식·크리스프·콜드·페이디드·흑백·나이트)
- **10분 현상** — 앱을 꺼도 진행. 실제 폴라로이드 곡선을 따른다: **윤곽이 먼저, 색이 나중에**(균일하게 밝아지지 않는다)
- **흔들기로 단축** (최대 절반까지). 실제론 미신이지만 널리 알려져 있어 인터랙션으로 강하다
- **현상 완료 푸시 알림** — 앱을 다시 열게 만드는 장치
- 앨범(현상 중/완료 구분) · 저장 · 공유

**빼는 것** — 스티커·글꼴·텍스트 편집(Instants가 그러다 방치됐다), 카메라 수십 종(TOK CAM 흉내), 동영상, 계정·서버(고정비 0원 유지)

**가격 ₩3,300** — 베리필름·Instants가 증명한 지점. ₩1,100은 차트 1위(올디)를 해도 월 약 66만원 추정이라 목표 미달.

**스킵 없음** — 기다림이 컨셉이므로. 손잡이는 흔들기 하나만 준다.

## 마일스톤 0 결과 (2026-08-25) — 현상 곡선 성립

앱을 만들기 전에 제품의 심장만 떼어내 검증했다. **성립한다.** 상세: [[프로젝트/개인/즉석카메라/즉석카메라 개발 기록 2026-08-25|개발 기록 2026-08-25]]

- **"형태 먼저, 색 나중"이 구현됐다** — 채도를 가장 늦게 올리면 중간에 흑백 사진처럼 형태만 보이는 구간이 생기고, 빨강이 먼저 살아난 뒤 나머지 색이 따라온다
- **확정: A(흰 베일) 곡선 + 암실 배경 고정 + 인화지 프레임.** 이 셋이 맞물린다. 어둠에서 떠오르는 B안의 드라마는 **어두운 배경 위에 뜬 흰 인화지**가 대신한다
- **다크/라이트 모드에 따라 곡선을 바꾸지 않는다** — 현상 방식은 물리 현상이지 사용자 설정이 아니다. "밝은 배경에서 흰 베일이 묻힌다"는 걱정은 인화지 프레임이 없앤다
- 반복 루프 확보: `filmTone` 수정 → `swiftc` → 스트립 렌더 → 눈으로 판정, **한 사이클 30초**

**앱 골격 완성(같은 날)** — tuist 기반 iOS 프로젝트, 검증된 색 파이프라인 이식, 시뮬레이터에서 빌드·실행·현상 렌더 확인. 필름 4종(클래식·크리스프·콜드·페이디드) 확정.

미결(2026-08-25 시점 목록 — 1.0·1.1 출시로 대부분 해소됐다. 현재 잔여는 맨 위 현재 카드): **초반 30초 훅이 없다**(인화지 배출 애니메이션·햅틱·모터 소리로 채울 자리) · 흔들기 감지 연결 · 사진 앱 저장·공유 · 아이콘·스토어 이름 · StoreKit ₩3,300

## 배운 것

- [[작업노트/Apple/CoreImage 색 파이프라인|CoreImage 색 파이프라인]] — 색조 이동은 ±10% 안쪽, 블랙 리프트는 bias가 아니라 톤커브, **색은 UI 맥락 없이 판정하면 안 된다**, `CIImage`는 EXIF 방향을 무시한다, 표시 크기로 먼저 디코드. **폴라로이드다움은 색이 아니라 결함이다**(할레이션·입자·번짐·얼룩), `CIAdditionCompositing`은 알파도 더한다, `CIRandomGenerator`는 알파까지 난수다
- [[작업노트/Apple/시뮬레이터로 UI 검증하기|시뮬레이터로 UI 검증하기]] — `simctl`에 탭이 없고 권한 다이얼로그는 `erase`만 듣는다. 답은 **앱 안의 DEBUG 데모 모드**
- [[작업노트/Apple/SwiftUI|SwiftUI]] — **`Text(String)`은 로컬라이즈를 안 한다**(헬퍼 인자를 `LocalizedStringKey`로), 화면 밖 요소는 여백 대신 `.clipped()`, 시간 경과는 `@Published`를 안 울린다(`.task(id:)`로 다음 시각에 한 번), 고정 랜덤에 `hashValue` 금지, **"처음인가"를 `@AppStorage`로 직접 판정 금지**, 겹침 방지는 상수가 아니라 `PreferenceKey`. **가운데 칸이 곧 선택인 가로 다이얼은 `.contentMargins`가 만든다** — 그리고 스크롤 선택은 setter의 부수 효과를 debounce하게 만든다
- [[작업노트/Apple/카메라 캡처와 실시간 필터|카메라 캡처와 실시간 필터]] — 촬영음은 관할에 따라 공식 API로도 못 끈다(억지로 켜면 죽는다), **진짜 무음은 사진 출력을 안 쓰는 것**, `AVCaptureVideoPreviewLayer`에는 필터를 못 건다. **확대는 기기 배율 하나가 프리뷰와 촬영에 함께 걸린다** — 대신 범위를 벗어난 `videoZoomFactor`는 못 잡는 예외고 `activeFormat` 대입이 배율을 1로 되돌린다
- [[작업노트/AppStore/실물을 흉내 내는 앱의 상표 위험|실물을 흉내 내는 앱의 상표 위험]] — 흰 테두리는 **classic border logo**라는 등록 상표이고 계류 중. 실질 위험은 소송이 아니라 **신고 한 건으로 내려가는 것**
- [[작업노트/Apple/메인 스레드를 막는 것들|메인 스레드를 막는 것들]] — 실기기 검증 세 라운드의 산물. 블록을 없애면 우연에 기대던 코드가 깨진다. **네 번째 라운드는 계측으로 끝났고 범인은 메인이 아니었다** — `startRunning()` 200ms, 그리고 "멈춘 것 같다"의 절반은 블록이 아니라 침묵
- [[작업노트/AppStore/앱 이름과 검색 노출|앱 이름과 검색 노출]] — **짧은 조어 브랜드명은 흔한 단어에 먹힌다.** `Fadeo`는 `Video`에 묻혀 자기 이름 검색 200위 밖. 키워드는 단어 뜻이 아니라 **그 검색어가 속한 시장**을 보고 넣는다
- [[작업노트/Apple/Xcode 빌드와 번들 구성|Xcode 빌드와 번들 구성]] — tuist `extendingDefault`는 `CFBundleShortVersionString`을 "1.0" 리터럴로 박는다. 두 번째 버전을 올릴 때 처음 터진다

## 판정 기준 ("1위 수준"의 정의)

만들기 전에 기준을 정한다 — 이게 없으면 반복이 안 돌아간다.

1. **현상 연출이 진짜 같은가** — 색이 늦게 올라오는가, 균일하게 밝아지지 않는가
2. **첫 화면이 예쁜가** — 이 카테고리 구매 이유가 UI 디자인이라는 게 실측됐다
3. **10분을 기다릴 만한가** — 알림을 받고 다시 열고 싶은가
4. **기능이 더 없어도 되는가** — 뭔가 더 넣고 싶으면 그건 대체로 잘못된 신호다
