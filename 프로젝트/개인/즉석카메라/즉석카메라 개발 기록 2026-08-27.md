# 즉석카메라 개발 기록 2026-08-27

실기기 검증에서 나온 문제들을 잡고 **1.0 (3) 심사 제출까지** 간 날.

## 카메라 화면 — 세 번째이자 최종 구조

"4:3인데 아래가 잘린다"는 지적으로 최종 확정. **아이폰 기본 카메라는 애초에 화면을 꽉 채우지 않는다** — 비율대로 잘린 사각형이 위에 놓이고 아래는 검은 조작부다. 전체 화면 프리뷰 + 마스크 방식(2차)을 버리고 이 구조로 갔더니, **보이는 사각형 = 잘리는 영역**이 되면서 크롭 마스크·가이드·offsetFraction·PreferenceKey가 통째로 삭제됐다. 올바른 구조는 코드를 줄인다.

## 실기기가 잡아준 것들 ★

시뮬레이터로 못 보는 것들이 실기기 첫날 줄줄이 나왔다. 전부 [[공부/Apple/메인 스레드를 막는 것들|메인 스레드를 막는 것들]]과 [[공부/Apple/SwiftUI|SwiftUI]]에 일반화했다.

1. **셔터 순간 멈춤** — `AVAudioSession.setActive`(재생마다, 메인) + `CHHapticEngine.start`(자동종료 후 재기동, 메인)
2. **그래도 멈춤** — `store.add`의 원본 JPEG(1~2MB)·인덱스 쓰기가 메인
3. **콜드 스타트 굳음** — 카메라 세션 구성(100~300ms)·`CIContext(mtlDevice:)` 생성·프리로드 자체가 메인
4. **블록을 고치자 배출 애니메이션이 사라짐** — `withAnimation`이 화면 삽입 트랜잭션에 삼켜짐. 전에 움직인 건 블록이 시간을 벌어준 우연. **시계(TimelineView) 기반으로 교체**

## 배출 연출 — 넣었다 뺀 것

슬롯 + 지이잉 떨림(13Hz×0.7pt, 소리 26Hz를 그대로 흔들면 잔상만 남는다) + 낙하(기울며 정착). **낙하는 사용자 판정으로 제거** — 슬롯에 물려 있던 종이가 이유 없이 떨어지는 게 이상하고, 이 화면의 일은 사진을 반듯하게 보여주는 것. 실물 고증 하나: 인화지는 **현상액 포드가 있는 두꺼운 여백부터** 나온다(롤러가 포드를 먼저 터뜨려야 하므로).

## 남은 시간 표기

`9:57` 초 단위 카운트다운 → **`약 10분` / `곧 나옵니다`**. 찍은 직후 최댓값을 정면으로 보여주면 기다림이 벌칙으로 읽히고, 매초 깎이는 숫자는 시계를 보게 만든다. 갱신은 부모 렌더 주기(5초 양자화)에서 분리해 자기 시계로 초당.

## 지역화 — 6개 언어

ko·en·ja·zh-Hans·zh-Hant·es, String Catalog 하나(45 문자열 + 권한 문구 2). 요청은 4개였지만 **영어를 추가** — 없으면 미국 사용자가 한국어를 본다. "완료"가 섹션 제목(Developed)과 버튼(Done)으로 갈려 별도 키. 복수형은 en·es만. `String(format:)`으로 감싸면 복수형이 죽는다 — `String(localized: "\(n)장")` 형태여야 한다.

## 제출 — [[프로젝트/개인/즉석카메라/App Store 심사 이력|심사 이력]] 참조

**1.0은 무료로 선회**(유료 전제 문구 "한 번 사면 끝입니다"를 설명·심사 노트에서 제거). 스크린샷은 데모 모드로 **실제 앱에서** ko·en 각 5장(1320×2868) — 옛 렌더는 2.3.3 반려감이라 폐기. 연령 등급 신필수 항목 지뢰는 appstore-release 스킬 플레이북에 등재.
