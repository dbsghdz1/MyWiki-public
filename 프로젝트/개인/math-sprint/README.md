## 2호 앱: 찰나의 승부 (flash-tap)

2026-08-01에 시작한 두 번째 앱인토스 미니게임이다. 위치 `(로컬 경로)`, GitHub `dbsghdz1/flash-tap`(비공개). 처음 이름은 「번개 탭」이었고 뼈대(30초 스코어 어택, 콤보, 랭킹, 이어하기 광고, 공유)는 math-sprint에서 가져왔다. 아래는 2026-08-02 기록이고 이후 진행은 확인하지 못했다. 레포의 마지막 커밋은 「찰나의 승부 출시 준비」(광고 그룹 ID와 아이콘 URL 연결)다.

- **게임**: 순발력 5종 챌린지. 한 판에 F1 스타트(신호등), 초록불, 과녁 저격, 방향 판단, 색깔 함정(스트룹) 다섯 미션이 랜덤 순서로 나오고 다섯 번의 평균 ms가 기록이다(낮을수록 상위). 실패나 부정 출발은 999ms로 친다. 등급제는 300ms 미만 「F1 드라이버급」부터 「연습 필요」까지다. 보상형 광고는 「최악의 시도 하나 지우기」다. 숫자 탭 게임에서 F1 단일 모드로, 다시 5종 챌린지로 두 번 피벗했다(홍이 다양하고 재밌는 것을 원했다).
- **정체성**: 앱 이름 「찰나의 승부」, 영문 Split Second, `appName`은 `split-second`(폴더와 GitHub 저장소 이름은 `flash-tap` 그대로). 다크 바탕에 F1 라이트 브랜딩이다. 콘솔 miniAppId는 59776으로 2026-08-02에 MCP로 등록했고 앱 정보 검토 중이었다. 번들 `v20260802-1`을 올리고 테스트 푸시까지 했으며, 앱 정보 검토가 승인되면 `bundle_submit_review`가 필요하다.
- **광고**: 보상형(기록 보호)과 전면형 두 그룹이고 ID는 `src/ads.ts`의 `AD_GROUP_IDS`에 있다. 광고 그룹 이름은 워크스페이스 전체에서 유일해야 한다.
- **리더보드**: math-sprint와 같은 Supabase 프로젝트의 `reaction_scores` 테이블과 `submit_reaction` RPC, `best_ms` 80에서 2000까지 오름차순이다. 스키마는 `supabase/schema.sql`이고 SQL Editor에서 실행하는 일은 홍이 한다. 옛 `tap_scores` 스키마는 쓰지 않는다.
- **OG 이미지**: `dbsghdz1.github.io/brain-rush-docs/og-flash-tap.png`에 호스팅했다.
- **2026-08-02에 남았던 일**: SQL 실행, 콘솔 웹에서 미니앱 등록(아이콘 `assets/icon.png` 업로드), `granite.config.ts` 아이콘 URL 반영, 광고 그룹 생성과 ID 반영, 번들 업로드와 검수. 레포 커밋으로 광고 그룹 ID와 아이콘 URL 반영은 끝났다. 검수 제출 여부는 미확인이다.
