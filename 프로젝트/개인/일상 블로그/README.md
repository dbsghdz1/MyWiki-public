# 일상 블로그

## 현재 카드
- **단계**: 7일 MVP
- **현재**: 2026-10-20 홍이 계획서 v3를 기본값 그대로 확정(「이대로 Opus에 넘기자」, 이름과 도메인만 미정). 같은 날 밤 Opus가 Stage A(레포 뼈대, `pipeline/` 전체와 테스트, `site/` 데이터 계층과 다국어 라우팅, 임시 화면)를 `(로컬 경로)`(가칭) 로컬 레포에 끝냈다. 파이프라인 테스트 166개, 사이트 빌드 175페이지와 산출물 검증 통과, 독립 리뷰 3회 반영. Claude가 테스트와 빌드를 다시 돌려 확인했다. 실제 API와 배포는 홍의 계정 작업 뒤라 아직 0회. Stage B(템플릿 이식, 공개 저장소 `basehub-ai/nextjs-blog`에서 레이아웃과 스타일만)도 같은 날 밤 Opus가 끝냈다(커밋 6개, 독립 리뷰 P2 5건 반영, Claude가 빌드와 테스트 재실행으로 확인). 같은 밤 홍이 이름을 **기록(Girok)**, 도메인을 **girok.day**로 정했고, 이름 적용(폴더 `(로컬 경로)`, 사전, 주소, favicon, 서버 경로)도 Opus가 끝냈고(커밋 4개, 총 38개) Claude가 빌드와 테스트 재실행으로 확인했다. 2026-10-21 홍 승인으로 GitHub private 레포 `dbsghdz1/girok`을 만들고 커밋 38개를 올렸다. 독자는 한국 독자와 서울을 찾는 외국인 둘이고 언어는 한국어, 영어, 일본어, 중국어 간체와 번체. 네이버 상위 글 16편 실측으로 글쓰기 규칙서(모델 공통)를 만들었다
- **다음 판정**: 2026-11-10. 실제 글 10개가 Slack에서 발행됐고 글당 확인 시간 평균 5분 이하, 수정 지시 평균 1회 이하면 운영으로, 아니면 입력 방식과 규칙서를 다시 본다
- **지금 할 일**: 홍이 Cloudflare Registrar에서 `girok.day`를 산다(표준 연 $10.20, 프리미엄 아님). GitHub private 레포 `girok`은 만들었다(2026-10-21). 남은 것은 Hermes 봇 초대와 홍의 Slack 사용자 ID, Cloudflare Pages 프로젝트 `girok`과 미리보기 Access와 읽기 토큰, 소개와 개인정보처리방침 초안 확인, 저자 표시 이름, 데이트 글의 동행 별칭과 금지 표현 목록. 끝난 것: Slack 채널(2026-10-20), Kakao Developers 앱(2026-10-20, 계정의 첫 활성화 앱이라 무료 쿼터. REST API 키는 서버 설치 때 `BLOG_KAKAO_REST_KEY`로 넣는다), 블로그 이름(2026-10-20)
- **하지 않을 일**: AdSense 신청, 네이버 블로그 동시 게시, 계획서 밖 기능 추가

폰에서 사진 여러 장과 한 줄 메모를 올리면 AI가 카테고리 규칙서대로 한국어 글을 쓰고, 미리보기를 확인한 뒤 「발행」 한마디로 영어, 일본어, 중국어까지 번역돼 개인 도메인에 올라가는 블로그다. 한국에서 열면 한국어, 다른 나라에서 열면 그 나라 언어가 먼저 보인다. 목표는 순서대로 일상 기록, 검색과 AI 답변 노출(SEO, GEO), 글이 쌓인 뒤 광고다. 2026-10-20 홍 요청으로 Claude(Fable)가 설계하고 조사했고 구현은 Opus가 맡는다.

## 핵심 결정 (2026-10-20 계획서 v3, 홍 확정)

| 결정 | 내용 | 이유 |
|---|---|---|
| 디자인 | [v0 blog 템플릿](https://v0.app/templates/blog-Oi5INHKYsqg)의 레이아웃과 타이포를 그대로. 코드는 같은 구조의 BaseHub 공개 저장소 [basehub-ai/nextjs-blog](https://github.com/basehub-ai/nextjs-blog)에서 레이아웃과 스타일만 가져오고 데이터 계층은 우리 것 | 홍이 고른 것. 저장소에 LICENSE 파일이 없어 컴포넌트를 그대로 복사하지 않는다 |
| 콘텐츠 저장 | 템플릿의 BaseHub CMS 대신 레포 안 MDX 파일. 글 1개 = 폴더 1개, 언어별 파일 | AI가 파일을 만들고 PR을 여는 흐름이 가장 단순하고 무료다. 홍이 직접 고칠 수도 있다 |
| 호스팅 | Cloudflare Pages 정적 export + 미들웨어 1개, 도메인도 Cloudflare. 미리보기는 Cloudflare Access 뒤에 | 무료, 광고 허용, 배포별 미리보기, 언어 라우팅. 미리보기 URL은 기본 공개라 접근 제어가 필요하다. Vercel Hobby는 비상업 조건 |
| 승인 버전 | 배포별 고유 URL과 커밋 SHA를 스레드에 올리고 `발행`은 그 SHA에만 유효. 새 커밋이면 승인 무효 | 브랜치 별칭은 최신 성공 배포를 보여 줘 본 것과 올라가는 것이 어긋날 수 있다 |
| 언어 | `/ko/`, `/en/`, `/ja/`, `/zh-hans/`, `/zh-hant/`. 영어가 x-default. 루트와 공유 링크만 브라우저 언어로 분기, 언어판 페이지는 리다이렉트 없음 | 2025년 방한객 순위(중국, 일본, 대만, 미국, 홍콩)와 Google 다국어 지침 |
| 번역 | 한국어 `발행`이 전 언어 승인. Gemini가 3개 언어 번역, 번체는 OpenCC 변환. 결정적 검증과 원문 대조 호출을 통과한 언어만 공개, 번역 고지 줄 | 언어마다 사람 승인을 받으면 읽지 못하는 언어까지 확인 부담이 생긴다. Google scaled content 정책은 고지가 아니라 가치와 품질을 본다 |
| 입력 | Slack 채널에 메시지 1개 = 글 1개(사진 여러 장 + 메모). 사진은 촬영 시각 순 고정 ID, 번호 썸네일 모음을 같이 보냄. 승인과 수정은 홍의 사용자 ID만 | 이미 폰에서 쓰는 도구. 「3번 빼줘」가 언제나 같은 사진을 가리켜야 한다 |
| 실행 | Oracle 서버 타이머가 LLM 없는 스크립트를 돌리고, 초안 1회와 근거 검증 1회, 번역 3회와 대조 3회만 Hermes가 쓰는 Gemini 3.6 Flash를 같은 키로 부른다 | 홍: 「Hermes에 Gemini랑 GPT 있잖아」. 새 키와 결제 없이 0원. 무료 티어 약관 때문에 사진은 얼굴 없는 것만 보내고, 유료 티어(월 약 $2)로 올리면 전부 보낸다 |
| 글쓰기 규칙 | 네이버 상위 글 16편 실측으로 만든 규칙서 하나를 Gemini와 GPT에 같이 쓴다. 해요체, 사진 사이 짧은 글, 정보 블록, 과장 금지. 분량은 상한만 두고 메모에 없는 것은 쓰지도 묻지도 않는다 | 상위 글의 공통점은 어미가 아니라 직접 경험, 사진 많이, 정보 블록, 장단점이었다. 그 수치는 관찰이지 인과가 아니라 최소 조건으로 쓰지 않는다 |
| 승인 | 스레드 답글 `발행`, `보류`, `삭제`, 수정 문장, 발행 뒤 `영어 수정:` | 외부 공개는 홍이 본 뒤에만 |
| 크롤러 | 검색용(Googlebot, Yeti, OAI-SearchBot, Claude-SearchBot, PerplexityBot)은 허용, 학습용(GPTBot, ClaudeBot, Google-Extended)은 홍 결정 | 검색 노출과 학습 허용은 독립 설정이다 |
| 개인정보 | EXIF 전부 제거, 얼굴 검출 경고, 이름과 집 근처는 홍이 확인, 제3자 실명 금지 | 사진 GPS는 집 주소를 드러낸다 |
| 광고 | 자리만 비워 두고 글 25개 뒤 AdSense 신청 | 승인 전 광고는 의미 없다 |

## 코드 저장소

- 로컬 레포 `(로컬 경로)`(2026-10-20 밤 `life-blog`에서 옮김), 원격은 GitHub private `dbsghdz1/girok`(2026-10-21 홍 승인 뒤 생성, 커밋 38개, 기본 브랜치 `main`). `site/`(Next.js 16 정적 export)와 `pipeline/`(Python 3.12)을 레포 하나에 두고, 진행 기록은 레포의 `docs/progress.md`, 에이전트 규칙은 `AGENTS.md`다. 서버용 deploy key와 fine-grained 토큰은 서버 설치 때 홍 승인을 받고 만든다.
