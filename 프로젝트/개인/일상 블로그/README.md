# 일상 블로그

## 현재 카드
- **단계**: 7일 MVP
- **현재**: 2026-10-20 계획서 v2에 Codex 검토 답변을 추가했다. 검토 제안의 설계 반영과 홍 확정 대기. 독자는 한국 독자와 서울을 찾는 외국인 둘이고 언어는 한국어, 영어, 일본어, 중국어 간체와 번체. 네이버 상위 글 16편 실측으로 글쓰기 규칙서(모델 공통)를 만들었다
- **다음 판정**: 2026-11-10. 실제 글 10개가 Slack에서 발행됐고 글당 수정 지시가 평균 1회 이하면 운영으로, 아니면 입력 방식과 규칙서를 다시 본다
- **지금 할 일**: 계획서의 검토 답변을 확인하고 「홍이 확정할 것」 11개와 설계 수정 범위를 정한다
- **하지 않을 일**: 확정 전 코드 작성, AdSense 신청, 네이버 블로그 동시 게시

폰에서 사진 여러 장과 한 줄 메모를 올리면 AI가 카테고리 규칙서대로 한국어 글을 쓰고, 미리보기를 확인한 뒤 「발행」 한마디로 영어, 일본어, 중국어까지 번역돼 개인 도메인에 올라가는 블로그다. 한국에서 열면 한국어, 다른 나라에서 열면 그 나라 언어가 먼저 보인다. 목표는 순서대로 일상 기록, 검색과 AI 답변 노출(SEO, GEO), 글이 쌓인 뒤 광고다. 2026-10-20 홍 요청으로 Claude(Fable)가 설계하고 조사했고 구현은 Opus가 맡는다.

## 핵심 결정 (2026-10-20 계획서 v2, 홍 확정 대기)

| 결정 | 내용 | 이유 |
|---|---|---|
| 디자인 | [v0 blog 템플릿](https://v0.app/templates/blog-Oi5INHKYsqg)의 레이아웃과 타이포를 그대로 | 홍이 고른 것 |
| 콘텐츠 저장 | 템플릿의 BaseHub CMS 대신 레포 안 MDX 파일. 글 1개 = 폴더 1개, 언어별 파일 | AI가 파일을 만들고 PR을 여는 흐름이 가장 단순하고 무료다. 홍이 직접 고칠 수도 있다 |
| 호스팅 | Cloudflare Pages 정적 export + 미들웨어 1개, 도메인도 Cloudflare | 무료, 광고 허용, 브랜치 미리보기, 언어 라우팅. Vercel Hobby는 비상업 조건 |
| 언어 | `/ko/`, `/en/`, `/ja/`, `/zh-hans/`, `/zh-hant/`. 영어가 x-default. 루트와 공유 링크만 브라우저 언어로 분기, 언어판 페이지는 리다이렉트 없음 | 2025년 방한객 순위(중국, 일본, 대만, 미국, 홍콩)와 Google 다국어 지침 |
| 번역 | 발행 승인 뒤 Gemini가 3개 언어 번역, 번체는 OpenCC 변환. 영어는 홍이 훑어보고 나머지는 자동, 번역 고지 줄 | Google scaled content 정책을 피하려면 원문 가치와 고지가 필요하다 |
| 입력 | Slack 채널에 메시지 1개 = 글 1개(사진 여러 장 + 메모). 사진은 촬영 시각 순 번호 | 이미 폰에서 쓰는 도구 |
| 실행 | Oracle 서버 타이머가 LLM 없는 스크립트를 돌리고, 초안 1회와 번역 3회만 Gemini 3.6 Flash 유료 티어 | 무료 티어는 입력을 제품 개선에 쓰고 사람이 읽을 수 있다는 약관이라 사진에 맞지 않는다. 글 1개 약 $0.05 |
| 글쓰기 규칙 | 네이버 상위 글 16편 실측으로 만든 규칙서 하나를 Gemini와 GPT에 같이 쓴다. 해요체, 사진 사이 짧은 글, 정보 블록, 단점 하나 이상, 과장 금지 | 상위 글의 공통점은 어미가 아니라 직접 경험, 사진 많이, 정보 블록, 장단점이었다 |
| 승인 | 스레드 답글 `발행`, `보류`, 수정 문장 | 외부 공개는 홍이 본 뒤에만 |
| 개인정보 | EXIF 전부 제거, 얼굴 검출 경고, 이름과 집 근처는 홍이 확인, 제3자 실명 금지 | 사진 GPS는 집 주소를 드러낸다 |
| 광고 | 자리만 비워 두고 글 25개 뒤 AdSense 신청 | 승인 전 광고는 의미 없다 |

## 코드 저장소

- 아직 없다. 구현 때 `site/`(Next.js)와 `pipeline/`(Python)을 레포 하나에 둔다.

## 이 작업공간에서 관리할 것

- 콘텐츠 계약(frontmatter, 카테고리별 양식, JSON-LD)과 글쓰기 규칙서, 바꾼 이유
- 입력, 초안, 미리보기, 승인, 번역, 발행 흐름의 구조와 제약
- 다국어 라우팅과 SEO, GEO 체크리스트, 광고 신청 시점
- 판정 결과와 되돌림 기록. 발행된 글 목록은 GitHub와 사이트가 기록하므로 여기에 중복해서 쓰지 않는다
