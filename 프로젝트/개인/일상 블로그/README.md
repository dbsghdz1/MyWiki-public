# 일상 블로그

## 현재 카드
- **단계**: 7일 MVP
- **현재**: 2026-10-20 설계 완료, 홍 확정 대기. 디자인은 v0 blog 템플릿, 글은 레포 안 MDX, 호스팅은 Cloudflare Pages, 입력은 Slack 채널, 초안은 Gemini 1회 호출, 발행은 스레드 답글 `발행`
- **다음 판정**: 2026-11-10. 실제 글 10개가 Slack에서 발행됐고 글당 수정 지시가 평균 1회 이하면 운영으로, 아니면 입력 방식과 양식을 다시 본다
- **지금 할 일**: 설계의 「홍이 확정할 것」 9개에 답한다
- **하지 않을 일**: 확정 전 코드 작성, AdSense 신청, 네이버 블로그 동시 게시

폰에서 사진과 한 줄 메모를 올리면 AI가 카테고리 양식에 맞춰 글을 쓰고, 미리보기를 확인한 뒤 「발행」 한마디로 개인 도메인에 올라가는 일상 블로그다. 목표는 순서대로 일상 기록, 검색과 AI 답변 노출(SEO, GEO), 글이 쌓인 뒤 광고다. 2026-10-20 홍 요청으로 Claude(Fable)가 설계했고 구현은 Opus가 맡는다.

## 핵심 결정 (2026-10-20 설계, 홍 확정 대기)

| 결정 | 내용 | 이유 |
|---|---|---|
| 디자인 | [v0 blog 템플릿](https://v0.app/templates/blog-Oi5INHKYsqg)의 레이아웃과 타이포를 그대로 | 홍이 고른 것 |
| 콘텐츠 저장 | 템플릿의 BaseHub CMS 대신 레포 안 MDX 파일. 글 1개 = 폴더 1개 | AI가 파일을 만들고 PR을 여는 흐름이 가장 단순하고 무료다. 홍이 직접 고칠 수도 있다 |
| 호스팅 | Cloudflare Pages 정적 export, 도메인도 Cloudflare | 무료, 광고 허용, 브랜치마다 미리보기. Vercel Hobby는 비상업 조건이라 광고와 맞지 않는다(2026-10-20 기준, 구현 때 재확인) |
| 입력 | Slack 채널에 메시지 1개 = 글 1개(사진 + 메모) | 이미 폰에서 쓰는 도구 |
| 실행 | Oracle 서버 타이머가 LLM 없는 스크립트를 돌리고, 초안만 Gemini 3.6 Flash 1회 | Hermes 에이전트 턴은 무료 쿼터 때문에 조용히 죽은 전례가 있다 |
| 승인 | 스레드 답글 `발행`, `보류`, 수정 문장 | 외부 공개는 홍이 본 뒤에만 |
| 개인정보 | EXIF 전부 제거, 얼굴과 이름과 집 근처는 미리보기에서 홍이 확인, 제3자 실명 금지 | 사진 GPS는 집 주소를 드러낸다 |
| 광고 | 자리만 비워 두고 글 25개 뒤 AdSense 신청 | 승인 전 광고는 의미 없다 |

## 코드 저장소

- 아직 없다. 구현 때 `site/`(Next.js)와 `pipeline/`(Python)을 레포 하나에 둔다.

## 이 작업공간에서 관리할 것

- 콘텐츠 계약(frontmatter, 카테고리별 양식, JSON-LD)과 바꾼 이유
- 입력, 초안, 미리보기, 발행 흐름의 구조와 제약
- SEO와 GEO 체크리스트, 광고 신청 시점
- 판정 결과와 되돌림 기록. 발행된 글 목록은 GitHub와 사이트가 기록하므로 여기에 중복해서 쓰지 않는다
