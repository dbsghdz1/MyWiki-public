# 사진 선지 복원 스파이크 (2026-09-01)

홍: *"사진 문제 빠진 게 너무 아쉬워. 유료앱은 완성도가 중요한데."* — 사진 선지 108문항(6%)을 **시험지 사진이 아니라 자유이용 사진(공공누리 1유형·CC·PD)으로 복원**할 수 있는지 12문항·선지 55개 표본으로 쟀다. 배경: [[프로젝트/개인/한능검/한능검 시장 조사 2026-08-26|시장 조사]] 4절(시험지 사진은 제3자 저작물 — 국편 고지 2026-09-01 재확인), 1위 앱은 사진을 따로 조달.

## 소스별 라이선스 (실제 확인)

- **국가유산청**: 기본 공공누리 1유형(출처표시, 상업·변경 가능) — khs.go.kr 저작권정책. 국가유산포털 사진 목록은 비공개 AJAX `selectCulImageList.do`(JSON, `open` A/D 코드 — A=1유형 추정, **매핑 미검증**). 부석사 소조여래좌상·간송 매병은 전부 D.
- **국립중앙박물관 museum.go.kr**: 확인한 소장품 5건(철조석가불좌상·송시열 초상·청동 은입사 정병·명도전·구한말 동전) 모두 **출처표시(1유형)**. e뮤지엄은 소장품별 상이 — 공공데이터포털 "e뮤지엄 유물정보" API(약 11.6만 건, 키 필요)로 검색 가능.
- **Wikimedia Commons**: MediaWiki API `list=search` + `extmetadata.LicenseShortName`로 일괄 확인. 한국 문화유산 사진이 CC0·CC BY(-SA)·KOGL 1·PD로 풍부. UA 없이 연속 호출하면 429.
