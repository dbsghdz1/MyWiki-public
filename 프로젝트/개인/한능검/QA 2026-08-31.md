# QA — v1.1~1.3 통합 점검 (2026-08-31)

기능 QA(Maestro) + 코드 리뷰를 돌려 **7건을 수정**했다. 회귀 주행 15스텝 전부 통과.

## 기능 QA

| 항목 | 결과 |
|---|---|
| 다크 모드 (홈·채점·강의·기본 홈) | ✅ `maestro/dark.yaml` 4컷 — 유리 캡슐·한지·채점색 정상 |
| 웹 체험판 잠금·Paywall | ✅ `maestro/web-paywall.yaml` 4컷 — 76회 잠금, 기본 체험 75회 열림 |
| 이어풀기·레벨 분리 저장 | ✅ (QA 중 확인) |

## 코드 리뷰 수정 7건 (medium, `web/src` 전체)

1. **이어풀기 결번 버그 (핵심)** — 문항 번호에 결번(사진 선지 제외: 79회는 6·11번 없음)이 있는데 `firstUnsolved`가 1..count 연속 번호를 가정 → **첫 결번에서 영구히 걸려 항상 같은 문항으로 재개**. 실제 문항 배열 `findIndex`로 교체 (`at: -1` = 이어풀기 신호)
2. **기록 지우기가 '극복' 표시를 안 지움** — 다시 풀다 틀린 문항이 오답노트에 영영 안 뜨는 경로. `clearProgress`가 해당 회차 overcome도 삭제
3. **출처표시 미렌더 — CLAUDE.md 불변 조건 위반** — `index.source`를 로드만 하고 어디에도 안 그렸다. 홈 하단에 국편 출처 + "무관한 개인 개발자" 명시
4. 노트 fetch 1회 실패 시 빈 캐시가 고정돼 세션 내내 노트가 사라짐 — 실패 시 재시도 가능하게
5. Paywall 기본 체험 문구 "제75~79회"(범위 표기) — 78회 기본이 없어 오표기 → "제79·77·75회" 나열로
6. `roundFile` 중복 정의 → `edition.ts`로 통합
7. 도달 불가능한 선택 하이라이트 분기 + 미사용 `.picked` CSS 제거

리뷰가 기각한 후보(fetch 레이스·id 충돌 등)는 근거와 함께 반려됨 — 오탐 아님 확인.

## 미수정으로 남긴 것

- **채점된 문항 재방문 시 강의·노트 카드가 하단 캡슐 뒤에 있음** — 스크롤하면 보여 동작엔 문제없음. 재방문에도 자동 스크롤을 넣을지는 UX 취향 문제라 보류 (넣으면 문항 확인 전에 화면이 내려가버림)
- 심화 79회 문항 수가 48로 감소 표기(사진 선지 제외) — 데이터 정합상 올바름. 스토어 문구의 "1,102문항"과는 무관(전체 합계)

## 교훈

**"탭 COMPLETED인데 무반응"과 "이어풀기 어긋남"은 둘 다 플로우 주행이 잡았다** — 정적 리뷰는 결번 가정 버그를, 주행은 오버레이 가림을 각각 잡아 상호 보완이 실증됨.
