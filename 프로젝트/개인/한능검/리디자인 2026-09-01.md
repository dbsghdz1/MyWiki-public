# 리디자인 (v1.5) — 노션형 구조 + Liquid Glass 컨트롤

홍: *"UI를 바꾸고 싶고 조금 더 제대로 만들고 싶어"* → 코드 전에 **시안부터**. 방향 질문 둘(톤·범위) → "토스·노션 단정함, 전체" → 5화면 시안 + 홈 대안 → 홍 선택 **"노션형 + 리퀴드"**.

시안: https://claude.ai/code/artifact/43cb2c88-aee8-4a38-9ced-96c6b3d84f12 (A 토스형 카드 5화면 · B 노션형 홈 대안)

## 채택한 시스템

| | |
|---|---|
| 구조 | **카드·그림자 없음.** 흰 배경 + 헤어라인(`--line #f2f4f6`) + 여백 + 큰 숫자 히어로. 목록은 `.row` 한 줄 단위 |
| 컨트롤 | 상단 캡슐·세그먼트만 **Liquid Glass** — 유리는 떠 있는 것에만 |
| 색 | 토스 그레이 램프(`#191f28 / #8b95a1 / #f2f4f6`) + 신호색(정답 초록·오답 빨강) + 자료 박스 한지. 그 외 색 없음 |
| 홈 | `제80회까지 · 날짜` / **D-46**(54px) / "1,102문항 중 n문항 풀이 · 완료 n회차" → 먹색 룰 위 이어서 풀기 → 오답노트 → 회차 행 |
| 결과 | 링+정답수 가로, **시대별 정답률 바(60% 미만 빨강)**, 문항 지도 8열, 오답 있으면 CTA "오답 n개 다시 풀기" |
| 풀이 | 문항 번호 큰 숫자, 배점·시대 칩 |

## 과정에서 배운 것

- **디자인을 먼저 보여주니 결정이 한 번에 났다.** 앞선 "프리미엄 패스"는 코드로 먼저 만들었다가 "유료앱 같지 않다"로 반려됐고, 시안(캔버스)으로 A/B를 나란히 두자 한 마디("노션형 + 리퀴드")로 확정. 시안 검토에서 잡힌 건 화면 간 예시 숫자 불일치 하나뿐.
- 화면 전환 시 이전 스크롤 위치가 남아 짧은 화면(오답노트)이 iOS 바운스로 내려앉았다 — `view.name` 변경마다 `scrollTo(0,0)`.
- Maestro 앵커는 그대로 살았다 — 행 버튼이 "제79회 44문항"으로 합쳐지는 라벨 구조를 유지했기 때문. 리디자인해도 **접근성 라벨 구조를 보존하면 플로우가 안 깨진다.**
