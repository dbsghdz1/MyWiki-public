# 이름과 색 — 한국사 정복 · 먹색과 한지

## 이름: **한국사 정복** (2026-08-28 확정)

App Store 이름은 **`한국사 정복 - 한능검 기출`**. 부제는 *모르면 강의로 바로 · 심화 기출 1,102문항*.

**중복 확인**: App Store에 `한국사 정복`이라는 앱은 **없다**. 기존에는 `한국사 능력`·`한국사 능력 기본`·`한국사 오답노트`·`수능 한국사`·`한국사 요점정리`가 있다. **선점 가능하다.**

이름 하나에 검색어 셋을 담았다 — `한국사`(가장 넓은 검색어) · `정복`(동기·차별) · `한능검 기출`(구매 의도가 가장 높은 검색어). 30자 제한에 16자라 여유가 있다.

> [!note] 검색 중 발견한 것
> - **시장 조사(08-26) 때 없던 경쟁자**: `한국사능력검정시험 - 기본 기출문제`(최근 등록, AI 해설·시대별 학습·오답노트)
> - **문항 수 격차**: 2위 `한국사 능력`이 **7,970문항 + 해설 6,250**. 우리는 1,102문항이다. `오르조`는 2012~2025 전 회차
> - **홍의 결정: 회차는 나중에 추가한다.** 파이프라인이 자동화돼 있어 시간만 들이면 되는 문제다

## 색: 파랑 → **먹색 + 한지** (2026-08-28 변경)

홍이 *"파란색보다 검정이나 갈색이 나아 보인다"*고 했고, **세 안을 실제로 렌더링해 비교**했다. 감각이 아니라 기능 문제였다.

> [!important] 문제 풀이 앱에서 색은 신호다
> 정답=초록, 오답=빨강을 쓰는데 **주색이 강하면 그 신호와 경쟁한다.**
> - **파랑**: 흔하다(교육 앱 기본값). 초록·빨강과 합쳐 3색이 된다
> - **갈색**: ❌ **빨강과 색상환에서 가깝다.** 실제로 렌더링하니 갈색 `다음` 버튼과 빨간 오답 테두리가 같은 계열로 읽혔다
> - **먹색**: ✅ 주색이 무채색이라 **초록·빨강만 색을 갖는다.** 신호가 선명해진다

**한국사 정체성은 주색이 아니라 자료 박스로 낸다.** 발문 위 지문(사료·자료)만 **한지색 배경 + 고서 표지색 왼쪽 선**으로 처리했다. 화면에서 "옛 문서를 옮겨 놓은 자리"가 시각적으로 구분되고, UI 신호는 깨끗하게 남는다.

```
--accent: #1a1a1a       /* 먹 */
--paper: #faf6ee        /* 한지 */
--paper-edge: #8b6f47   /* 고서 표지 */
```

**다크 모드에서는 주색을 반전**한다(`--accent: #f2f0ec`, `--on-accent: #16181d`). 먹색을 그대로 두면 어두운 배경에서 버튼이 사라진다. 한지색도 어두운 톤(`#1c1a17`)으로 낮췄다.

앱 아이콘도 먹색 바탕 + 한지색 획 + 고서 테두리로 교체했다.

## 검증

라이트·다크 양쪽을 WKWebView 스냅샷으로 확인했다. 오답 케이스(빨강)와 정답 케이스(초록)가 같이 나오는 화면으로 찍어 **신호 충돌이 없는지**를 봤다.
