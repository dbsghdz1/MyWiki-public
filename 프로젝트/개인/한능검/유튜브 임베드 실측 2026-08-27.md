# 유튜브 임베드 실측 — 차별점의 마지막 전제를 확인했다

> [!warning] 2026-09-02 뒤집힘 — 판정은 "임베드 허용"이었지 "앱에서 재생됨"이 아니었다
> `playableInEmbed`는 영상 쪽 설정이고, **재생 시점에 유튜브는 임베드한 쪽의 HTTP Referer를 요구한다.** Capacitor 앱은 capacitor:// 스킴이라 Referer가 없고, 재생 버튼을 누르면 **오류 153**이 난다(시뮬레이터 실측 — 썸네일·플레이어 UI는 떠서 이 판정으론 안 걸렸다). 해결: **https 래퍼 임베드** — GitHub Pages `dbsghdz1/hangeom-docs/player.html?v=<id>`(원본 `(로컬 경로)`)를 앱이 iframe으로 물면 유튜브는 정상 웹사이트의 임베드로 보고 재생한다(시뮬레이터 재생 실측 통과). 래퍼가 죽으면 `EMBED_IN_APP=false` 외부 열기 폴백. 교훈: **임베드 검증은 재생 버튼까지 눌러야 끝난다.**

[[프로젝트/개인/한능검/차별점 검증 2026-08-26|차별점 검증]]에서 **"확인 안 된 것"**으로 남겨둔 두 항목이다.

> *"최태성 등 주요 강의의 임베드 허용 여부 — 채널별로 다르고, 소속사(EBS·이투스 등) 정책이 걸릴 수 있다. 실제 영상 몇 개로 임베드 가능 여부를 직접 확인해야 한다."*

**둘 다 통과했고, 예상하지 못한 소득이 하나 더 나왔다.**

## 판정 방법 — API 키 없이 판정한다

유튜브 Data API의 `status.embeddable`을 쓰려면 키가 필요하다. 대신 **`/embed/<id>` 페이지에 들어 있는 `embedded_player_response`**를 파싱했다.

```
videoFlags.playableInEmbed              ← 임베드 허용 여부 (불리언)
previewPlayabilityStatus.playableInEmbed
previewPlayabilityStatus.status          ← OK / UNPLAYABLE / ERROR
```

도구는 `tools/embcheck.py`. 영상 ID를 주면 `OK / BLOCKED / ?`를 뱉는다.

> [!warning] oEmbed는 임베드 판정에 쓸 수 없다
> 처음엔 `youtube.com/oembed`의 HTTP 상태로 판정하려 했는데, **검사한 60개가 전부 200**이었다. oEmbed는 사실상 *영상이 존재하는가*에 가깝지 임베드 허용 여부가 아니다. 이걸 근거로 삼았으면 잘못된 확신을 얻을 뻔했다.

## 대조군을 먼저 세웠다

"전부 OK"라는 결과는 **판정기가 항상 OK만 뱉는 경우에도 똑같이 나온다.** 그래서 차단 사례를 먼저 확보했다.

| 대조군 | 결과 |
|---|---|
| 일본 음반사 채널 24개 | **6개 `UNPLAYABLE`** · 18개 OK |
| 국내 방송사(SBS·KBS·MBC·JTBC) 27개 | 27개 OK |
| 무작위 유명 영상 6개 | 1개 `ERROR`(재생 불가) · 5개 OK |

**판정기가 실제로 재생 불가를 구별한다**는 걸 확인한 뒤에 본 검사를 돌렸다.

## 결과 — 검사한 강의 전부 임베드 허용

| 대상 | 검사 | 임베드 허용 |
|---|---|---|
| 최태성 1TV **심화 자막 속성 분절** | 100 | **100** |
| 최태성 1TV **심화 PT 통강** | 40 | **40** |
| 최태성 1TV 최근 업로드 | 30 | **30** |
| 에듀윌 한국사능력검정 | 30 | **30** |
| **합계** | **200** | **200 (100%)** |

소속사 정책 걸림돌은 없었다. 최태성 1TV는 **모든 강의를 무료 공개**로 표방하는 공식 채널이고, 실제로 임베드도 전부 열려 있다.

## 예상 못 한 소득 — 타임스탬프가 필요 없다

차별점 검증에서는 매핑 단위를 *"키워드 → 영상 **구간**"*으로 잡았다. 구간이면 영상 ID에 더해 시작·끝 초를 손으로 찍어야 한다.

그런데 **강의가 이미 주제 단위로 분절되어 있었다.**

```
[심화별개념9] 4-2 고구려의 발전 / 4강 고대(고구려,가야)
[심화별개념9] 6-3 발해(건국과 발전) / 6강 고대(통일신라, 발해)
[심화별개념9] 8-3 불교 / 8강 고대(문화1)
[심화별개념9] 30-2 동학 농민 운동 / 30강 개항기(동학 농민 운동~대한 제국)
```

강의 체계가 **40강 × 하위 절**이고, 그 하위 절이 [[프로젝트/개인/한능검/키워드 태깅 2026-08-27|우리 topic]]과 같은 입도다. 시대 구분도 그대로 겹친다 — 2~3강 선사, 4~9강 고대, 10~15강 고려, 16~21강 조선 전기, 22~27강 조선 후기, 28~33강 개항기, 34~37강 일제 강점기, 38~40강 현대.

> [!important] 매핑이 "구간 찍기"에서 "영상 고르기"로 바뀐다
> 문항 단위로 붙이면 1,102번, topic 단위면 153번이었는데, **거기서 타임스탬프 작업이 통째로 빠진다.** topic에 영상 ID 하나만 대응시키면 끝이다.

분절 강의 100개(1~34강)를 `data/youtube/segments.json`에 저장했다. 재생목록 페이지가 한 번에 100개까지만 주므로 35~40강 분절은 아직 안 받았다.

## 남은 리스크

- **링크 수명** — 차별점 검증에서 이미 짚었다. 깨진 링크 감지 + 키워드 검색 폴백은 그대로 필요하다. `tools/embcheck.py`를 주기적으로 돌리면 감지는 자동화된다
- **채널 단일 의존** — 최태성 1TV 하나에 걸면 채널 정책이 바뀔 때 차별점이 통째로 흔들린다. 에듀윌도 임베드가 열려 있으니 **2순위 채널로 병기**해 두는 게 안전하다
- **약관** — *"유료 콘텐츠가 주로 임베드 영상"* 조항은 [[프로젝트/개인/한능검/차별점 검증 2026-08-26|차별점 검증]]에서 **영상 연결을 무료 기능으로 두는 설계**로 이미 피해 뒀다. 이번 실측이 그 결론을 바꾸지 않는다
