# 오답노트 (v1.2) — 구현 완료, 시뮬레이터 E2E 검증

PRD v1.2 축(오답·복습). 콘텐츠 제작 없이 기존 데이터(era 태그·정답)로 만들었고, **전부 로컬 계산**이다 — 서버·계정을 만들 이유가 되지 않는다는 CLAUDE.md 원칙 그대로.

## 만든 것

- **오답노트 화면** — 풀이 기록이 있는 회차의 데이터만 내려받아(브라우저 캐시로 재방문 무료) 틀린 문항 목록 + **시대별 정답률 바**. 홈에 진입 카드
- **다시 풀기** — 오답만 순회하는 재풀이. 맞히면 '극복'으로 빠지고(빈 화면: *"재풀이로 N문항을 극복했습니다"*), 틀리면 남는다 — "맞힐 때까지"
- 수준(심화/기본)별로 분리. 문항 렌더는 `QuestionCard`로 추출해 회차 풀이와 한 벌 공유

## 설계 결정 둘

1. **원 회차의 채점 이력은 절대 덮지 않는다.** 재풀이 결과는 별도 키(`hangeom:review:<level>`)의 `overcome`에만 쓴다 — 시대별 통계는 첫 채점 기준이라 실력 변화가 왜곡되지 않고, 스키마 마이그레이션도 필요 없다
2. **재풀이 세션은 진입 시점 목록을 동결한다.** 풀다 맞혀도 목록이 즉시 줄지 않아 인덱스가 밀리지 않고, 극복분은 목록으로 돌아올 때 반영된다

## 검증

Maestro 플로우를 14컷으로 확장 — 기본 79회 1번을 **일부러 틀려** 오답을 만들고, 오답노트 목록(선사 0/1) → 재풀이 → 정답 → *"맞혔어요 — 오답노트에서 빠집니다"* → 빈 목록까지 완주. `web/maestro/shots/20260831-0004-v1.2-review/`.
