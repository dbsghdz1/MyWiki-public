## 파이프라인 (`tools/photos_*.py`)

1. `photos_render.py` — 제외 문항 시험지 페이지 렌더(150dpi, 식별용 — 시험지 사진은 앱에 넣지 않는다) + `targets.json`
2. 식별 에이전트 3조(Fable) — 페이지를 보고 선지마다 정식 명칭·kind·확신도·표준영정 여부. 475선지, 확신도 상 409·중 52·하 14, 정답 정합 불일치 0. 부수 발견: 75-3·59-6 페이지 번호 오류.
3. `photos_fetch.py search` — Commons 검색(라이선스 기계 판독, 허용 목록만) → 조달 에이전트 6조(Sonnet)가 검색어를 만들고 썸네일을 눈으로 대조해 선택 → `picks/*.json`. 같은 이름 재사용 자동 회수 36 + 2차 회수 조 35.
4. `photos_finalize.py` — 선택 파일을 Commons에서 640px로 재수신·라이선스 재검증·리사이즈, `data/*.json` 복원(`choices`=이름, `choiceImages`, `excluded=false`), `credits.json`. 규칙: 특정 국보에 동종 대체 금지, 복제·모작 금지.
5. 태그·해설 에이전트 2조 → `tag.py`·`explain.py` → `export.py`(choiceImages 전달) → `webdata.py`.
