# AI 예상 모의고사 — 제80회(10/17) 대비 50문항 × 5회 (2026-09-04 착수)

홍 제안·결정(09-04): *"리뷰 요청과 AI가 예상하는 이번 한국사 시험을 만들어서 50문제 5회 정도 내볼까?"* → **착수.** 2.2.0에 싣는다. 시즌 훅(강사들의 "파이널 모의고사"를 앱 안에)이자 홍보 소재("AI가 뽑은 제80회 예상 주제"). 기출과 달리 저작권 문제 없음. 리스크는 **틀린 사실 = 유료 앱 1★** 이라 생성보다 검증이 일이다.

## 방법 — 감이 아니라 빈도

1. **슬롯 통계** (`tools/predict_slots.py` → `data/predict/slots.json`): 심화 23회차(57~79) 1,149문항에서 **번호별 시대 분포**(한능검은 시대순 배열이라 번호→시대가 70~100%로 안정)와 **시대 안 주제 출제 빈도**(최근 회차 가중 0.45→1.0)를 세어 50슬롯 × 5벌. 한 벌 안 주제 중복 금지, 벌끼리는 상위 주제 분산, 시대 블록 안은 연대순(`topics.json` 순서), 배점 합 100(3점 6~8개).
2. **재료 한정** (`tools/predict_material.py` → `data/predict/material/<주제>.json`): 주제별 요약 노트 + 그 주제 기출 전부(자료·선지·정답·해설). 생성 규칙 원본은 `data/predict/SPEC.md` — **재료 밖 사실 금지, 기출 문장 12자 이상 복제 금지, 정답 유일, 오답은 다른 시대·인물의 사실, 자료 제시형 5지선다, 해설 필수, 강사·교재 이름 금지.** 만들 수 없으면 skipped.
3. **생성**: 벌마다 에이전트 1개(5개 병렬), 슬롯 50 + 예비 10. 10문항마다 자체 재점검 후 누적 저장.
4. **검증 3겹**: ① 기계(`tools/predict_verify.py`: 필드·선지 5·정답 범위·선지 중복·기출 부분 문자열 복제·세트 내 중복) ② **블라인드 풀이** — 다른 에이전트가 정답 모른 채 풀고 `tools/predict_compare.py`로 대조, 불일치·low 확신은 폐기 ③ 홍 표본 20%.
5. **내보내기** (`tools/predict_export.py` → `web/public/data/predict-80-N.json`): pass 문항만, 실패 슬롯은 같은 주제 예비로 대체, 강의 링크는 같은 주제 기출에서 재사용. id `P80-N-nn`, `official: false`, 비공식 문구.

## 진행 (2026-09-04, 착수 ~ 제출까지 약 13시간)

- **생성**: 5세트 × 60문항(본 50 + 예비 10) = 300문항, skipped 0. 에이전트당 55~62만 토큰·25~28분. 기계 검증기가 기출 12자 복제를 세트당 25~30건씩 잡아 전부 재작성됐다.
- **블라인드 풀이**: 5세트 × 60 = 300문항, 생성 정답과 **불일치 0**. 풀이자가 low로 표시한 2건이 실제 결함이었다 — 세트 1의 1번(청동기 문항에 "가락바퀴로 실을 뽑았다"가 한정어 없이 있어 정답이 둘) → 선지에 '시작' 추가, **세트 2의 22번(한산도 대첩 "이후" 문항에 정묘호란 1627 정봉수가 오답으로 들어가 정답이 둘)** → 삼포왜란·비변사(1510)로 교체. 그 외 풀이자 지적 3건은 표현 수정(세트 4의 7번 시무 10여 조 "받아들이지 않았다"→"시행되지 못하였다", 세트 5의 4번 대성동 고분 "금동관"→"철제 갑옷과 덩이쇠", 세트 1 spare-36 주어 중복).
- **세트 간 중복**: 3-gram Jaccard로 잡힌 좌우 합작 44번(세트 2·4·5가 같은 김규식 인물 카드)과 통일 정책 49번(세트 1·2). 세트 4의 44번은 여운형 인물 카드, 세트 5의 44번은 "삼천만 동포에게 읍고함" 이후 사실로 **다시 써서** 재풀이(둘 다 high), 세트 2의 49·50번은 같은 주제 예비로 대체(50번은 세트 3과 교육기관 4개 비교 구조가 같아 수동 지정).
- **내보내기**: 5세트 × 50문항, 배점 합 100, 시대 배열 단조, 정답 위치 세트당 ①~⑤ 각 9~12개(균형 셔플, 해설 원문자 재매핑, 연표형 고정), 강의 링크 47~49개/50. `web/public/data/predict-80-{1..5}.json`.
- **홍 표본 검수 페이지**: 세트당 10문항·총 50문항(20%)을 정답·해설과 함께 — https://claude.ai/code/artifact/94020b5b-145e-4e1d-8951-5184192cf6a6 (문제 있음 체크 + 댓글). 제출과 병렬로 본다 — 결함이 나오면 2.2.1.
- **앱**: Maestro 회귀 30장 통과(예상 모의고사 시작→풀이→채점 구간 추가). 2.2.0(build 10) 제출 — [[프로젝트/개인/한능검/App Store 심사 이력|심사 이력]].
- **AI가 작성한 문항 5개를 내가 직접 읽은 표본(세트 3의 7·15·29·41·50, 세트 1의 5·39·50, 세트 4의 13·50, 세트 5의 21·38·42, 세트 2의 35)**: 사실·연대·오답 구성 모두 이상 없음.

## 기본 5벌 추가 + 심화 2.2.1 수정 (2026-09-05)

홍 지시 *"심화만 만들었지? 기본도 만들어줘"* → 기본(4지선다·70분) 5벌 250문항을 같은 파이프라인으로 만들었다. **도구는 새로 쓰지 않고 수준으로 매개변수화**했다 — `tools/predict_cfg.py` 신설, `PREDICT_LEVEL=basic`이면 선지 4개·`basic-*.json` 기출·`data/predict-basic/`·출력 `predict-basic-80-N.json`·id `B80-N-nn`. 심화 내보내기가 09-04 결과와 바이트 동일함을 먼저 확인하고 갈랐다.

**슬롯**: 기본 시행 14회차 700문항으로 번호별 시대 분포(1번 선사 100% … 50번 통합 70%)와 주제 빈도를 다시 세어 5벌 × 50슬롯. 재료는 주제별 노트 + 기본 기출에 **같은 주제의 심화 기출(`past_advanced`)을 사실 범위로만** 덧붙였다 — 형식은 기본, 사실은 넓게.

**검증에서 파이프라인 결함 셋이 나왔다** (상세: [[작업노트/도구/LLM 문항 생성 검증|LLM 문항 생성 검증]]).
1. 복제 검사가 4자 간격 샘플링이라 사이 구간을 놓쳤다 → 12자 shingle 집합 전수 대조로 교체. 분포를 재보니 20자 이상은 0건이라 **16자 이상 불합격 · 12~15자 경고**로 임계값을 다시 잡았다.
2. 블라인드 사본이 원본 선지 순서를 그대로 써서 **검증이 무력화**됐다 — 기본 세트 2는 정답 60/60이 1번, 세트 5는 58/60. 사본에 셔플 + 순열표를 넣고 세 세트를 다시 풀렸다.
3. 자료 Jaccard가 실질 중복을 놓쳤다 — 직지심체요절 문항이 네 세트에 자료 형식만 바꿔 들어갔다(0.25~0.39). **같은 주제 + 정답 문장 유사도 ≥ 0.5** 규칙을 dedup에 추가.

**심화 2.2.1** — ①을 고치자 **이미 배포된 2.2.0에서 16자 이상 겹침 7문항**이 드러났다(최장 19자 `부소산성, 나성, 능산리 고분군, 정림사지`). 홍 지시로 함께 수정. 겹친 문장 하나씩만 다시 써 **정답 번호는 250/250 그대로**, 바뀐 문항은 의도한 7개뿐임을 재현 내보내기 diff로 확인했다(재검증 불필요).

**최종 상태 (기본)**: 5세트 × 60문항(본 50 + 예비 10) 기계 검증 불합격 0, 블라인드 대조 불일치 0, 자료를 고친 17문항 재풀이 불일치 0. 내보낸 250문항 전부 4지선다·배점 100·강의 49/50·정답 위치 12~13씩 균등.

**앱**: `Mock.tsx`의 예상 섹션에서 `level === '심화'` 조건을 걷고 수준별 파일을 받게 했다. Maestro 회귀에 기본 예상 구간을 추가(30 → **33장**) 후 주행 통과. 2.2.1(build 11) 빌드·`cap sync` 완료, **제출은 하지 않았다.**

**남은 것**: 실질 중복 22쌍(완전 동일 14)이 예비 부족으로 남았다. 근본 해결은 슬롯 생성기가 5벌에 같은 상위 주제를 배정하는 구조(`임진왜란`·`국외 독립운동 기지` 등 7개 주제가 5벌 전부)를 바꾸거나, 예비를 "빈도 상위 10슬롯"이 아니라 "세트 간 겹치는 주제"로 뽑는 것. 심화 기준(14쌍·동일 5)과 견주면 기본이 2배 넘는데, 주제 풀이 좁고 선지가 4개라 일부는 불가피하다.
