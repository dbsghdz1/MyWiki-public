## 만든 것
- **주소**: https://hangeom-predict.vercel.app (Vercel 프로젝트 `hangeom-predict`, 앱 체험판 사이트와 분리 — 앱 ₩6,600 가격 앵커를 건드리지 않으려고)
- **코드**: `(로컬 경로)` — Vite + React, 라우팅은 해시(`#/심화/1`). 데이터는 앱의 `predict-80-{1..5}.json`·`predict-basic-80-{1..5}.json` 그대로 복사(심화 250 + 기본 250).
- **무료 범위**: 수준별 1회의 1~5번. 6번부터, 그리고 2~5회는 잠금(`src/config.ts`의 `FREE_LIMIT`·`FREE_SET`).
- **결제**: PG 심사(토스페이먼츠 며칠~2주)를 기다리지 않는다. 토스 송금 링크(990원) → 입금자명 전달 → **코드 발급**(수동). 코드는 Vercel 환경 변수 `UNLOCK_CODES`(쉼표 구분 20개, 로컬 `unlock-codes.local.txt`, git 제외). `api/unlock.js`가 대조해 `{ok}`를 주고 클라이언트는 localStorage `p80:unlocked`에 저장. 데이터 파일이 공개 경로라 뚫으려면 뚫리지만 990원 실험에 맞는 수준.
- **풀이 UX**: 선택 즉시 정답·오답 표시 + 해설(why·오답 선지 설명) + 관련 무료 강의 링크. 50문항 끝나면 /100 채점과 급수 구간.

## 6차 — 실키 전환 + 결제 Slack 알림 (2026-10-05 밤)

- **실키 전환됨.** 토스페이먼츠가 「퀵오픈이 적용되었어요 · 지금 즉시 카드결제 서비스를 사용할 수 있어요」를 보냈고(홍 전달), 홍이 `set-live-keys.sh`를 돌렸다. 라이브 실측: 번들에 `live_gck`, `POST /api/confirm`에 가짜 paymentKey → `NOT_FOUND_PAYMENT_SESSION`(시크릿 키 유효). 검색용 4개 주소와 소유 확인 태그는 그대로 200.
- **근거 충돌**: 같은 시각 상점관리자는 신청 현황 「심사중」·계약일 비어 있음, 개발자센터 HSW 라이브 키 화면은 「계약이 완료되지 않은 상점은 라이브 환경에서 결제를 할 수 없어요」 경고를 그대로 보였다. 퀵오픈 안내와 화면 표시 중 어느 쪽이 맞는지는 **홍 폰 실결제 1건**으로만 가려진다 — 아직 하지 않았다.
- 개발자센터 API 키 메뉴는 「개발 연동 체험 상점」이 먼저 열리고 거기서는 「내 키는 전자결제 신청하고 확인할 수 있어요 · 이용 신청하기」가 뜬다. 다시 신청하라는 뜻이 아니다 — 상점을 「에이치에스더블유(HSW)」로 바꾸면 라이브 키가 보인다. 키 이름은 「결제위젯 연동 키」에서 「주문서형·결제창형 연동 키」로 바뀌었다.
- **결제 Slack 알림**(홍: *"결제 될때마다 슬랙으로 알림줘야하는거알지?"*): `api/_lib.js`에 `saleText`·`notifySale`, `api/confirm.js`의 첫 승인 성공 경로에서 `await notifySale(…)` 뒤 지급. Zappy 웹훅과 같은 Incoming Webhook `SLACK_WEBHOOK_URL`을 쓴다. **결제된 순간만** 보낸다(같은 날 Zappy 웹훅에 건 홍 규칙) — 실패·주문번호 복원·새로고침 재확인(`ALREADY_PROCESSED_PAYMENT`)은 보내지 않는다. 웹훅이 죽어도 2.5초 뒤 포기하고 지급은 한다. 문구: `💳 한능검 예상 모의고사 결제 ₩2,900 · 전체 10회 · 카드` + 주문번호 + 영수증 주소, 테스트 키면 `🧪 [테스트 키]`가 앞에 붙는다.
- 검증: fetch를 가짜로 바꾼 노드 스크립트로 웹훅 미설정·테스트 키 문구·실키 간편결제 문구·웹훅 예외·승인 성공 시 1회·승인 실패 시 0회를 확인. **실제 Slack 도착은 미확인** — `SLACK_WEBHOOK_URL`이 `hangeom-predict` Production에 아직 없다. `zappy-landing`에서 값을 옮기는 명령을 auto 모드 분류기가 「Credential Exploration」으로 막아 홍이 직접 넣는다.
- **빈 곳**: 토스 미니앱 안 인앱 결제는 우리 서버를 거치지 않아 이 알림이 가지 않는다. 환불·취소 알림도 없다.
