# 예상 모의고사 웹 판매 실험 — 990원 · 송금 링크 + 코드 (2026-10-01)

홍 결정(10-01): *"웹을 빠르게 만들고 카페 + 블로그에 넣는거지 … 5번까지 풀고 그 이후에 결제"*, *"SEO 필요없으면 그냥 vercel로 배포하고 결제만 붙일까?"* → **도메인·SEO 없이 vercel.app 주소로 바로 띄웠다.** 유입은 카페·블로그 글의 링크로 직접 들어오므로 색인·순위는 필요 없고, 링크 미리보기용 OG 태그만 넣었다.

## 만든 것
- **주소**: https://hangeom-predict.vercel.app (Vercel 프로젝트 `hangeom-predict`, 앱 체험판 사이트와 분리 — 앱 ₩6,600 가격 앵커를 건드리지 않으려고)
- **코드**: `(로컬 경로)` — Vite + React, 라우팅은 해시(`#/심화/1`). 데이터는 앱의 `predict-80-{1..5}.json`·`predict-basic-80-{1..5}.json` 그대로 복사(심화 250 + 기본 250).
- **무료 범위**: 수준별 1회의 1~5번. 6번부터, 그리고 2~5회는 잠금(`src/config.ts`의 `FREE_LIMIT`·`FREE_SET`).
- **결제**: PG 심사(토스페이먼츠 며칠~2주)를 기다리지 않는다. 토스 송금 링크(990원) → 입금자명 전달 → **코드 발급**(수동). 코드는 Vercel 환경 변수 `UNLOCK_CODES`(쉼표 구분 20개, 로컬 `unlock-codes.local.txt`, git 제외). `api/unlock.js`가 대조해 `{ok}`를 주고 클라이언트는 localStorage `p80:unlocked`에 저장. 데이터 파일이 공개 경로라 뚫으려면 뚫리지만 990원 실험에 맞는 수준.
- **풀이 UX**: 선택 즉시 정답·오답 표시 + 해설(why·오답 선지 설명) + 관련 무료 강의 링크. 50문항 끝나면 /100 채점과 급수 구간.

## 홍이 할 일
1. 토스 송금 링크 만들기 → `VITE_PAY_URL`, 입금 확인 창구(오픈채팅·메일) → `VITE_CONTACT_URL`을 Vercel 환경 변수로 넣고 재배포(`vercel --prod`). 둘 다 비어 있으면 페이월에 "결제 링크 준비 중"으로 보인다.
2. 카페·블로그 글 — 판매글이 아니라 **"AI가 23회차 통계로 뽑은 80회 예상 주제"** 자료글 끝에 링크. 소재는 앱 레포 `data/predict/stats.json`.
3. 10/17 시험 뒤 실제 80회 문항 topic과 슬롯 대조 → 적중률을 이 페이지에 공개 → 81회(11/28) 판매 소재.

## 판정
입금 10건 넘으면 PG(토스페이먼츠) 붙인다. 10/17까지 0건이면 웹 판매는 접고 앱 IAP 유입용 무료 페이지로 돌린다.

## 2차 — 토스 미니앱 + 리디자인 (같은 날 밤)

홍: *"토스 미니앱으로도 출시할거라서 … 그거에 맞게 해줘 그리고 웹이 누가봐도 안살것 같은 디자인이라서"* + v0 Nexus 템플릿 링크.

- **디자인**: Nexus/Apex 풍으로 전면 교체 — 거의 검은 배경(#0a0a0b)·비네트, 상단 알약 내비, 녹색 점 배지(`제80회 대비 · D-16`), 두 줄 디스플레이 타이포(두 번째 줄 회색), 흰 알약 CTA + 윤곽선 보조 CTA, 신뢰 줄, 유리 카드 그리드(세트·특징 3개). Pretendard Variable(jsdelivr). 풀이·페이월도 같은 토큰. **토스 안에서는 `html[data-theme=light]`로 라이트 토큰**(검수 요건) — 레이아웃은 같고 색만 바뀐다.
- **토스**: `@apps-in-toss/web-framework` 3.7.0 + `apps-in-toss.config.ts`(appName `hangeom-predict`). 페이월이 토스 안이면 **IAP 단건 구매 버튼 하나**(sku `predict80_all`), 밖이면 송금 링크+코드. 풀이 화면 진입 시 `getPendingOrders`·`getCompletedOrRefundedOrders`로 복원. 토스 안에서는 App Store 링크·상단 내비를 숨긴다(검수: 자체 홍보·설치 링크 금지, 내비바는 토스 것). `npx ait build` → `hangeom-predict.ait` 생성 확인. 상세·지뢰: [앱인토스 미니앱](../../../%EC%9E%91%EC%97%85%EB%85%B8%ED%8A%B8/%EB%8F%84%EA%B5%AC/%EC%95%B1%EC%9D%B8%ED%86%A0%EC%8A%A4%20%EB%AF%B8%EB%8B%88%EC%95%B1.md).
- **OG 이미지** `public/og.png`(1200×630, PIL 생성)로 카페·블로그 링크 미리보기가 다크 카드로 뜬다.
- 검증: Playwright 크로미움 헤드리스로 홈(모바일·데스크톱·라이트)·풀이·페이월 5컷 확인, 빌드·배포 완료. https://hangeom-predict.vercel.app

### 홍이 할 일 (토스)
1. 앱인토스 콘솔에서 미니앱 등록 — 이름 `hangeom-predict`(한글 표시명은 콘솔에서), 로고 600×600, 사업자 정보 → 정산 정보(검토 2~3영업일).
2. 인앱 상품 등록 — 비소모성, sku **`predict80_all`**, 공급가 **900원**(판매가 990), 이미지 1024×1024.
3. `npx ait token add` 뒤 `npx ait deploy`(또는 콘솔에 `hangeom-predict.ait` 업로드) → 샌드박스 앱에서 `intoss://hangeom-predict`로 구매·복원 테스트 → 검수 요청(2~3영업일).

## 3차 — 가격 플랜 2단계 (2026-10-02)

홍: *"5개 전체를 990원으로 하면 너무 싼가?"* → 싸다고 판정(앱 ₩6,600 앵커와 충돌, AI 덤핑 인상, 990은 지불 의사를 못 잼) → 홍 *"괜찮네"*로 확정.

| 상품 | 가격 | 토스 SKU | 공급가 |
|---|---|---|---|
| 1회분(수준·회차 선택, 50문항 + 해설) | **990원** | `predict80_one` · 소모성 | 900 |
| 전체 10벌 500문항 + 해설 | **2,900원** | `predict80_all` · 비소모성 | 2,636 |

- 잠금 상태가 `all` 또는 `['심화:2', …]` 목록으로 바뀌었다(`src/storage.ts`). 1회분은 소모성이라 기기 간 복원이 안 되고, 결제 뒤 지급 실패만 `p80:pending-one`에 둔 회차로 복원한다. 전체는 비소모성 복원.
- 웹 경로: 송금 링크는 `VITE_PAY_URL`(toss.me 기본 주소) 뒤에 금액을 붙여 두 버튼. 코드는 `UNLOCK_CODES`(전체)와 `UNLOCK_CODES_ONE`(1회분, 로컬 `unlock-codes-one.local.txt`)로 나뉘고 API가 `scope`를 돌려준다. 둘 다 실배포에서 확인.
- 10/17 적중률 공개 뒤 전체를 3,900원으로 올리는 안을 열어 뒀다.
- **토스 콘솔 MCP**: 공식 플러그인 `toss/apps-in-toss-harness`(스킬 9종 + MCP 2개, 콘솔 MCP는 OAuth)가 있어 미니앱 등록·상품 등록을 AI가 할 수 있다. 홍이 새 세션에서 `claude plugin marketplace add toss/apps-in-toss-harness` → `claude plugin install ait@apps-in-toss` → `/mcp` 로그인. `.ait` 재생성됨(deploymentId `01a0f848-…`).
