# 논문표

## 현재 카드
- **단계**: 7일 MVP
- **현재**: 2026-09-26 배포(https://nonmunpyo.vercel.app, 베타 무료). 8종 분석 값이 scipy·statsmodels 정답지와 일치하고 단위 테스트 270개·배포본 e2e 3개가 통과한다. 실사용자·결제 0
- **다음 판정**: 2026-10-10 — 실제 대학원생이 **자기 설문 파일로** 끝까지 써서 워드를 받은 사람이 10명 중 몇 명인가. 3명 미만이면 결제를 붙이기 전에 문제 정의·채널부터 다시 본다
- **지금 할 일**: 첫 사용자 10명에게 링크 전달 — 논문 통계 대행을 산 적 있는 대학원생과 대학원 커뮤니티
- **하지 않을 일**: 사용자 반응 전 분석 종류 추가(요인분석·매개효과 등)

## 무엇

설문 엑셀(xlsx·xls·csv)을 올리면 **한국 학위논문 양식의 통계표와 해석문**이 나오고, 워드(.docx)로 내려받아 한글(HWP)에서 바로 연다. 대상은 SPSS가 어려운 대학원생이다. 모든 계산은 브라우저 안에서만 하고 파일은 서버로 가지 않는다(서버 코드 자체가 없다 — 정적 빌드).

- 분석 8종: 빈도(일반적 특성) · 기술통계 · 신뢰도(Cronbach's α) · 상관 · 독립표본 t검정 · 일원배치 분산분석과 Scheffé 사후검정 · 다중회귀 · 교차분석(χ²)
- 척도 만들기: 문항 평균, 역문항 역코딩, 같은 접두어 문항 묶음 제안(JS1~JS5 등)
- 출력: 논문식 표(가로선 3개·세로선 없음·캡션 위), 조사까지 맞춘 한국어 해석문, 워드 전체 다운로드, 표별 복사(한글·워드 붙여넣기)

## 왜 이것

2026-09-23~26 제품 후보를 세 라운드와 재심사로 22개 봤는데, 조사 단계에서 전부 탈락했다. 탈락 기준이 "같은 고객군을 무료·저가로 덮는 제품이 있으면 죽인다"였고, 그 기준은 성공한 제품 대부분도 죽인다. 조사를 끊고, **사람이 이미 돈을 내고 있는 게 확인된 일**을 골랐다 — 크몽 논문 통계 대행이 건당 3만~7만원, 한 판매자 거래 1,074건(리뷰 497). 무료 대체재(스탯지니, StatMate, JASP)가 있다는 것은 감수했다.

## 검증

- **정답지**: `scripts/gen_reference.py`가 시드 고정 가상 설문(n=200, 역문항·결측·CP949 CSV 포함)을 만들고 scipy·statsmodels·pingouin으로 참조값을 뽑는다. 테스트가 8종 결과의 **모든 필드**를 비교한다(통계량 상대 1e-9, p값 상대 1e-6).
- **e2e**(Playwright): 예시 데이터 → 척도 3개 → 분석 8종 → 워드 다운로드, 모바일 390px 가로 넘침 없음, **외부 출처 요청 0건**. `E2E_BASE_URL=https://nonmunpyo.vercel.app npx playwright test`로 배포본에도 돈다(2026-09-26 통과).
- 적대적 검토 3명(통계 감사·논문 편집자·UX)이 경계 사례와 문장 사실성을 고쳤다.
