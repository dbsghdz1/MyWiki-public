# 아카이빙

학습 영역에서 **더 이상 활성이 아닌 노트**를 옮겨 두는 곳이다 — 끝난 학습 계획, 방향이 바뀌어 안 쓰는 정리, `status: stale`로 오래 남은 주제. 삭제하지 않고 여기로 옮겨 `학습/공부/`·`학습/야생학습/`을 가볍게 유지한다.

## 규칙

- 옮길 때 원래 있던 허브(공부 README 주제 목록 등)에서 목록 항목을 지우고, 아래 목록에 `- [[<파일>]] — 왜 아카이빙했는지 (날짜)` 로 등재한다.
- 옮긴 파일을 가리키던 다른 문서의 링크는 새 경로로 갱신한다.
- 다시 활성화되면 원래 영역으로 되돌리고 여기 목록에서 지운다.
