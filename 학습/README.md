## 야생학습 발동 규칙 (2026-08-30 도입)

**에이전트가 타이밍을 잡아 제안한다.** 작업 중 다음 신호가 보이면 "이건 야생학습으로 하자"고 홍에게 알린다:

- 같은 개념에 **반복해서 막힘** (예: 08-21 진단 — 구조 분해·truthy/falsy에서 4일 소모)
- 설명을 들어도 흐릿할 개념인데 **예측→실행 실험으로 10~30분이면 확인 가능한 것**
- 실험 한 번이면 논쟁이 끝나는 질문 ("이거 되나?" → 만들어보면 됨)

근거: [[학습/공부/README|공부]]의 08-21 결정 — "방법은 강의·책이 아니라 손이다". 진행하면 기록은 `학습/야생학습/`에 남기고, 승격할 개념 정리는 `학습/공부/`로 보낸다.

Matt Pocock의 `/teach`(mattpocock-skills 플러그인)를 이 폴더 구조에 맞게 개조한 사용자 호출 스킬 — `(로컬 경로)`. 새 폴더 없이 기존 파일을 워크스페이스로 쓴다: **미션**은 주제 노트 `## 학습 계획` 첫 줄 `**미션:**`, **증명된 이해**만 `## 기록`, 실험은 `야생학습/`, 막힌 것은 `## 막힌 것`. 원칙은 미션 우선·근접발달영역·저장 강도(인출·간격) > 유창성·한 블록·에러가 교보재. 조사 기록: [[작업노트/도구/Claude Code 설정과 훅|Claude Code 설정과 훅]] 09-05 항목.

## 규칙

- 각 하위 영역의 세부 규칙은 그 영역 README가 원본이다. 이 파일은 목록과 경계만 유지한다.
- `학습/` 전체가 **공개 영역**이다 (publish.allow의 `공부`를 `학습`으로 교체, 2026-08-30). 비공개로 남길 내용은 여기에 쓰지 않는다.
- 옛 경로 `공부/<분야>/<주제>.md`는 전부 `학습/공부/<분야>/<주제>.md`가 됐다. 루틴·프롬프트 사본에 옛 경로가 남아 있으면 **위키가 우선**이다.
