# 약국맵 사다리 3-A — Fastify 프록시 (2026-09-09)

**결론 한 줄**: 번들에서 `serviceKey=x7MTtJX86eeW…`가 나오는 것을 **먼저 측정하고** 프록시를 붙였다 — 끝나고 같은 명령이 **0**을 냈다. 키가 브라우저로 내려가지 않는다.

**몰입 판정**: **에너지 7 / 몰입.** 세션 1·2가 둘 다 5에 불안 쪽이었는데 처음 올라왔다. 이유로 짚이는 것 — ① 오늘은 **에러가 네 번 났는데 전부 1~2줄짜리**였다(오타·순서·`/` 누락·`.env` 누락). 막힘의 크기가 작아 매번 바로 다음 칸으로 갔다 ② **측정이 시작과 끝에 한 번씩** 있어서(`grep` 1 → 0) 진척이 숫자로 보였다.

## 계기

[[학습/야생학습/약국맵 사다리 2 — useEffect와 useQuery 2026-09-09|세션 2]]에서 미룬 칸. 사다리에서 가장 큰 계단(새 개념 3개, 서버가 처음 등장)이라 **3-A/3-B/3-C로 쪼갰고, 오늘은 3-A(프록시)만** 했다. 새 개념은 2개로 줄였다 — ① 브라우저가 아닌 곳(Node)에서 도는 내 코드 ② 프록시.

## 예측 vs 실제

| # | 예측 질문 | 홍의 예측 | 실제 | |
|---|---|---|---|---|
| 1 | 지금 빌드하면 번들에 서비스키가 나올까 | **나올 것 같다** (개발자 도구에서 본 기억) | `serviceKey=x7MTtJX86eeW` **나온다** | **적중** |
| 2 | 프록시 후 Network 탭에 `apis.data.go.kr`이 보일까 | **안 보인다** — 프록시가 대신 다녀오니까 | 안 보인다 | **적중** |
| 3 | `fetch("/api/pharmacies")`는 몇 번 포트로 갈까 | **3000번** | **5173으로 간다.** 브라우저는 3000을 모른다 — Vite가 받아서 3000으로 전달 | **절반** |
| 4 | `node server/main.js`를 실행하면 프롬프트가 돌아올까 | **안 돌아온다, 계속 듣고 있어야 하니까** | 그대로 | **적중** |

3번이 오늘의 핵심 오해였다. **Network 탭은 「브라우저가 보낸 것」만 보여준다** — 그 뒤 서버끼리 주고받는 건 브라우저 밖의 일이라 안 보인다. 키가 안 보이는 이유도 숨겨서가 아니라 **애초에 브라우저를 지나가지 않아서**다.

## 해본 것

```
브라우저 ──① /api/pharmacies──> localhost:5173 (Vite)
                                     └──② /api──> localhost:3000 (Fastify) ──③ 키를 들고──> apis.data.go.kr
```

- `server/main.js` — Fastify 인스턴스 하나, `/api/health`와 `/api/pharmacies` 두 라우트, 맨 아래 `await app.listen({ port: 3000 })`
- 키는 `process.env.DATA_GO_KR_KEY`로 읽고 **`node --env-file=.env.local`**로 실행 (Node 20.6+ 내장 옵션, dotenv 불필요)
- `vite.config.ts`에 `server.proxy = { "/api": "http://localhost:3000" }`
- `App.tsx`는 상대 경로 `fetch("/api/pharmacies")` — 브라우저 입장에선 **동일 출처**라 CORS 얘기가 아예 안 나온다
- `.env.local`에서 `VITE_DATA_GO_KR_KEY` 줄을 **삭제**

## 오늘의 에러 넷 — 전부 다른 종류였다

| 에러 | 원인 | 언제 잡혔나 |
|---|---|---|
| `SyntaxError: Unexpected token '{'` | `async () = {` — 화살표의 `>` 누락 | **파일을 읽다가.** 실행조차 안 됨 |
| `FST_ERR_INSTANCE_ALREADY_LISTENING` | `app.get`을 `await app.listen` **아래**에 씀 | 실행 중 (순서 위반) |
| `ERR_ASSERTION: 첫 글자는 / 나 *` | `app.get("api/pharmacies")` — `/` 누락 | 실행 중 (값 위반) |
| `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | `.env.local`에 `DATA_GO_KR_KEY` 줄이 없어 `undefined`가 전송됨 | **원격 서버가** |

**구문 에러는 원인보다 뒤에서 터진다.** `() = {`를 파서는 "대입인가 보다" 하고 넘어갔다가, 다음 줄 `return`에서야 멈췄다 — 그래서 **에러가 가리킨 줄(6)이 아니라 그 위(5)가 범인**이었다. 런타임 에러는 반대로 가리킨 자리가 대체로 범인이다.

그리고 마지막 것 — **에러 메시지는 「내가 보낸 값」에 대한 판정이지 「내 파일 상태」를 모른다.** 서버는 *"등록되지 않은 서비스키"*라고 했지만 실제로 보낸 값은 `undefined`였다. 이 메시지를 곧이곧대로 읽으면 키를 다시 발급받으러 가게 된다. 그래서 `console.log("KEY 길이:", KEY?.length)` 한 줄을 진단용으로 남겼다 — 96이면 정상, `undefined`면 파일 문제.

## 덤으로 잡힌 것

- **`numbersOfRows` → `numOfRows`.** 09-08에 이미 *"모르는 파라미터는 조용히 무시된다"*고 [[작업노트/도구/공공데이터포털 오픈API|기록]]해 놓고도 코드에는 오타가 남아 있었다. 고치니 정확히 3개가 온다 (`grep -o '"dutyName"' | wc -l` → 3)
- **`p` 암시적 any (TS7006).** `r.json()`은 `any`라서 `.map((p) => …)`의 `p`가 뭔지 TS가 모른다. `const pharmacies: Pharmacy[] = …`로 **경계에서 타입을 선언**해 해결

## 세션 끝 인출 퀴즈 — 5문항 중 3

| # | 질문 | 결과 |
|---|---|---|
| 1 | 키가 번들에 안 실리게 된 진짜 이유 | ⚠️ `import.meta.env` 쪽은 정확, **`process.env` 쪽은 모름** |
| 2 | Network에 API가 안 보이는 이유 | ✅ "프록시가 대신 다녀와서" — 정확 |
| 3 | 왜 `listen` 아래에 라우트를 못 붙이나 | ✅ |
| 4 | `useEffect`의 `[]`가 뜻하는 것 | ❌ **이틀째 못 답함** ("의존성이었던 것 같은데") |
| 5 | `staleTime`이 새로고침을 못 막는 이유 | ⚠️ "브라우저 안에 있어서" — **메모리**까지는 못 감 |

**1번의 못 간 자리**: 이유가 두 겹이다. ① `process.env`는 치환이 아니라 **실행 중에 읽는다** ② 더 중요한 것 — **`server/main.js`는 애초에 브라우저로 전송되지 않는다.** 번들에 안 실리는 게 아니라 **코드가 사는 세계가 다르다.**

**5번**: 캐시는 **메모리(실행 중인 JS 변수)**에 산다. `localStorage`처럼 디스크가 아니라서 새로고침하면 JS가 통째로 새로 시작하며 캐시도 사라진다.

**다음 세션 시작 5분은 4번(의존성 배열)에 쓴다** — 어제 "다시 볼 것"으로 적어놓고 안 봐서 그대로 남았다. 설명만 들은 것은 안 남는다는 표본이 이틀 연속 나왔다.
