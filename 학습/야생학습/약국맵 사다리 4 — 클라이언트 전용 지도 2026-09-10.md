# 약국맵 사다리 4 — 클라이언트 전용 지도 (2026-09-10)

**결론 한 줄**: 서버는 지도 영역(`<div id="map">`)만 HTML로 준비하고, 브라우저의 `useEffect`에서 카카오 지도 SDK를 불러온 뒤 지도 인스턴스를 만들었다. Node에서 `window`를 읽으면 `ReferenceError: window is not defined`가 나지만, 브라우저에서는 `window.innerWidth`와 지도가 정상 동작했다.

## 오늘 한 것

- `node -e "console.log(window.innerWidth)"`로 서버(Node)에 `window`가 없다는 에러를 먼저 재현했다.
- `useEffect`는 서버 렌더링에서는 실행되지 않고 브라우저에서만 실행된다는 것을 확인했다.
- 카카오 JavaScript SDK 도메인에 `http://localhost:3000`을 등록하고 `.env.local`에 `VITE_KAKAO_MAP_KEY`를 넣었다.
- `document.createElement("script")`와 `appendChild`로 SDK를 동적으로 로드했다.
- `script.onload` 뒤 `kakao.maps.load` 콜백에서 `new kakao.maps.Map(...)`을 실행했다.
- 서버가 보낸 지도 자리와 브라우저가 그 자리에 생성한 지도 인스턴스의 역할을 구분했다.
- HTML만 남기고 JavaScript를 끄면 약국 목록은 보이고 지도는 보이지 않는다는 것도 확인했다.

## 예측 vs 실제

| 질문 | 예측/답 | 실제 |
|---|---|---|
| Node에서 `window.innerWidth` | 브라우저 너비가 나올 것 | `window is not defined` |
| `useEffect` 실행 환경 | 브라우저 | 적중. 서버 렌더링에서는 실행되지 않음 |
| JavaScript를 끄면 | 목록은 보이고 지도는 안 보임 | 적중 |

## 막힌 자리와 해결

- 서버 응답에서 `<body>`와 지도 `<div>`를 잘못 이어 써 지도가 왼쪽 위에 이상하게 보였다. `<body><div id="map" ...>`으로 고쳤다.
- 지도 중심 좌표의 위도 오타도 수정했다(`37.4784`).
- SDK 다운로드 완료(`script.onload`)와 지도 기능 준비 완료(`kakao.maps.load`)를 구분했다.

## 오늘의 이해

`<div id="map">`은 서버가 지도가 들어갈 빈 자리를 만드는 HTML이고, `new kakao.maps.Map(...)`은 브라우저에서 그 자리를 실제 지도 객체로 채우는 코드다. `useEffect` 안에 브라우저 전용 코드를 두는 이유는 Node 서버에는 `window`와 `document`가 없기 때문이다.
