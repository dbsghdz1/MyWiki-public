**[roadmap.sh HTML 로드맵](https://roadmap.sh/html)을 끝까지 판다** (2026-09-26 홍 결정). 로드맵은 토픽 16개·서브토픽 73개이고, 이를 세션 H1~H11과 연습 프로젝트 P1~P6으로 묶었다. 순서는 로드맵의 등뼈 순서 그대로다.

- **자리**: **2026-09-26(토) 하루에 H3~H11과 P1~P6을 전부 본다** (홍 결정). 세션을 순서대로 잇고, 프로젝트는 세션이 끝난 뒤 이어서 한다.
- **세션 하나**: 레슨(roadmap.sh [HTML pack](https://roadmap.sh/packs/html)이 있으면 그것, 없으면 MDN) → Elements 탭에서 직접 확인 → **말로 뱉기 질문**에 답한다. 답이 `## 기록`이 된다.
- **밀리면** 날짜를 다시 붙이지 않고 다음 미체크부터 간다.

### CSS 로드맵 세션

> [!NOTE]
> 2026-10-02 — **C1~C14 완료.** 기록은 [CSS 기초](CSS%20%EA%B8%B0%EC%B4%88.md). C12·C14는 홍 요청으로 에이전트가 작성. 다음 묶음은 미정 — 일간 루틴은 이 파일에 미체크가 없으면 밤 블록에 넣지 않는다.

**[roadmap.sh CSS 로드맵](https://roadmap.sh/css)을 「밀과 오븐」 페이지를 꾸미면서 판다** (2026-10-01 홍 결정 — "만들면서 배워보자"). 로드맵은 주제 33개·하위 71개이고, 로드맵 순서를 지키되 **빵집 페이지에 바로 쓸 수 있는 순서**로 C1~C14에 묶었다.

- **작업물**: `(로컬 경로)`에 `style.css`를 만들어 HTML 미션 결과물에 입힌다. 목표 모양은 Figma 「동네 빵집 소개 — HTML 미션」 프레임(MyCryptoDiary 파일 node `503-467`). **C13이 끝나면 Figma와 거의 같은 페이지 + 모바일 1단 레이아웃**.
- **세션 하나**: MDN 레슨 → **빵집에 적용할 한 가지**를 먼저 예측(「이렇게 쓰면 이렇게 보일 것」) → 적용 → DevTools Styles·Computed 탭으로 확인 → **말로 뱉기**. HTML 때처럼 **단계마다 검증받는다**.
- **HTML은 건드리지 않는 게 원칙** — 꾸미려고 태그를 바꾸고 싶어지면 그 이유를 먼저 말한다(대개 CSS로 된다).
- **밀리면** 날짜를 다시 붙이지 않고 다음 미체크부터.
