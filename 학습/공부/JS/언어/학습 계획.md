# JS/언어 학습 계획

`JS/언어` 폴더의 **세션 체크리스트**다. 이해한 것은 주제 노트에, 여기는 「언제 무엇을 보나」만 둔다. 슬롯·시각의 정본은 [[학습/공부/학습 계획|공부 학습 계획]]이고, 일간 루틴은 밤 블록에 이 파일 `### HTML 로드맵 세션`의 다음 미체크를 넣는다.

## 학습 계획

**[roadmap.sh HTML 로드맵](https://roadmap.sh/html)을 끝까지 판다** (2026-09-26 홍 결정). 로드맵은 토픽 16개·서브토픽 73개이고, 이를 세션 H1~H11과 연습 프로젝트 P1~P6으로 묶었다. 순서는 로드맵의 등뼈 순서 그대로다.

- **자리**: 밤 블록(20:00~23:00) 앞자리. 한 밤 = 뽀모도로 3개 = **세션 2개 + 프로젝트 1개**.
- **세션 하나**: 레슨(roadmap.sh [HTML pack](https://roadmap.sh/packs/html)이 있으면 그것, 없으면 MDN) → Elements 탭에서 직접 확인 → **말로 뱉기 질문**에 답한다. 답이 `## 기록`이 된다.
- **밀리면** 날짜를 다시 붙이지 않고 다음 미체크부터 간다.

### HTML 로드맵 세션

- [x] **H1** (09-26 완료): Introduction(마크업 언어·프론트엔드) · How the web works(HTTP·도메인·호스팅·DNS·브라우저·SEO) — pack 1강. 기록: [[학습/공부/JS/언어/브라우저 렌더링과 DOM|브라우저 렌더링과 DOM]], 웹 동작은 [[학습/공부/CS/네트워크/DNS 조회 과정|DNS 조회 과정]]·[[학습/공부/CS/네트워크/HTTP와 TCP-IP의 역할|HTTP와 TCP-IP의 역할]]에 이미 있다
- [x] **H2** (09-26 완료, 빈칸 둘): Your First HTML File(태그·속성·엔티티·주석) · Basic Tags(doctype·html·head·body·meta·title) — pack 2강. 기록: [[학습/공부/JS/언어/HTML 문서 구조|HTML 문서 구조]]. **남은 빈칸 = 대소문자 무시·공백 처리 → H3 앞 5분**
- [ ] **H3** (09-26 토 ①): H2 빈칸([공백 처리](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Text/Whitespace)) → Textual Tags(`h1`~`h6`·`p`·`br`·`hr`·`pre`·`mark`·`sub`·`sup`·`b`/`strong`·`i`/`em`) · 변경 표시(`del`·`s`·`ins`) · 인용(`abbr`·`cite`·`dfn`·`address`·`blockquote`·`q`) — pack 3강, MDN [Headings and paragraphs](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Headings_and_paragraphs) · [Emphasis and importance](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Emphasis_and_importance) · [Advanced text features](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Advanced_text_features)
  - 말로 뱉기: `<b>`와 `<strong>`은 화면에서 똑같이 굵은데 왜 둘 다 있나? 스크린 리더에겐 뭐가 다른가?
- [ ] **H4** (09-26 토 ②): Grouping text(`div`·`span`) · Standard attributes(`id`·`class`·`data-*`·`style`) · Lists(`ol`·`ul`·`dl`·중첩) — pack 3·8강, MDN [Lists](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Lists) · [Use data attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/How_to/Use_data_attributes)
  - 말로 뱉기: `div`와 `span`의 차이를 「블록·인라인」이라는 말 없이 설명하면?
- [ ] **H5** (09-29 화 ①): Links(URL·프래그먼트·새 탭·링크 텍스트) · Images(`alt`·`img` vs `figure`) · Priority Hints(`fetchpriority`) — pack 4·5강, MDN [Creating links](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Creating_links) · [HTML images](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/HTML_images), web.dev [Fetch Priority](https://web.dev/articles/fetch-priority)
  - 말로 뱉기: `alt=""`(빈 값)과 `alt` 생략은 뭐가 다른가? [[학습/공부/CS/네트워크/절대 URL과 상대 URL|절대 URL과 상대 URL]]과 이어서
- [ ] **H6** (09-29 화 ②): Table Tag(행·셀·`caption`·`scope`) — pack 6강, MDN [HTML table basics](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/HTML_table_basics)
  - 말로 뱉기: 표로 레이아웃을 짜면 왜 안 되나? `scope`가 없으면 스크린 리더가 뭘 못 하나?
- [ ] **H7** (09-30 수 ①): Embedding Media(`audio`·`video`·`iframe`) · CSP — pack 5강, MDN [Video and audio](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/HTML_video_and_audio) · [Embedding technologies](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/General_embedding_technologies) · [CSP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP)
  - 말로 뱉기: 남의 페이지를 `iframe`으로 넣을 때 막는 쪽은 누구고, 무엇으로 막나?
- [ ] **H8** (09-30 수 ②): Using Forms(`label`·`input`·GET vs POST·파일 업로드·검증·한계) — pack 7강, MDN [Your first form](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Your_first_form) · [Form validation](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Form_validation) · [input type=file](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/file)
  - 말로 뱉기: 브라우저 검증(`required`)이 있는데 서버에서 또 검증해야 하는 이유는?
- [ ] **H9** (10-01 목 ①): Semantic Markup(`header`·`nav`·`main`·`section`·`article`·`aside`·`footer`) — pack 8강, MDN [Structuring documents](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Structuring_documents)
  - 말로 뱉기: `section`과 `article`은 어떻게 고르나? 전부 `div`로 써도 화면은 같은데 뭐가 깨지나?
- [ ] **H10** (10-01 목 ②): Styling Basics(인라인·내부·외부 CSS) · Including JavaScript(`script`·`defer`·`async`) — MDN [CSS getting started](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Getting_started) · [script](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/script)
  - 말로 뱉기: `defer`와 `async`의 실행 시점 차이를 [[학습/공부/JS/언어/브라우저 렌더링과 DOM|파싱 과정]] 위에 그려 보면?
- [ ] **H11** (10-02 금 ①): Accessibility · Basics of SEO — MDN [HTML: A good basis for accessibility](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Accessibility/HTML), Google [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) → **로드맵 종료**
  - 말로 뱉기: H3~H10에서 「화면은 같은데 의미가 다른」 태그 쌍을 셋 꼽고, 누가 그 차이를 읽는지 말하면? [[학습/공부/JS/React/렌더링 방식과 SEO|렌더링 방식과 SEO]]와 이어서
