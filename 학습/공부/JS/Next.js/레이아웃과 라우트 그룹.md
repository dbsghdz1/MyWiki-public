# 레이아웃과 라우트 그룹

`layout.tsx`는 같은 폴더와 그 아래의 화면을 `children`으로 받아 감싸는 파일이다. 어느 화면에 씌울지는 코드로 적지 않고 화면 파일이 놓인 위치로 정해진다.

## 핵심 정리

- Next는 화면(`page.tsx`)을 보여줄 때 그 파일이 있는 폴더에서 위로 올라가며 `layout.tsx`를 전부 찾아 씌운다. 화면을 `children` 자리에 넣는 것은 Next가 한다
- **괄호 폴더 `(이름)`은 주소에 나오지 않는다.** `app/(shell)/page.tsx`의 주소는 `/`다. 화면을 묶어서 같은 레이아웃을 씌우는 용도로만 쓴다
- 그래서 「틀을 쓰는 화면」은 `(shell)` 안에, 틀이 없어야 하는 로그인은 밖에 둔다
- **생김새와 적용 범위를 나눈다.** 틀이 어떻게 생겼는지는 `src/widgets/app-shell`의 `AppShell`이 갖고, 어느 화면에 씌울지는 `app/(shell)/layout.tsx`가 정한다. 레이아웃은 `AppShell`을 불러 `children`을 넣는 한 줄만 한다. 이 저장소가 `app/`을 주소 연결 전용으로 쓰기로 했기 때문이다([Feature-Sliced Design](../React/Feature-Sliced%20Design.md))

```
app/
  layout.tsx          모든 화면 (html, body)
  (shell)/
    layout.tsx        이 폴더 안 화면만 AppShell로 감쌈
    page.tsx          거래소, 주소는 /
  sign-in/            그룹 밖이라 틀 없음 (예정)
```

## 기록

### 2026-11-18: 틀 코드를 레이아웃으로 옮기는 것인가, 레이아웃이 틀을 불러 쓰는 것인가
- 궁금했던 것: [MyCryptoDiary](../../../../%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/%EA%B0%9C%EC%9D%B8/MyCryptoDiary/README.md)에서 `app/page.tsx`가 `AppShell`을 직접 감싸고 있었고, code-review가 「`page.tsx`는 `_pages`로 넘기는 한 줄만」 규칙과 다르다고 지적했다. 그래서 `app/(shell)/layout.tsx`를 만들게 됐다
- 예측: 처음에는 왜 만드는지를 놓쳐 빈 함수만 썼다. 설명을 들은 뒤에는 「`AppShell` 코드는 특정 화면을 빼면 다 쓰니까 layout으로 빼자, 그러니 `AppShell`을 지우고 그 코드를 layout에 넣는 것」으로 이해해 박스들을 통째로 복사했다. 화면은 똑같이 나오지만 이 저장소의 방식은 아니었다
- 알게 된 것:
  - 화면이 하나일 때는 페이지가 직접 틀을 씌워도 문제가 없다. 화면이 다섯 개가 되면 같은 포장을 네 번 쓰게 되고 로그인만 빼기도 어렵다. 레이아웃은 그 포장을 한 번만 적는 곳이다
  - 틀 코드를 레이아웃에 옮겨도 동작은 같다. 다만 틀은 앞으로 링크, 아이콘, 모바일 동작으로 계속 커지므로 생김새는 widget에 두고 레이아웃은 불러 쓰기만 한다. 「`ShellLayout`이 `AppShell` 컴포넌트를 불러서 쓴다」로 정리했다
  - 어느 화면에 쓸지는 「파일을 `(shell)` 폴더에 넣느냐」로 정해진다. 따로 적는 곳이 없다
- 근거: MyCryptoDiary `228ee17`(`app/(shell)/layout.tsx`)

### 2026-11-18: 페이지를 그룹 안으로 옮겼더니 틀이 두 번 보였다
- 궁금했던 것: `app/page.tsx`를 내용은 그대로 둔 채 `app/(shell)/`로 옮기기만 했다
- 예측: 화면을 보고 「두 군데가 보여, 당연한 것 같아. page에서 `AppShell`을 부르고 layout에도 `AppShell`을 불러서 그런 거지?」라고 했다. 맞았다
- 알게 된 것:
  - 레이아웃이 씌운 틀의 본문 자리에 페이지가 들어가는데, 그 페이지가 틀을 또 씌우면 틀 안에 틀이 생긴다
  - 레이아웃이 틀을 맡으면 페이지는 틀을 몰라도 된다. 페이지에서 `AppShell`을 빼고 `ExchangePage`만 그리게 고쳤다
- 근거: MyCryptoDiary `40a5f55`. `/` 응답에서 `aside`가 한 번만 나오는 것으로 확인
- 새로 생긴 궁금증: `page.tsx`를 `export { ExchangePage as default } from` 한 줄로 줄이는 것은 아직 하지 않았다. [JavaScript 모듈 시스템](../%EC%96%B8%EC%96%B4/JavaScript%20%EB%AA%A8%EB%93%88%20%EC%8B%9C%EC%8A%A4%ED%85%9C.md)

## 더 알아보면 좋은 것

- 화면을 이동해도 레이아웃은 다시 그려지지 않는다고 한다. 메뉴 이동을 붙일 때 직접 확인한다
- 계정이 필요한 화면(대시보드, 내 자산)만 막는 것을 레이아웃에서 할지 화면에서 할지는 로그인 작업에서 정한다. [proxy 미들웨어와 matcher](proxy%20%EB%AF%B8%EB%93%A4%EC%9B%A8%EC%96%B4%EC%99%80%20matcher.md)
