### 영상 세션 — 화~금 **13:00~13:55 (55분)**, 영상 약 30분

**강 번호는 첫 세션에서 채운다.** 섹션 4 운영체제가 끝나는 강 번호 다음부터이고, 강의 목록을 열어 확인하기 전에는 적지 않는다.

- [ ] **D1** (10-22 목): 섹션 5 시작 — 강의 목록에서 **강 번호·각 강 길이를 이 목록에 채우는 것부터.** 그다음 DB 기초·트랜잭션 ACID
- [ ] **D2** (10-23 금): 무결성·정규화
- [ ] **D3** (10-27 화): 인덱스 — B+Tree, 인덱스가 안 타는 경우
- [ ] **D4** (10-28 수): 조인 전략·실행 계획
- [ ] **D5** (10-29 목): 격리 수준과 이상 현상(dirty·non-repeatable·phantom read)
- [ ] **D6** (10-30 금): 락·MVCC
- [ ] **D7** (11-03 화): 복제·파티셔닝·샤딩 개론
- [ ] **D8** (11-04 수): 섹션 5 종료 + `## 핵심 정리` 작성 → **1획독(네트워크·OS·DB) 완료.** 소마 DB 쿼리 하나를 `EXPLAIN`으로 읽고 `## 기록`에 한 줄

### 영어 원문 세션 — 토 **13:00~14:15** (10-31 · 11-07 · 11-14)

방식은 **에이전트가 한국어 요약을 먼저 주고 홍이 원문에서 근거 문장을 찾는 것**이다 (2026-09-17 변경, 정본은 [[학습/공부/학습 계획|공부 학습 계획]]).

- [ ] **10-31 토**: Use The Index, Luke «Anatomy of an SQL Index» — https://use-the-index-luke.com/sql/anatomy → «The Where Clause» — https://use-the-index-luke.com/sql/where-clause
  - D3(10-27)에서 들은 B+Tree를 영어 원문으로. 첫 장은 인덱스를 **리프 노드(이중 연결 리스트) + B-Tree 두 구조**로 설명하고, 둘째 장이 **왜 인덱스를 못 타는가**(함수·바인드 변수·범위 검색·NULL·난독화된 조건)다 — 소마 쿼리에 그대로 걸리는 목록이다
- [ ] **11-07 토**: PostgreSQL Docs «Transaction Isolation» — https://www.postgresql.org/docs/current/transaction-iso.html
  - D5(10-29)의 격리 수준 4단계와 이상 현상 표를 **공식 문서 표현으로** 다시 쓰고, 강의와 어긋나는 점이 있으면 명시한다. 원문 한 문장 인용
- [ ] **11-14 토 — 면접 대비 인출 세션** (새 자료 없음): 1획독 전체(네트워크·OS·DB)를 **말로 뱉는다.** 에이전트가 섹션별로 묻고 못 답한 것이 11-15·16 복습 재료가 된다. **2026-11-17 지원 개시 3일 전이다**
