# 운영체제 학습 계획

[[학습/공부/CS/운영체제/운영체제|운영체제]] 폴더의 **세션 체크리스트**다. 슬롯·요일·주차 표의 정본은 [[학습/공부/학습 계획|공부 학습 계획]], 세션 구조·운영 규칙은 [[학습/공부/CS/네트워크/학습 계획|네트워크 학습 계획]]이 정본이다. 일간 루틴은 이 파일의 `### 영상 세션`·`### 영어 원문 학습 세션`에서 다음 미체크 항목을 뽑는다. (2026-09-16 [[학습/공부/CS/운영체제/운영체제|운영체제]]에서 분리)

## 학습 계획

**2026-09-13 재편 — 주 교재를 강의로 바꿨다.** 9·10월 1획독 목표에 따라 이 파일의 10월 자리는 인프런 [CS 지식의 정석](https://www.inflearn.com/course/%EA%B0%9C%EB%B0%9C%EC%9E%90-%EB%A9%B4%EC%A0%91-cs-%ED%8A%B9%EA%B0%95) **섹션 4 운영체제(190분)**를 **7 영상세션**(세션당 약 27분)에 배분한다. 세션 구조·시각·운영 규칙은 [[학습/공부/CS/네트워크/네트워크|네트워크]] `## 학습 계획`이 정본이다 — 아침 블록 첫 자리 45분, 화~금 영상 + 토요일 영어 원문 학습.

> [!important] 2026-09-13 — 아래 OSTEP W4~W11 계획은 **1획독 이후로 미뤘다** (폐기 아님)
> 이 파일에는 8월에 짠 OSTEP 8세션 계획이 10-27까지 미체크로 깔려 있었고, 이제 같은 자리에 강의 1획독이 들어온다. **두 축을 같은 슬롯에 겹쳐 두면 또 0이 된다** — 08-21 이후 CS 실행이 0회였던 것이 그 모양이었다(네트워크 파일 09-13 경고).
> **강의가 먼저인 이유**: 1획독의 목적은 OS 전체 지형을 한 번 훑어 전체 지형을 한 번 훑은 상태를 만드는 것이고, OSTEP 정독은 그 지형이 생긴 뒤에 깊이를 넣는 작업이다. 190분 강의로 지형을, 토요일 영어 원문 학습 세션 한 번으로 **OSTEP을 맛만** 본다.
> **살려 둔 것**: 10-17 영어 원문 학습 세션의 OSTEP Ch.26~28(동시성)은 남는다. 동시성은 소마 Spring 서버의 스레드 모델과 직결이라 1획독 중에도 한 번은 원전으로 읽는다.

### 영상 세션 — 화~금 아침 45분 (영상 약 27분 + 거친 불릿 10분)

**강 번호는 첫 세션에서 채운다.** 네트워크가 99강에서 끝나므로 섹션 4는 100강부터일 것이 유력하지만, 강의 목록을 열어 확인하기 전에는 적지 않는다 — 08-17에 네트워크를 38~99강으로 확정한 것과 같은 절차다.

- [ ] **O1** (10-07 수): 섹션 4 시작 — 강의 목록에서 **강 번호·각 강 길이를 이 목록에 채우는 것부터.** 그다음 운영체제·컴퓨터 구조 기초
- [ ] **O2** (10-08 목): 프로세스·스레드
- [ ] **O3** (10-09 금): 메모리 계층·가상 메모리
- [ ] **O4** (10-13 화): 페이징·세그멘테이션·페이지 교체
- [ ] **O5** (10-14 수): CPU 스케줄링
- [ ] **O6** (10-15 목): 동시성 — 임계 영역·뮤텍스·세마포어·데드락
- [ ] **O7** (10-16 금): 섹션 4 종료 + `## 핵심 정리` 작성. 남으면 "Q." 강의로 자기 점검

10-20(화)부터는 [[학습/공부/CS/데이터베이스/데이터베이스|데이터베이스]] 섹션으로 넘어간다.

### 영어 원문 학습 세션 — 10-17 토 60~75분

- [ ] **10-17 토**: OSTEP Ch.28 «Locks» — https://pages.cs.wisc.edu/~remzi/OSTEP/threads-locks.pdf
  - 앞의 Ch.26 «Concurrency and Threads» — https://pages.cs.wisc.edu/~remzi/OSTEP/threads-intro.pdf · Ch.27 «Thread API» — https://pages.cs.wisc.edu/~remzi/OSTEP/threads-api.pdf 를 훑고 Ch.28을 정독한다(장별 PDF가 각각 따로 열린다).
  - O6에서 들은 동시성을 영어 원문으로 다시 읽고, **소마 Spring 서버의 스레드 모델과 JS 이벤트 루프를 각각 한 줄로 연결**해 `## 기록`에. 원문 한 문장을 그대로 인용한다

### 1획독 이후로 미룬 OSTEP 정독 계획 (2026-08-16 수립)

챕터는 짧아서 한 세션에 2~4장. 1획독 이후 이 순서로 재개한다.

- [ ] 프로세스·스레드 — OSTEP Ch.4~6 (Process, Process API, Limited Direct Execution)
- [ ] CPU 스케줄링 — OSTEP Ch.7~9 (Scheduling, MLFQ, Lottery)
- [ ] 가상 메모리 — OSTEP Ch.13~16, 18 (Address Spaces, Segmentation, Paging)
- [ ] TLB·페이지 교체 — OSTEP Ch.19~22
- [ ] 동시성 — OSTEP Ch.26~30 (Threads, Locks, Condition Variables) — **Ch.26~28은 10-17에 먼저 읽는다**
- [ ] 세마포어·데드락 — OSTEP Ch.31~32
- [ ] 파일시스템·I/O — OSTEP Ch.36~40 (I/O Devices, Disks, File System Implementation)
- [ ] 핵심 질문 10개에 스스로 답해보기
