# 운영체제

프로세스·스레드, CPU 스케줄링, 가상 메모리, 동시성(락·조건 변수·데드락), 파일시스템 — 프로그램이 커널 위에서 어떻게 실행되는가. 백엔드 서버(스레드 풀·커넥션·메모리)와 프론트 런타임(이벤트 루프가 왜 단일 스레드인지)을 설명하는 밑바닥이다.

## 핵심 정리

강의 1획독(09-30) 뒤에 프로세스 vs 스레드, 스케줄링 정책 비교, 페이징·TLB가 필요한 이유, 락·조건 변수·세마포어의 관계와 데드락 4조건, 파일시스템의 inode를 한 표로 정리한다. 지금 있는 것은 운영 중에 먼저 만난 하나다.

- **cron = 시간 기반 작업 스케줄러 데몬.** 1분마다 깨어나 표를 보고 명령을 대신 실행한다. 이 볼트의 루틴 식 셋은 전부 UTC라 KST−9 → [[학습/공부/CS/운영체제/cron|cron]]
