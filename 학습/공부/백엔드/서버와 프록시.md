# 서버와 프록시

**서버는 "포트를 붙잡고 요청을 기다리는 프로그램"이고, 프록시는 "요청을 대신 받아 다른 곳에 전달하는 서버"다.** 프록시를 두면 비밀(API 키)이 브라우저를 아예 지나가지 않는다 — 숨기는 게 아니라 경로에서 빼는 것이다.

## 핵심 정리

### 말의 구분

| 말 | 뜻 |
|---|---|
| **서버** | 포트를 붙잡고 요청을 기다리는 **프로그램**. `node server/main.js`로 띄운 그것 |
| **엔드포인트** | 그 서버가 응답하기로 한 **주소 하나** — `/api/pharmacies` |
| **API** | 엔드포인트들의 묶음 = *"이렇게 물어보면 이렇게 답한다"는 약속* |

공공 API를 호출하던 쪽에서 **응답하는 쪽으로 자리를 하나 더 갖는 것** — 그게 프록시를 만든다는 뜻이다.

### 서버는 안 끝난다

`listen`을 부르면 프로세스가 살아 있는 채로 요청을 기다린다. **터미널 프롬프트가 안 돌아오는 건 멈춘 게 아니라 일하고 있는 것이다.** 스크립트(`npm run build`)는 할 일을 하고 죽고, 서버는 안 죽는다. `npm run dev`(Vite)도 같은 이유로 안 끝난다 — 그것도 서버다.

### 라우트 등록은 `listen` 전에 전부

```
1. import
2. const app = Fastify(...)
3. app.get(...)   ← 라우트 전부
4. await app.listen(...)  ← 반드시 맨 마지막, 한 번
```

`listen`은 **개점 선언**이다. 손님을 받기 시작한 뒤에 메뉴판을 새로 짜겠다고 하면 Fastify가 `FST_ERR_INSTANCE_ALREADY_LISTENING`으로 거절한다. 공식 문서도 *"플러그인 로딩은 `fastify.listen()`·`inject()`·`ready()`를 호출할 때 시작된다"*고 쓴다 — 그 시점에 등록이 끝나 있어야 한다는 뜻이다.

경로는 **`/`로 시작해야 한다**(`ERR_ASSERTION: The first character of a path should be / or *`). `/`는 "이 서버의 루트 기준"이라는 뜻이고, 없으면 기준점이 없다.

### 프록시 — 요청이 두 번 간다

```
브라우저 ──① /api/x──> 내 서버 ──② 키를 들고──> 남의 API
```

**브라우저는 ②를 모른다.** 그래서:

- **DevTools Network 탭에 남의 API가 안 나온다.** Network 탭은 「브라우저가 보낸 것」만 볼 수 있다. 서버끼리의 통신은 브라우저 밖의 일이다
- **키가 안 보이는 건 잘 숨겨서가 아니라 애초에 안 지나가서다.** 이 차이가 중요하다 — 난독화·인코딩 같은 "숨기기"는 전부 뚫리고, 경로에서 빼는 것만 안 뚫린다
- **CORS 얘기가 사라진다.** 브라우저가 말을 거는 곳이 자기 출처와 같아지기 때문 → [[학습/공부/CS/CORS와 동일 출처 정책|CORS와 동일 출처 정책]]
- 덤: 응답을 **내 서버에 캐싱**할 자리가 생긴다. 남의 API 호출 한도를 방어하는 자리도 여기다

### 개발용 프록시는 배포에 없다

Vite 개발 서버의 `server.proxy`는 **개발 중에만** 도는 기능이다.

```ts
// vite.config.ts — 문자열 축약형
server: { proxy: { "/api": "http://localhost:3000" } }
```

브라우저는 `5173`으로 보내고 Vite가 `3000`으로 넘긴다. 배포판엔 Vite 개발 서버가 없으므로, **그 전달 역할을 실제 서버(Fastify)가 직접 맡아야 한다.**

### 환경변수를 읽는 두 방식

| | 브라우저 코드 | 서버 코드 |
|---|---|---|
| 문법 | `import.meta.env.VITE_X` | `process.env.X` |
| 언제 값이 정해지나 | **빌드할 때 문자열로 치환** | **실행할 때 읽음** |
| 비밀을 담을 수 있나 | **못 담는다** (번들에 박힌다) | 담을 수 있다 |

Node 20.6+는 `node --env-file=.env.local main.js`로 `.env`를 직접 읽는다(dotenv 패키지 불필요). 상세는 [[학습/공부/JS/JavaScript 모듈 시스템|JavaScript 모듈 시스템]].

## 기록

### 2026-09-09 — 프록시를 붙여 서비스키를 브라우저에서 없앴다

- 맥락: [[프로젝트/개인/약국맵/README|약국맵]] [[학습/야생학습/약국맵 사다리 3-A — Fastify 프록시 2026-09-09|사다리 3-A]]. 공고 스택(Fastify)을 "왜 필요한지" 측정으로 먼저 확인하고 붙였다
- 배운 것:
  - **먼저 측정했다**: `npm run build && grep -c 'serviceKey=' dist/assets/*.js` → **1**. 프록시가 필요한 이유가 문서의 주장이 아니라 눈으로 본 사실이 됐다. 붙인 뒤 같은 명령 → **0**
  - 요청이 두 홉이 되면서 **Network 탭에서 외부 API가 사라졌다.** "브라우저는 자기가 보낸 것만 안다"가 이 구조의 전부다
  - `listen` 순서·경로 `/`·`--env-file` 누락으로 에러가 세 번 났는데, **각각 다른 층에서 잡혔다**(파싱 / 등록 / 원격 서버)
