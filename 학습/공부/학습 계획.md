## CS 3시간 블록의 구조 (2026-09-17 (2))

**세션 3개를 잇는다.** 한 세션은 아래 네 토막이고, 이게 55분이다. 3시간이면 세션 3개 + 쉬는 시간이다.

| 시간 | 무엇 |
|---|---|
| **5분** | **복습** — 지난 세션·3일 전·일주일 전 것을 섞어 에이전트가 묻는다 |
| **30분** | **영상** |
| **10분** | **명령 검증** — 에이전트가 준 명령을 **홍이 직접 친다** → **결과 2지선다 예측과 대조** |
| **10분** | **말로 뱉기** — 노트 덮고 에이전트에게 설명(말 + 타이핑). 그게 `## 기록`의 원료가 된다 |

- **예측은 강의 제목이 아니라 「명령 결과」에 대해 한다.** 배경 지식 0에서도 2지선다는 고를 수 있고 답이 10초 안에 나온다.
- **검증 명령이 없는 강은 억지로 만들지 않는다** — 영상 + 말로 뱉기로 간다.
- 검증 수단: **네트워크** `curl -D -`·`dig`·`route get default` / **운영체제** `ps`·`vmstat`·`lsof`·`sysctl` / **데이터베이스** `EXPLAIN`·소마 실제 쿼리.
- **1획독이 끝나면 이 블록은 면접 대비로 바뀐다** — 인출(말로 답하기)·약한 주제 재시청·영어 원문.

## 토요일 영어 원문 — 순서를 뒤집는다 (2026-09-17 변경)

**에이전트가 한국어 요약을 먼저 주고, 홍은 원문에서 그 근거 문장을 찾아 옮긴다.** 통독하지 않는다. 산출물은 그대로 **원문 인용 한 문장**이고, 강의와 어긋나면 그 차이를 `## 기록`에 남긴다.

> [!note] 왜 뒤집었나
> 09-09에 홍이 한 말 — *"문서를 주면 다 보기에는 어렵고 **영어로 쓰여 있어서 더 어려운 것 같아서**"*. 그때 해법이 「한국어 링크 + 절 이름 + 요약 3줄」이었는데, 토요일 세션은 정의상 영어 원문이라 그 해법을 쓸 수 없었다. **평일에 없앤 마찰을 주말에 60~75분짜리로 되살려 둔 셈이었다.**
> 목적은 09-13에 이미 *"지식보다 **원문을 직접 읽는 습관**"*으로 적혀 있다. 습관이 목적이면 통독일 필요가 없다. 찾기는 읽기보다 쉽고, 영어 노출과 산출물은 그대로 남는다. 공부 README 원칙 5(블로그 → 원전 교차검증)의 방향을 뒤집은 것뿐이다.
