> [!important] 2026-09-13 — **CS를 아침 첫 자리로 옮겼다. 횟수는 그대로 주 5회다** (홍의 결정)
> **09-02 콜아웃의 되돌림 조건이 발동했다**: *"주 5회로 2주(09-02~09-15) 돌린 뒤에도 실행이 절반 아래면, 문제는 횟수가 아니라 슬롯이 어느 시간대에 놓이는가다 — 그때는 횟수를 다시 만지지 말고 시간대를 정한다."* 표본은 **0/10**이었다. `## 기록` 마지막 항목이 08-22이고 일간 파일 09-01~09-12가 전부 같은 `W1-3`을 이월했다(12일).
> **같은 기간 아침 실습은 돌았다** — 약국맵 커밋 5개(`238df0c`…`f4de709`), 세션 1·2·2-B·3-A~3-C 완료. 차이는 **"소마 작업 시작 전 아침"이라는 시각이 박혀 있었는지**뿐이다. 그래서 CS를 그 검증된 앵커의 **첫 자리**에 넣었다.
> **JS 워밍업 15분은 실습에 흡수한다.** 아침 블록이 CS 45 + 실습 35 = 80분인데 워밍업까지 앞에 두면 95분이 되고, 그건 08-20에 되돌린 "하루 1시간" 기조를 두 배로 넘긴다. 게다가 **09-09에 갱신된 JS 노트 3개**([[학습/공부/JS/언어/JavaScript 모듈 시스템\|모듈 시스템]]·[[학습/공부/JS/언어/JavaScript 기초 문법\|기초 문법]]·[[학습/공부/JS/언어/TypeScript 타입 시스템\|타입 시스템]])가 **전부 실습에서 나왔다** — 실습이 이미 매일 JS를 손으로 쓰게 만들고 있다. **되살릴 조건**: 실습에서 문법 자체 때문에 막히는 일이 다시 잦아지면 별도 15분을 복원한다.
> **9·10월 목표는 1획독이다** — 강의 1획독 + 영어 원문 학습 주 1회. 무엇을 뺐는지는 아래 CS 학습 절.

> [!note] 2026-09-05 — MyCryptoDiary 블록이 **실습(아침)**로 바뀌었다. 총량은 그대로
> MyCryptoDiary는 09-05에 잠시 중지됐다(원인은 풀스택 범위의 난이도 — [[프로젝트/개인/MyCryptoDiary/D4 회고 2026-09-04|D4 회고]]). 그 자리에 TanStack Query·Streaming SSR·하이드레이션·리렌더 측정을 버리는 코드로 익히는 [[프로젝트/개인/약국맵/학습 로드맵|실습]]가 들어간다 — **소마 작업 시작 전 아침 30~45분, 화~토.** JS 워밍업 15분과 CS 주 5회(네트워크)는 홍의 결정으로 그대로다. **08-21 진단("막힌 지점은 전부 JS 언어 자체")은 유효하다** — 실습에서도 언어 때문에 막히면 그 자리에서 파지 않고 워밍업 주제로 보낸다. 세션에서 개념이 남으면 `JS/` 주제 파일(SSR과 하이드레이션 · 서버 상태와 TanStack Query · React 렌더링과 리렌더 최적화)로 승격한다 — 실제로 나온 것만.

> [!important] 2026-08-21 — JS 문법을 CS보다 위에 올렸다 (본인 결정)
> **진단**: MyCryptoDiary D1이 계획 6.5h → 4 작업일이 걸렸는데, 막힌 지점을 세어 보니 전부 **JS 언어 자체**였다 — 구조 분해(`const { searchParams } = ...`), 객체 리터럴(`{ error: '...' }`), truthy/falsy(`if (!markets)`), 배열 메서드(`join`/`split`/`find`). React·Next·FSD 같은 상위 개념은 오히려 빨리 이해했다(캐시 주기를 데이터 변화 속도로 정하기, 메타데이터 하드코딩을 스스로 버린 판단). 상세는 [[프로젝트/개인/MyCryptoDiary/모의투자 전환 D1 2026-08-16|D1 작업 기록]].
> **언어가 안 익으면 모든 게 3배 어려워진다** — 코드를 읽을 때 문법 해독에 뇌를 다 써서 정작 설계를 볼 여유가 없다.
> **방법은 강의·책이 아니라 손**이다. 근거: 튜토리얼 없이 4일 만에 위젯을 실데이터로 연결했고 그 와중에 설계 판단까지 했다. 반대로 대화 중 길게 설명한 개념은 지금 다시 물으면 절반이 흐릿하다.
> **우선순위 근거**: 08-21 진단대로 막힌 지점이 전부 JS 언어 자체라 JS를 CS보다 앞에 둔다.

> [!important] 2026-09-02 — CS를 **주 5회로 되돌렸다**. 08-21의 "화·금 주 2회"는 폐기 (홍의 결정)

## JS 문법 워밍업 — 6일 순환 (매일 15분)

`node` 띄우고 **예측 먼저, 그다음 엔터.** 15분 넘기지 않는다. 틀린 것이 그날 배운 것.
